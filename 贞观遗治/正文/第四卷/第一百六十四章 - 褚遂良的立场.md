# 第一百六十四章 褚遂良的立场

贞观十七年深秋，一场决定性的朝会。

议题是立储。

太子承乾已经被废，魏王李泰的野心已经不是秘密，晋王李治站在朝堂上，像一个安静的影子。朝臣们知道，今天之后，储君之位就会尘埃落定。所有人都等着看谁会站出来，会站在哪一边。

朝会开始后的一段时间里，殿内安静得有些异常。没有人先开口。百官站在那里，目光低垂，仿佛都在等别人先迈出那一步。

然后褚遂良出列了。

沈知远在殿角握紧了笔。褚遂良比他年长许多，官阶也高，在中书省里是沈知远的上司之一。此人的文名很盛，书法冠绝一时，但沈知远更关注的是他在政治上的判断。褚遂良不是那种轻易表态的人——他说话慢，落笔稳，从不随声附和。他的意见，往往代表了中书省内部某种经过深思熟虑的倾向。

褚遂良的声音不大，但很清晰。他说："陛下，晋王仁孝，天下所知。立嫡以长，以贤以德，晋王当立。"

殿内更安静了。

这句话等于明确站在了李治一边。褚遂良说完，没有退回去，仍然站在那里，腰背挺直，双手执笏，姿态端正。沈知远在记录中一字不差地记下了这句话。写完之后，他的笔尖在纸面上停了一瞬——褚遂良的选择，将影响接下来的朝局走向。

褚遂良不是一个人。他的背后有长孙无忌的影子——虽然长孙无忌一句话都没有说，但所有人都知道这两人之间的关系。褚遂良的表态，某种程度上也代表了长孙无忌的立场。沈知远抬眼迅速扫了一下武官行列中的长孙无忌。他还是那副表情——不动声色地站在那里，好像在旁观和自己无关的事。

朝会结束后，沈知远收拾好记录，走出大殿。在廊下他遇到了褚遂良。褚遂良走在前面，步子不快，沈知远追上了他，叫了一声"褚公"。褚遂良停下来，回头看了他一眼。

沈知远没有说任何关于刚才朝会的事。他只是问了一句关于书法的问题，说最近在练习褚遂良的楷书，有几个笔画的收笔处总是写不好，想请教。褚遂良看了他几秒，然后微微点头，说改日可以拿字来给他看看。说完转身走了。

沈知远站在原地，看着褚遂良的背影在长廊拐角处消失。他低头看了看自己的手——握笔的那只手，指甲修剪得很整齐，指腹上有一个常年握笔磨出的茧。褚遂良今天的选择，意味着未来很长一段时间内，李治的储君地位会有中书省的支持。而沈知远自己的立场——他没有任何立场。他的立场就是如实记录，然后继续过他的日子。

他回到值房，把今天朝会的记录誊清、归档、放好。一切做完之后，他坐下来，研了一点新墨，铺开一张纸，开始练字。他临的是褚遂良的《孟法师碑》，一笔一划，很慢很稳。

练了约莫半个时辰，他停笔，把临好的字举到灯下看了看。褚遂良的字笔力清瘦，筋骨分明，每一个转折都带着一种不容置疑的自信。他自己的字相比之下软了一些，像是一棵树还没有长到足够的年月。他把那张纸折起来，夹进一本旧书里。他想起褚遂良说的那句“立嫡以长，以贤以德，晋王当立”——这十四个字，沈知远把它们刻在了脑子里。不是因为措辞漂亮，而是因为它说了一个事情：中书省的最高文官之一，在这个关键的时刻选择了站在长孙无忌一边。这让未来的朝局多了一重可预测性，但也多了一重风险。如果将来长孙无忌和皇帝之间产生分歧，褚遂良会站在哪一边？这个问题的答案，可能决定了未来十年中书省的命运。沈知远把灯芯挑亮了一些，又铺开一张新纸。他决定今晚多写几页字。
