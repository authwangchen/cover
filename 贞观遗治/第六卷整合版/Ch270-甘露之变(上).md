# 第二百七十章 甘露之变（上）

大和九年，冬。

文宗想除掉宦官。

这个念头在他心里藏了好几年。从登基的那天起，他就知道自己的处境——皇帝是宦官立的，皇帝也可以被宦官废。敬宗是怎么死的，宪宗又是怎么死的——他都记得。

他不想和他们一样。

他暗中联络了几个信得过的官员。宰相李训，节度使郑注——这两个人是他最信任的棋子。他们计划了一次行动：谎称金吾厅后的石榴树上降了甘露——古时候，天降甘露是祥瑞，上天对皇帝治理的认可。到时候宦官们会出来观看，趁其不备，一网打尽。

计划制定得很周密。

十一月的某一天，按照计划上朝，宦官们按规定都要陪同皇帝去观看甘露。文宗坐在龙椅上，听着官员们的报告，手指在扶手上轻轻敲着——他在等。

消息传进来了。

"左金吾厅后，石榴树上，夜降甘露。"

文宗站起来，说："朕当亲往。"

宦官们跟着他走出了大殿。

金吾厅在含元殿前。皇帝和宦官们穿过广场的时候，风吹过来，冷得刺骨。文宗的袍子在风里卷了一下。他裹了裹袍子，继续往前走。

金吾厅的门是关着的。

有人上去敲门。没有人应答。

文宗站在广场中央，看着那扇紧闭的门。风吹着他的袍角，吹得忽忽作响。他等了一小会儿，又叫人上去敲门。仍然没有人应答。

仇士良——禁军中尉，权力最大的宦官——站在皇帝的身旁。他的眼睛一直盯着那扇门。他看了一会儿，转头对自己的亲信说了几句话。那亲信快步走向了金吾厅的后墙。他翻墙跳了进去。

里面没有甘露。只有伏兵。

消息传出来的时候，仇士良的脸色变了。他发出命令——"有变。"

神策军的士兵从四面八方涌了出来。

不是计划里的"一网打尽"——是宫变。

文宗站在广场上，看着那些穿着黑色军服的神策军士兵从各个方向跑出来，手中握着刀，刀光在冬日的阳光下闪着寒光。他的手握紧了——他没有动。

仇士良转过头对他说话："陛下，请回宫。"

文宗没有说话。他转身，走回了含元殿。

李训跑了。郑注在凤翔，还没有来得及赶到长安就得到了消息——失败了。他掉头就跑，没有跑掉。追兵追上他，当场斩首。

文宗被宦官们软禁在了内宫。

那天长安城的天很阴沉，没有下雪，但风很大。风卷着尘土在街道上横冲直撞，行人都低着头走路，用袖子遮着脸。

神策军的士兵在长安城里抓人。

他们敲开每一扇门——不问身份，不问官职，只要是被怀疑参与了那场计划的人，就地正法。宰相李训的家人被抄了，上下老幼一个不留。知情者、不知情者、路过的邻居、隔壁卖菜的——只要和那家人有关系，全部被杀。

郑济的铺子在崇仁坊。

那天下午，神策军的士兵敲了他隔壁的门。隔壁住着一个姓张的御史。士兵们冲进去之后，郑济听到了几声喊叫，然后是一声闷响。过了一会儿，几个士兵抬着一具尸体出来，扔在了门口的板车上。板车已经装了好几具尸体了，摞在一起，手脚交错着，在风中微微晃动。

郑济站在自己的铺子里，把门掩了一半。从门缝里看出去，他看到板车上的血顺着车板的缝隙往下滴——滴在路上，一滴，一滴，一滴。没有人去擦。过路的行人绕着血走。

那天长安城里死了多少人，没有人说得清楚。有人说一千，有人说两千，有人说更多。

那些死人里，有真的参与了的，有被冤枉的，有路过的，有躲在家门口还没来得及跑的。刀不认人。

郑济在门后站了整整一个下午。

他没有开门。他没有开灯。他就那样站在黑暗里，听着外面的声音——士兵的脚步声、马蹄声、敲门声、喊叫声、哭声、闷响。那些声音从远处传来，又渐渐远去，然后又有新的声音从另一个方向传来。此起彼伏，像是长安城在一夜之间变成了一座巨大的刑场。

当所有声音消失之后，天已经全黑了。长安城的街道上再没有一个人走动。宵禁提前了一个时辰。整座城市沉在黑暗和安静里。

郑济坐在门后的地上，手上还握着那块木板——他也不知道自己什么时候拿起来的。

"贞观遗制"——四个字。

他在黑暗中摸到了木板上的刻痕。那些刻痕深深的，填过墨的地方有些凸起。

他握了一夜。
