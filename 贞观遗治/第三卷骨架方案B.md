# 第三卷《暗战》骨架（方案B定稿）

> 副标题：制度落地后，真正战争才开始
> 时间：贞观七年（633）→ 贞观十七年（643），跨度11年
> 章节：Ch101—150，50章
> 核心主题：制度已立，但执行靠人；夺嫡之争波及制度布局

---

## 一、Vol2→Vol3衔接

### Vol2出口

贞观六年春末·长安春雪。韩慎尚在。沈知远起居郎（从六品上），关陇黑名单上的人。刚躲过一次暗杀。遗制第四稿。

### Vol3入口

贞观七年春。Ch101以"贞观七年，春"开篇，用一段回述过渡已过的4年，不做逐章填充。

## 三、分幕详表

### 第一幕：过渡与皇后崩（Ch101-120，20章）

**时段**：贞观七年→十年（4年）

#### Ch101-108：贞观七→九年过渡（8章）

| 章 | 标题暂拟 | 核心内容 | 功能 |
|----|---------|---------|------|
| 101 | **七年春** | 贞观七年春，沈走过归义坊巷口，看到新换的禁令告示。回到值房，整理起居注 | 时间过渡，归义坊线延续 |
| 102 | **马周来访** | 马周带来一份关于武德旧档的线索——他在门下省旧档中发现了一份不应存在的交接记录 | 武德旧档线重新激活 |
| 103 | **起居注的暗痕** | 沈查阅起居注底稿，发现贞观元年某日长孙无忌的奏对记录与存档不一致 | 武德旧档→长孙关联初现 |
| 104 | **韩慎·冬** | 韩慎咳嗽加重。沈下值后去东市抓药，药铺伙计说"这副药不便宜" | 韩慎线积累 |
| 105 | **韩慎·终** | 韩慎在一个清晨安静地走了。沈没有哭，在门槛上坐了一整天。整理遗物时发现一本旧笔记——韩慎记下了年轻时在秘书省见过的"被抹掉的人"的名字 | ⭐情感高潮+伏笔回收 |
| 106 | **空院** | 沈一个人住在空荡荡的小院里。马周来陪他喝了一壶酒 | 孤独感建立 |
| 107 | **三年报告** | 分署办公试点三年报告送到案头——效果显著，但阻力也在增大 | 制度推进 |
| 108 | **贞观九年** | 朝会上听到消息：吐谷浑平定。沈知道大唐的边患正从西北转向东北 | 历史事件+铺垫 |

#### Ch109-120：贞观十年·皇后崩（12章）

| 章 | 标题暂拟 | 核心内容 | 功能 |
|----|---------|---------|------|
| 109 | **长孙皇后** | 春，长孙皇后病重。沈站在殿廊下记录御医出入的次数 | 历史事件 |
| 110 | **崩** | 六月，皇后崩。太宗辍朝三日 | 历史事件 |
| 111 | **太子** | 葬礼上，沈第一次正面看到李承乾——十岁的孩子，站在母亲灵前，背挺得很直 | ⭐太子首登场 |
| 112 | **关陇暂退** | 长孙无忌守丧暂退，关陇集团群龙无首。窗口期出现 | 政治变化 |
| 113 | **窗口** | 沈利用关陇暂退，将之前被搁置的军政分离试点范围扩大 | 制度推进 |
| 114 | **默许** | 太宗默许了沈的方案。沈意识到这是皇后崩后权力重组带来的机会 | 制度推进 |
| 115 | **扩大** | 试点方案通过，扩大到陇右、河西两个边镇 | 制度推进 |
| 116 | **旧档再查** | 沈在整理旧起居注时发现：被"抹掉"的那个人最后一条记录，与长孙无忌的升迁时间只差三天 | 武德旧档→长孙线索强化 |
| 117 | **仓曹旧吏** | 通过马周找到当年仓曹的旧吏。旧吏承认代签存在，但说"上面有人" | ⭐仓曹签名回收 |
| 118 | **代签真相** | 旧吏说出了当时指使代签的人名——一个已故的仓曹参军，是长孙家的门客 | 仓曹签名回收完成 |
| 119 | **武氏入宫** | 贞观十一年，沈听到消息：武氏入宫，封才人。他知道这个名字意味着什么，但什么都不能说 | ⭐武则天登场 |
| 120 | **长孙复出** | 守丧期满，长孙无忌复出。第一件事：调阅沈知远这几个月推动的所有文件 | 冲突再起，幕终 |

### 第二幕：太子之争（Ch121-135，15章）

**时段**：贞观十年→十五年

| 章 | 核心内容 | 功能 |
|----|---------|------|
| 121-122 | 李承乾（太子，足疾，性情渐躁）vs 李泰（魏王，才华横溢，深得宠爱） | 夺嫡开端 |
| 123-125 | 沈的困境：他知道李治胜出→长孙辅政→武则天杀长孙；不能暴露；任何站队都会毁掉布局。选择：通过房玄龄暗示"太子不可轻废，藩王不可过重" | 核心困境 |
| 126 | 长孙无忌押注李泰。关陇集团开始为李泰铺设权力基础 | 长孙线 |
| 127-128 | ⭐武德旧档回收：沈将旧起居注中被修改的记录与被抹掉的人物传记对照，确认所有修改指向同一目的——掩盖长孙无忌在武德年间的一场政治清洗。证据留在了起居注的暗格中 | 大伏笔回收 |
| 129-130 | 归义坊车辙印回收：沈通过兵部旧档发现运粮路线与长孙家商号路线重叠——归义坊夜火可能与私运军粮有关 | 伏笔回收 |
| 131-132 | 夺嫡日趋激烈。韦家公开站队李泰 | 伏笔回收（韦家） |
| 133-135 | 韦家站队暴露了长孙的真正布局。沈意识到：长孙无忌押注李泰，不是为了李泰本人，是为了削弱太子，最终推举更容易控制的李治上位 | 长孙线深化 |

### 第三幕：府兵裂痕（Ch136-140，5章）

**时段**：贞观十二年→十五年

| 章 | 核心内容 | 功能 |
|----|---------|------|
| 136 | 沈巡察关中军府。发现府兵制深层问题（呼应Vol2 Ch68） | 巡察 |
| 137 | 关键画面：一个年轻府兵伸出手——掌心老茧是握锄头的，不是握刀的。和Vol2 Ch68形成呼应对照 | 意象呼应 |
| 138 | 沈上书《府兵弊疏》。核心：府兵之弊不在无兵，而在无田 | 制度推进 |
| 139 | ⭐朝会当面对峙："臣不懂兵，臣懂数字。贞观十年关中府兵在册十二万，实到七万三。差额四万七千人——请问长孙大人，这四万七千人去了哪里？" | 全书级场景 |
| 140 | 太宗犹豫。"限田令"和"府兵仓"被搁置。但边将限任仍继续执行 | 部分胜利 |

### 第四幕：马周之死与魏徵夜谈（Ch141-148，8章）

**时段**：贞观十五年

| 章 | 核心内容 | 功能 |
|----|---------|------|
| 141-142 | 马周病重。沈守在床前。马周瘦得脱了形，但眼睛还是亮的 | 情感铺垫 |
| 143 | ⭐马周临终："卿之制度，百年后方见其效。然百年之后，谁还记得沈知远？卿可愿为此？"沈答："愿。历史不记得我，只要记得那些制度。" | 全书级高潮 |
| 144 | 马周葬礼。沈站在雨中，没有打伞 | 情感 |

| 147 | ⭐魏徵召沈夜谈。魏徵："你想用制度代替贤臣？"沈答："臣只是不敢赌后世还有贤臣。"魏徵沉默良久，没有再反驳 | 全书级高潮 |
| 148 | 魏徵走的时候在门口站了一下。贞观十七年，魏徵病逝于任上 | 历史收束 |
