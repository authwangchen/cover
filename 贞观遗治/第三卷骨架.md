# 第三卷《暗战》骨架（方案B修订版）

> 副标题：制度落地后，真正战争才开始
> 时间：贞观七年（633）→ 贞观十七年（643），跨度11年
> 章节：Ch101—150，50章

---

## 核心调整说明

**原大纲**：Vol3 贞观十年→十七年（7年）
**方案B**：Vol3 贞观七年→十七年（11年）

调整动机：Vol2实际只写到贞观六年，原"Vol2 7年50章"的写作节奏实测是"3年50章"。强行跳过4年会造成断层。

### Vol2→Vol3 新衔接

```
Vol2末（贞观六年春）→ Ch101回述覆盖4年 → Vol3正式从贞观十年开始
                            ↓
                    Ch101-115 分述贞观七→九年：
                    起居郎日常、制度深化、韩慎离世（若存活至此）、
                    武德旧档线索浮现、马周升迁
```

## 分幕详析

### 第一幕：过渡与崩塌（Ch101-120）

**目的**：覆盖贞观七→十年的4年空缺，让时间自然流到皇后崩

**Ch101-108（贞观七年→九年）：过渡铺垫**

| 章 | 核心内容 | 功能 |
|----|---------|------|
| 101 | **七年春**：沈下值后经过归义坊巷口，看到新贴的告示——和几年前一样的那条禁令，纸又换了一张新的 | 归义坊线延续 |
| 102 | 马周来访，带来一份关于武德旧档的线索 | 武德旧档线重新激活 |
| 103 | 沈在起居注中发现一条被修改过的记录——贞观元年某日，长孙无忌的奏对内容与存档不符 | 武德旧档→长孙关联初现 |
| 104 | 韩慎病情加重（若Vol2未写韩慎结局，则在此安排） | 情感线 |
| 105 | **韩慎离世**：沈失去长安最后一个亲人。在韩慎遗物中发现一本旧笔记，记录了他年轻时在秘书省见过的"被抹掉的人"——和沈在旧档中发现的线索指向同一个人 | 伏笔回收+情感高潮 |
| 106 | 沈一个人住在空荡荡的小院里。马周来陪他喝了一壶酒 | 孤独感建立 |
| 107 | 分署办公试点三年报告送到案头——效果显著，但阻力也在增大 | 制度推进 |
| 108 | 贞观九年，沈在朝会上听到消息：吐谷浑平定。他知道大唐的边患正在从西北转向东北 | 历史事件+铺垫 |

**Ch109-120（贞观十年）：皇后崩+关陇暂退**

| 章 | 核心内容 | 功能 |
|----|---------|------|
| 109 | 春，长孙皇后病重。沈站在殿廊下记录御医出入的次数 | 历史事件 |
| 110 | 六月，长孙皇后崩。太宗辍朝，长安暂停一切喜庆活动 | 历史事件 |
| 111 | 葬礼上，沈第一次正面看到太子李承乾——十岁的孩子，站在母亲灵前，背挺得很直 | ⭐太子首次出场 |
| 112 | 长孙无忌守丧暂退朝堂。关陇集团群龙无首 | 窗口出现 |
| 113-115 | 沈利用窗口期，将之前被搁置的军政分离试点范围扩大，并争取到太宗的默许 | 制度推进 |
| 116 | 沈在整理旧起居注时发现：武德年间被"抹掉"的那个人，其最后一条记录与长孙无忌的升迁时间高度吻合 | 武德旧档→长孙线索强化 |
| 117-118 | 通过马周找到当年代签的仓曹旧吏，仓曹签名代签案获关键突破 | 仓曹签名回收 |

### 第二幕：太子之争（Ch121-135）

**时间**：贞观十年→十五年

| 章 | 核心 | 功能 |
|----|------|------|
| 121-122 | 李承乾（太子，足疾，性情渐躁）vs 李泰（魏王，才华横溢） | 夺嫡开端 |
| 123-125 | 沈的困境：他知道李治胜出→长孙辅政→武则天杀长孙；但不能暴露；任何站队都会毁掉制度布局。选择：通过房玄龄暗示"太子不可轻废，藩王不可过重" | 核心困境 |
| 126 | 长孙无忌开始押注李泰 | 长孙线 |
| 127-128 | ⭐武德旧档正式回收：沈将旧起居注中被修改的记录与被抹掉的人物传记对照，确认所有修改都指向同一目的——掩盖长孙无忌在武德年间的一场政治清洗。他没有声张，但证据留在了起居注的暗格中 | 伏笔回收 |
| 129-130 | ⭐归义坊车辙印回收：通过兵部旧档发现运粮路线与长孙家商号重叠。沈意识到归义坊夜火可能与私运军粮有关 | 伏笔回收 |
| 131-135 | 长孙+韦家联盟在夺嫡中暴露：韦家公开站队李泰。沈通过这条线确认了长孙无忌的真正政治布局 | 伏笔回收 |

### 第五幕：制度入律+太子谋反（Ch149-150）

**时间**：贞观十五年末→十七年

**压缩说明**：原大纲Ch146-150（5章）压缩为2章。因第五幕的核心事件（太子谋反+长孙复出+制度入律）主要是历史收束而非叙事展开，2章足够。

| 章 | 核心 | 功能 |
|----|------|------|
| 149 | 贞观十七年正月。边将限任和军政分离的条款经过多年博弈，终于写入律法。沈拿到正式文本时，手指微微发抖 | 制度入律 |
| 150 | 三月，太子李承乾谋反被废，李泰被贬，李治立为太子。长孙无忌权势更盛，成为托孤首臣。沈站在长安城头，看着暮色中的帝国。他知道自己做了能做的一切。剩下的，交给时间 | 卷终 |
