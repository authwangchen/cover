# 第二百四十六章 安禄山兼三镇（中）

天宝十载，夏。

安禄山在三镇节度使的位置上坐稳了之后，做了一件事：大规模更换将领。他逐渐罢免了先帝时期任命的人。不是杀掉，是把那些不是自己心腹的人调离要害职位，换上自己的亲信。史思明、崔乾祐、高邈、李归仁——这些后来在那场席卷天下的浩劫中如雷贯耳的名字，此时正一个一个地被安禄山提拔起来，安置在三镇的各个关键位置上。

他也开始大规模囤积武器。他给朝廷的奏报里写的是：边关不宁，须加强武备。朝廷批了。于是安禄山名正言顺地给自己增加了一个兵器厂。他在范阳城外设了铸甲场，日夜不停。箭矢堆积如山，刀枪的数量足够装备一支二十万人的大军。夜里经过那里，能听到铁锤敲打的叮当声，远近皆知。

他还养马。

他在范阳以北的大草原上设立了一个巨大的牧场，从契丹和奚人那里购入大量的战马。每年数千匹。这些马在草原上繁殖，三年之后就是一支庞大的骑兵。他的副将史思明有一次巡视牧场回来，对安禄山说了一句话：

"将军，这些马——够跑到长安了。"

安禄山没有说话。他坐在案前，面前摊着一张地图。地图上用朱笔画了一个圈——从范阳到洛阳，再从洛阳到长安。他的手指在那些州县的名字上一个个点过去。他的嘴角微微动了一下。
