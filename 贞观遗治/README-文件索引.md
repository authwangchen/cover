## 🎯 使用指南

### 写作前
1. 阅读 **00-作品定位与核心设定.md** —— 理解作品基调
2. 阅读 **04-写作风格指南.md** —— 统一语言风格

### 写作中
1. 参考 **01-六卷完整大纲.md** —— 确认当前卷剧情
2. 参考 **02-300 章结构总纲.md** —— 确认当前章节位置与钩子
3. 参考 **03-人物关系权谋图.md** —— 确认人物关系和立场

### 写作后
1. 检查是否符合 **04-写作风格指南.md** 中的规范
2. 确认章节钩子是否足够强
3. 更新本索引文件
