## 二、🔴 严重问题（时间倒流/重叠）

### 1. Ch54→Ch55: 三月→正月倒流

```
Ch54→Ch55: [时间倒流，无过渡信号]
  上章结尾: 「第二天，旨意下来了。」
  下章开头: 「旨意下来之后的几天，沈知远没有睡好。……正月里的天气一直不好不坏……正月十六七的月亮还圆着」
  问题: 
    - Ch53 明确在"三月中旬"，Ch54 是降俘入城"第二天"——即三月中旬。
    - Ch55 开头随即切换到"正月十六七"（约两个月前），无任何"在此之前"/"数日前"等回溯信号。
    - 读者从Ch53-54的三月叙事突然跌回正月，没有过渡引导。
  修复: 
    - 方案A：在Ch55开头加上明确的回溯句（如"此事需回溯到正月"）
    - 方案B：将Ch55-57整体移至Ch53之前
    - 方案C：在Ch54末添加过渡段，提示接下来要回溯
```

### 2. Ch64→Ch65: 贞观五年→贞观四年整年倒流

```
Ch64→Ch65: [时间倒流，倒退一整年]
  上章结尾: Ch64整体在贞观五年三月初十（归义坊纵火案）
  下章开头: 「贞观四年春末。……看不出两个月前这里曾有过一场几乎烧穿半边坊的火灾。」
  问题:
    - Ch63：贞观四年三月（番学设立）
    - Ch64：贞观五年三月初十（归义坊夜火）——已跳越一整年
    - Ch65：贞观四年春末（第一幕收束）——又倒退回贞观四年
    - 若Ch64是第二幕事件、Ch65是第一幕收束，则Ch65应放在Ch64之前
    - 或Ch64应删除"贞观五年"标注，改为贞观四年
  修复:
    - 方案A：将Ch64（归义坊夜火）移至Ch65之后（Ch66之前）
    - 方案B：若Ch64纵火案确实是贞观五年事件（区别于Ch65提到的贞观四年三月底旧火），则需在Ch64开头添加过渡句说明已过一年
    - 方案C：统一改为同一年（贞观四年），消除年号差异
```

### 3. Ch70→Ch71: 正月十七→腊月二十一倒流

```
Ch70→Ch71: [时间倒流，倒退约四周]
  上章结尾: 「贞观五年正月十七的夜雪。雪不大，细细碎碎的……雪花落在窗纸上」
  下章开头: 「贞观四年，腊月二十一。长安城入冬以来最冷的一天。」
  问题:
    - Ch70从贞观四年十月末写到贞观五年正月十七（跨越三个月）
    - Ch71立即跳到贞观四年腊月二十一——比Ch70结尾早约四周
    - 读者读完一场夜雪后，突然被拉回到一个月前的寒冬
  修复:
    - 将Ch71-73（腊月二十一→年底→正月十二）移至Ch70之前
    - 或在Ch70末尾增加"回溯"标注
```

### 4. Ch80→Ch81: 晚春→早春重叠倒流

```
Ch80→Ch81: [同一季节内时间重叠]
  上章结尾: 「番学风波平息之后，贞观五年的春天快过完了。……第二幕落幕了。」
  下章开头: 「贞观五年，春。秘书省院子里的那棵桃树开花了。……沈知远在秘书省已经待了整整一年。」
  问题:
    - Ch80在贞观五年晚春（番学风波在三月中旬，平息后"春天快过完了"）
    - Ch81在贞观五年早春（桃花刚开，描述整年回忆）
    - 两者在同一年春，但Ch81的叙事起点比Ch80更早
    - 读者刚读完"第二幕落幕"，下一章又回到了第二幕开始的时间点
    - Ch81内容（编纂组成立、日常）实际上是Ch80之前发生的事
  修复:
    - 方案A：Ch81开头添加"回溯"信号，如"若要回溯这一年春天的起点……"
    - 方案B：将Ch81移至Ch79之前（番学风波前）
    - 方案C：将Ch81的时间改为贞观六年春（但会与后续Ch82-84的贞观五年三月冲突）
```

### 5. Ch90→Ch91: 九月→五月倒流

```
Ch90→Ch91: [时间倒流，倒退约四个月]
  上章结尾: 「编纂组内部的分署办公条款表决通过了。」（延续Ch89的贞观五年九月背景）
  下章开头: 「贞观五年，五月末。长安城里的暑气还没有完全逼上来」

    - 方案A：将Ch91-93（五月→六月太宗试探）移至Ch88（八月）与Ch89（九月）之间
```

## 三、🟡 中等问题（大幅跳越缺过渡）

### 6. Ch52→Ch53: 正月→三月中旬跳越（约2-2.5个月）

```
Ch52→Ch53: [大幅时间跳越，缺过渡句]
  上章结尾: Ch52整体在贞观四年正月（李靖捷报入京），末段沈知远写下"贞观遗制"四个字
  下章开头: 「三月中旬。沈知远到秘书省的时候天还没有大亮。」
  问题:
    - 从正月直接跳到三月中旬（约2-2.5月），中间发生了什么？
    - 遗制的进展、朝堂的讨论、俘虏的押送过程——全被跳过
    - 但Ch53开头提到"这几天长安城一直处在一种奇异的躁动中。捷报带来的狂欢还没有完全散去"，暗示时间已过去数周但仍与捷报有情绪连接——这个处理比完全没有过渡好，但仍显突兀。
  修复:
    - 在Ch52末尾或Ch53开头添加1-2句过渡（如"此后的近两个月里，长安城的狂欢渐渐沉淀为等待"）
    - 或整合Ch56-57的二月事件插入此空档
```

### 7. Ch63→Ch64: 贞观四年三月→贞观五年三月跳越（整年）

```
Ch63→Ch64: [整年跳越，年号断层]
  上章结尾: Ch63在贞观四年三月（番学设立，桃花落窗台）
  下章开头: 「贞观五年三月初十，归义坊起了一场火。」
  问题:
    - 跳跃了整整一年（贞观四年→贞观五年），无任何过渡
    - 读者毫无准备地发现时间前进了一整年
    - 中间缺失：贞观四年春夏秋冬发生了什么？（虽然Ch65-70补了一些，但叙事顺序被打乱）
  修复:
    - 添加明确的年号过渡句（如"一年过去了"）
    - 或调整年份标注消除跳越
```

### 8. Ch53内 vs Ch54内: 降俘抵达日期的内部矛盾

```
Ch53→Ch54: [档案日期矛盾]
  Ch53: 「三月中旬」降俘入城，沈知远存档写「贞观四年三月中旬，突厥降俘至长安」
  Ch54: 同日，沈知远翻阅昨日存档，看到「贞观四年正月二十，突厥降俘至长安」

    - 同一批降俘的抵达日期，出现了两个不同时间点
    - Ch53写三月中旬，Ch54内部文档写正月二十——相差近两个月
    - 可能意图：Ch53指大规模普通俘虏入城，Ch54档案指第一批贵族俘虏
    - 但文本未明确区分，读者容易困惑
  修复:
    - 在Ch54档案处加注释（如"那是第一批——颉利可汗的近支——早在正月就押到了"）
    - 或将Ch54内的日期统一为三月中旬
```

### 10. Ch52→Ch51: 事件顺序基本合理（已知重叠模板，但可接受）

```
Ch51→Ch52: [时间线合理性确认]
  Ch51: 沈知远读到李靖夜袭定襄的军报（颉利遁走）

  判定:

    - 叙事上两个章节都在正月，时间平行但不矛盾
    - ✅ 无需修复
```
