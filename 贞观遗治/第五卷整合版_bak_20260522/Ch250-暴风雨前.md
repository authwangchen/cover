# 第二百五十章 暴风雨前

天宝十四载，十一月初。

长安。

长安城一切如常。

东市西市照样开张。东市卖的是来自天下的货物——江南的丝绸、巴蜀的锦缎、河北的铁器、西域的玉石、南海的珍珠。西市胡商的摊位一个挨着一个，卖葡萄酒的、卖胡饼的、卖骆驼的。胡姬站在酒肆门口，用带着口音的汉语招客。有人在讨价还价，有人在说笑，有人在为一文钱争得面红耳赤。街道上人群来来往往，车马络绎不绝。马蹄踏在青石板路上，发出笃笃的声响，混杂着小贩的叫卖声和车轮碾过路面的吱呀声，汇成一片嘈杂的、生机勃勃的轰鸣。

花萼相辉楼里，玄宗正在听曲。梨园的弟子正在排练新谱的《霓裳羽衣曲》。曲声悠扬，从楼中飘出，飘到宫城外的坊间。有人驻足听了一会儿，然后继续赶路。风吹过楼角，檐下的铃铛叮叮当当地响着，和乐曲的旋律交织在一起，分不清哪个是曲子哪个是风。

华清宫的温泉池中，水温恰到好处。水汽升腾，在冬日的冷空气中凝结成白雾，弥漫在池面上。玄宗靠在池边，合着眼。杨贵妃将剥好的荔枝递到他嘴边。他微微张嘴，吃了。荔枝是快马从岭南送来的——换了三次马，跑了七天七夜。没有人问值不值。玄宗觉得值，那就值。

朝堂上最近最热门的话题是——杨国忠和安禄山之间的矛盾，以及安禄山到底会不会入朝。有人发话说安禄山会入朝。有人说不会。争论了几句，也就不了了之。大家更关心的，是明年春天的科举。有门路的已经在活动了，没门路的在埋头苦读。长安的酒楼里，到处都可以听到举子们在谈论经义和策论。没有人谈论边镇——边镇太远了，远到不像是真的。

没有人觉得有什么异常。

贞观六年，长安也是一片繁华。但那时的繁华是不同的——那时候长安城里的雪下得很大，沈知远穿着一件旧棉袍站在门下省廊下看雪。韩慎站在他旁边，说"今年的雪下得不是时候"。那时候的长安，街道上还能看到穿旧衣的人，还能看到在雪中踩着前人脚印走路的人。长安城也有灯火，但更安静——远处有狗吠，近处有更夫敲梆子的声音。

现在的长安不是那样的了。现在的长安灯火通明，彻夜不歇。东西两市周围新开了不知道多少家酒肆，每一家都在抢客。有人在花萼相辉楼下说笑——说宰相又在弹劾谁了，说那个姓安的胡人又给陛下送了多少东西，说秋天的柿子今年卖得特别贵。没有人想到，这些说笑中提到的那个姓安的胡人，此刻已经穿上了金甲，站在范阳的校场上。没有人想到，他面前的十五万大军，正在等待他的一声令下。

长安城中，没有人知道——在东北方向一千多里外，范阳城里，一场风暴正在无声地酝酿。

范阳的校场上，十五万大军已经集结完毕。在营帐之间穿梭的火把将整片天空映成了一种铁锈般的暗橙色。士兵们的甲胄在营火中反射着零星的光芒，马匹低鸣着，打着响鼻。十五万人的呼吸声在夜风中聚成一股低沉的气流，像大地本身在缓缓地呼吸。火把的光在风中跳动，照在每一张脸上，脸的轮廓在明暗之间不断切换，时而清晰，时而模糊。

安禄山骑着马，从一排一排的士兵面前经过。他穿着金甲——是他专门为这一天准备的，胸口的护心镜打磨得锃亮，上面映着跳动的火光。他的目光扫过每一张脸。没有人说话。空气里只有马匹偶尔打出的响鼻声和火把燃烧的噼啪声。他的马停在队伍的最前方——朝南。

他回头看了一眼范阳城。城楼上的旗帜在夜风中飘扬——不是朝廷的旗帜，是他自己的旗。旗上绣着一个字——"安"。那面旗在风中猎猎作响，像一只巨大的鸟展开翅膀，正欲飞起。

他转回头，看向南方。长安的方向。

天空是深蓝色的。没有月亮。星星在头顶铺开，密密麻麻，像一场即将落下的雪。他在马背上坐了很久，久到身后的副将们开始不安地交换目光。但他只是在看那些星星。他想——今夜过后，这些星星会不会记住范阳发生的事。

长安城的花萼相辉楼中，曲子还在继续。梨园的弟子们的衣袖在灯光下翻飞，像蝴蝶的翅膀。玄宗在曲声中微微睁开了眼，看了一眼窗外的夜空。月亮被云遮住了，天色不算太好。他看了一会儿，又合上了眼。

天宝十四载，十一月甲子日。

安禄山在范阳起兵。

以"诛杨国忠、清君侧"为名。

十五万大军在黎明前出发。马蹄踏碎地面的霜冻，留下深深的印痕。队伍像一条黑色的河流，无声地朝南流淌而去。范阳城头的那面绣着"安"字的旗，在晨风中飘扬了一会儿，然后被收了下来。城门在队伍全部出城之后缓缓合上，发出沉闷的声响，在空旷的黎明中传出去很远。

长春殿里，玄宗正在翻看奏章。有一份是安禄山送来的贺表——祝贺陛下圣体安康，祝贺贵妃千秋。他笑了笑，批了一个"阅"字，就放到了一边。他没有注意到那份贺表的落款日期——一个月前。一个月前的信，走了这么久才到长安。他也没有注意到，送贺表的人不是安禄山的亲信，而是一个他从未听说过的名字。

消息传到长安，需要至少七天。

这七天里，长安城的灯火还会亮着。东西市的摊位还会照样开张。胡姬还会站在酒肆门口招客。花萼相辉楼的曲子还会继续奏下去。

七天。

长安城里没有一个人知道还剩七天。
