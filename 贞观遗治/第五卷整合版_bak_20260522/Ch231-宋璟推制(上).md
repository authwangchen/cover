# 第二百三十一章 宋璟推制（上）

开元八年，春。

长安，崇文馆。

馆丞姓崔，做了十二年的馆丞。他每天要做的事情不多——管管藏书，理理旧档，安排几个校书郎的工作。崇文馆是大唐藏书最丰的地方，但也是最无人问津的地方。真正要紧的书在秘书省，在弘文馆。崇文馆里存的，大多是些陈年旧档——当年修史剩下的底稿，历年积压的案牍，还有一些不知道从哪里来的、连名字都叫不上的卷宗。

崔馆丞每日的工作，就是站在书架之间，看灰尘在光柱里浮动。

这一日，他打开了一间久未开启的库房。锁已经生锈了，钥匙拧了半天才转动——他不得不双手握着钥匙柄，额头上挣出了青筋，才听到锁簧弹开时那一声清脆的响声。门推开的一瞬间，一股陈年的气息迎面扑来——不是霉味，是纸和墨在漫长的静置中散发出的那种气味，干燥，微苦，像旧药铺里的味道。库房里堆着几十只木箱，有的已经开裂。墙角有一捆散落的卷宗，用麻绳捆着，麻绳已经朽了，轻轻一碰就断。

崔馆丞蹲下来，解开麻绳。

卷宗里是一份手抄本。封面没有题名，只有一行小字：

**"贞观遗制，以待后来。"**

崔馆丞愣了愣。他在崇文馆待了十二年，从来没听说过有这个东西。他翻开第一页，字迹工整，笔画端正。没有署名。但他认得这字——他在崇文馆见过沈知远留下的旧档。这个笔迹，和那些旧档上的字一模一样。

他翻了几页。越翻越慢。

他不是读不懂。他是读懂了，但不敢相信。兵制篇、官制篇、民制篇、储制篇、戒篇——五个篇章，四万余言。每一篇都写得清清楚楚，明明白白。不是空谈议论，是具体的制度设计。边将限任几年，兵权如何分割，地方军政如何分离——每一条都指向一个核心：权力不能集中。

崔馆丞站了起来。他捧着那卷遗制，走到窗边。窗外是长安的春天，柳絮飘飞。他把遗制放在窗台上，小心翼翼地翻到最后一页。

那一页上，有一行朱笔批注。

他看了很久。

然后他合上遗制，走出了库房。他没有把那卷遗制放回原处。他把它夹在腋下，穿过崇文馆的长廊，走向朱雀大街的方向。他的步子很快——快到他身边经过的小吏都侧目看了他一眼。一个做了十二年馆丞的人，从来没有走得这么快过。

朱雀大街，中书省办事厅。

宋璟正在批阅公文。

他是开元名相——或者说，是开元年间最严肃的宰相。他不笑，不怒，不徇私。凡是经过他手的公文，没有一件敷衍了事的。每一件都要逐字读过，逐条批注过，确认无误之后才会往下传。他在中书省的厅事里办公，厅事不大，案上堆满了待批的文书。窗外的阳光照进来，照在他花白的头发上。他已经六十岁了。

崔馆丞被拦在了厅外。

"宋相正在批文，不见客。"

崔馆丞站在厅外，手里捧着那卷遗制。他没有退。他站在那里，站了很久。久到门口的当值吏三次侧目看他，一次欲言又止。然后他开口了，声音不大，但很稳：

"请转告宋相——崇文馆旧档中，发现贞观年间沈知远遗卷一部，请宋相过目。"

当值吏进去了。过了一会儿，出来了。

"宋相说——进。"

崔馆丞走进去。宋璟抬头看他的第一眼——不是看他，是看他手里那卷东西。宋璟的目光落在遗制的封面上，落在那行小字上。他皱了一下眉头，不是不满，是辨认——他在确认自己有没有看错。

"贞观遗制？"

"是。"

"沈知远——"

"是。"

宋璟伸出手，没有说话。崔馆丞将遗制呈上去。宋璟接过来，低头看了封面上的那行字。

**"贞观遗制，以待后来。"**

他没有翻开。他先用手掌压了压卷面的厚度。然后他翻开了。

他看完了第一篇。兵制篇。

他抬起头，看了崔馆丞一眼——那一眼很短，然后他又低下了头。他继续看。看完了官制篇。看完了民制篇。看完了储制篇。一直看到戒篇。

戒篇的最后一页，那行朱笔批注。

宋璟的手停住了。

朱笔批注的内容是——**"边将兼统，国之贼也；胡将专兵，乱之本也。后世子孙，慎之戒之。"** 批注下面，是另一个字迹写的一行小字：

**"朕从卿言。"**

宋璟没有说话。他把遗制合上，放在自己的案上，然后抬头看着崔馆丞。他的表情没有变化。但他的手指——那是宋璟的习惯——他的右手指节在案上轻轻叩了两下。那是他思考时才会做的动作。

"这个，先放在我这里。"

"是。"

崔馆丞退了出去。

厅里只剩下宋璟一个人。他坐着，面前摊着那卷遗制。窗外有脚步声经过——是某个官员端着一摞公文走过去。脚步声越来越远，消失了。宋璟低头看着遗制的封面，伸出手，手指在封面上的那行字上划过。

"以待后来。"

他念了一遍。

后来的那个人，是他。
