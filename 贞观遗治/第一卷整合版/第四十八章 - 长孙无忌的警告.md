# 第四十八章 长孙无忌的警告

粮政透明的榜文在关中各县张贴了一个月后，长安城里的米价确实稳了一些。但沈知远知道，这只是开始。更大的阻力，来自那些被触动利益的人。他以为警告会来得晚一些，但没有。

那天傍晚，他从秘书省出来，一个穿戴整齐的小厮在门口等他，手里拿着一封请柬。请柬上没有署名，只写了一行字——"长孙府备薄酒，请沈校书郎过府一叙。"字迹端正，没有多余的话。

沈知远握着那张请柬在秘书省门口站了一会儿。他没有犹豫太久——长孙无忌的请柬不是能推的。他跟着小厮穿过几条坊巷，到了长孙府。这是他第二次走进这座宅子。第一次是房玄龄带他来的——那次他是房玄龄的后辈，坐在角落里，没有说话。这次他是自己走进来的。

长孙无忌在后堂等他。没有其他客人。桌上摆着几碟简单的菜，一壶温过的酒。长孙无忌坐在主位，看到沈知远进来，抬了抬手示意他坐下。沈知远坐下来。长孙无忌给他斟了一杯酒，动作从容——酒液在杯中微微晃动，映着头顶灯笼的光。

"你写的那份策论，我看了。"

沈知远的手指在杯沿上停了一下。他没有想到长孙无忌会对他说这件事。

"边将限任、粮政透明、府兵检核——三条都对。"长孙无忌端起自己的酒杯，没有喝，只是拿在手里转了转，"但都对的事情，不一定都要做。"

"——请长孙公明示。"

长孙无忌没有直接回答。他端起酒杯，慢慢喝了一口，放下。他放下杯子的动作很稳，没有一点多余的声响，像他说的每一句话一样，精确而克制。

"粮政透明——这个可以做。你把账目晒出来，百姓看到了，放心了——上下都好看。但边将限任和府兵检核——你动的是别人的根基。那些人不会跟你讲道理——他们会直接想办法让你消失。"

沈知远没有说话。长孙无忌的话和戴胄如出一辙，但分量不一样——戴胄说这话的时候是在提醒他，长孙无忌说这话的时候是在给他选路。

长孙无忌又给自己斟了一杯酒。酒液在灯光下泛着琥珀色的光泽。他的目光从酒杯上抬起来，落在沈知远脸上，很淡，但很沉。

"你做粮政就够了。把那件事做好，升官，活下去。另外两件——不要再碰了。"

他端起杯，喝了一口。没有再说话。沈知远坐在那里，知道这顿饭不是请他吃饭——是给他划了一条线。他端起自己面前那杯酒，喝了一口。酒是温的，微辣，顺着喉咙淌下去，在胃里烧成一小团火。

他站起来告退。长孙无忌没有起身送，只是坐在那里，端起酒杯又喝了一口。沈知远走出后堂，穿过回廊。夜风迎面吹来，把他刚才喝的酒意吹散了一些。他站在长孙府的大门外，抬头看了一眼夜空。冬天的星星很亮，一颗一颗钉在深蓝色的天幕上。他知道长孙无忌说的话是对的——做一件，活下来；做三件，死得快。

但他也知道，如果他现在停下来，那卷塞在墙缝里的遗策就永远不会有人看到。
