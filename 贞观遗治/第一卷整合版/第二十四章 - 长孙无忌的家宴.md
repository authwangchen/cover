# 第二十四章 长孙无忌的家宴

请帖是三天前送到的。

沈知远在秘书省值房里接到的。送帖的是长孙府的一个家仆——穿着干净的青布短褐，头发梳得整齐，态度恭敬但不卑微。他把一张烫金帖子放在沈知远的桌上，说了句"长孙府敬备薄酒，请沈正字光临"，然后后退一步，转身走了。脚步不快不慢，节奏匀称，一看就是训练过的。

沈知远拿起那张帖子，看了看。

帖子用的纸是上好的——不是秘书省用的那种粗麻纸，是细腻的宣纸，纸面光滑洁白，对着光能看到均匀的帘纹。上面的字写得端正，标准的楷书，笔画稳重，每一个字都端端正正地待在格子中央——"敬备薄酒，恭候光临。"落款是长孙无忌的名字，但没有盖章，没有官印，只有名字，素净的。

他看了两遍，把帖子折好，放进袖子里。

旁边的同值侧过头来，瞥了一眼，目光在帖子边角上停了一下，低声说了一句："长孙尚书的帖子？"

沈知远没有回答，把帖子往袖子里又塞了塞，只说了一句："有人带了一句。"

同值没有再问了。长孙无忌的宴请，在这座城里不是谁都能收到的。长孙无忌是长孙皇后的兄长，从龙功臣，尚书右仆射——朝堂上真正说一不二的人物之一。他的宴席上坐的都是五品以上的官员、六部尚书侍郎、以及少数被特意邀请的人物。一个正九品的校书郎出现在那样的宴席上，说出去都没有人信。

沈知远当然知道为什么。是房玄龄说了一句"带他见见世面"，长孙无忌便多备了一副碗筷。他只是一个附带的名字——不是因为他够资格，是因为有人提了他一句。他在心里记下了房玄龄的这份人情，也记下了自己的位置——他是被带去的，不是被请去的。这两者之间的区别，他在收到帖子的那一刻就已经想得很清楚了。

傍晚，他换了衣服。

说是换衣服，其实他没有太多可换的。他只有两身能穿出门的——一身是平时穿的旧布袍，袖口已经磨出了线头，膝盖处打了一块补丁，针脚有些歪，是韩慎补的。另一身是新一些的，料子也是粗布，但没有破洞，浆洗得干净，边角也整齐。他穿上了那身新些的，把袖口的线头剪掉，整了整衣领，又用湿布把鞋面上的灰擦了擦。做完这些，他出了门。

长孙府在永宁坊，靠近皇城，地段极好。他从崇仁坊走过去，穿过几条街道，天色在途中渐渐暗了。深秋的长安，天黑得比上月又早了一些，酉时刚过，街道上的光线就已经开始减弱了。走在路上，能看到各坊的坊门正在缓缓关闭——两个兵卒一人推一扇，木门合拢时发出沉闷的碰撞声。炊烟从墙头飘出来，在屋顶上方缓缓扩散，混着暮色，把整座长安城笼罩在一片淡灰色的雾气里。空气中有烧柴的气味，有炒菜的焦香，有人家门口点灯时火柴擦亮的硫磺味。

长孙府的大门比他见过的任何一座都宽。

门是朱红色的，宽约两丈有余。门上的铜钉一排一排，整整齐齐，每一颗都打磨得光亮，在灯笼的光线下泛着暗暗的金色。门口挂着两盏大灯笼，圆形的，用竹篾编成骨架，外面糊着红纱，里面燃着粗烛。烛光透出来，把门前的一大片空地照得通明——照着那两只蹲在大门两侧的石兽。石兽的底座被摸得发亮，青黑色的石面上泛着一层油润的光泽，像是被无数只手反复摩挲过，包了浆。

门口站着两个门房，穿着整齐的青色衣裳，腰间系着带子，站着笔直。看到沈知远走过来，一人上前一步，微微躬身——腰弯的幅度不深，但足够恭敬——问了一句："阁下是？"

"崇文馆沈知远。"

门房接过他递上的帖子，没有打开看，只是用两根手指捏着帖子边角，看了一眼封面的字迹——单是这个动作，就知道是见惯了各色来客的老手。然后他侧身让开，做了一个"请"的手势，道："沈正字请。"

沈知远迈过门槛，走进长孙府。

跨过门槛的那一刻，他能感觉到空气的变化——从街上的冷风变成了院子里的暖意。不是那种炉火烘出来的燥热，是一种慢悠悠的暖，像是整座院子本身就在散发一种温和的温度。空气里飘着一股淡淡的熏香味——不是浓烈的焚香，是一种清淡的、若有若无的香气，像是某种木料在慢燃中散发出来的，细细地渗在空气里。院子里的地面铺着平整的青砖，打扫得干干净净，砖缝之间没有一丝杂草，砖面平整得像是每天被人用抹布擦过。院子两侧种着几棵桂花树——十月的桂花已经开过了一季，枝头只剩下星星点点的残花，香气却还在空气中残留着，和熏香混在一起，形成了一种说不清道不明的气味。顺着廊檐下走过去，他看到廊柱之间挂着几盏风灯，灯罩里的蜡烛明明暗暗地跳动着。

宴席摆在正厅。

正厅比他想象的大。门口悬着一块匾，黑底金字，写着几个字，墨色深沉，笔力遒劲，他没有细看，随着引路的仆人走了进去。厅里摆了四桌，方桌，每桌坐八到十个人。桌上铺着干净的麻布，摆着碗、碟、杯和箸，都是素色的瓷器，没有纹饰——不是那种粗瓷，是质地细腻的白瓷，釉色均匀，对着光能透出淡淡的青色。他不知道这样的瓷器一只要多少钱，但肯定不便宜。不过他也不能完全确定这桌面的素雅是长孙无忌本人的趣味，还是府上管事的布置。

他扫了一眼厅里的人——大多不认识。几个穿着紫色官服的人坐在靠近主桌的位置，品级不低，神情坦然，一边说话一边饮酒，笑声低沉而从容。还有几个穿着绯色和绿色官服的坐在其他桌上，也在交谈，声音比紫衣官员那边稍高一些，气氛也更随和些。每个人面前都放着酒杯，有的已经空了，有的还是满的。

沈知远坐末席。

最靠门的位置，侧对着门。这个位置的好处是方便进出。坏处是上菜的小厮从他身边经过的时候，袍子的边会擦着他的肩膀过去，端菜的盘子从他头顶上方递过去的时候，碗底的热气会扑在他的脸上。他在坐下来之前就已经看清楚了——这个位置离权力中心最远，离门最近。他没有觉得不适。这很合理。一个正九品的校书郎坐在这样的宴席上，坐在这里是合适的。如果他被安排到主桌，那才是不合适的，那才值得警惕。

菜一道一道地上。

先是冷盘——切得整齐的肉脯，颜色深红，码放在素色瓷盘里，叠成整齐的扇形。旁边配了几碟腌菜——有切碎的芥菜，有泡萝卜，有腌制的蒜头，颜色深浅不一，码放得也很讲究。然后是热菜——有鱼，是清蒸的，鱼身上铺着细切的姜丝和葱段，鱼肉雪白，筷子夹下去的时候，肉从骨头上自然地分离。有羊肉，炖得很好，没有膻味，汤汁浓稠，呈酱色，面上浮着一层薄薄的油光，撒了一些茴香和葱段。有炖得烂熟的鸡——用砂锅端上来的，掀开盖子的时候，热气升腾起来，带着鸡肉和药材混合的香气，鸡已经炖得酥烂，用筷子一拨，肉就从骨头上分离开来。

仆人上菜时脚步轻快，端盘的手稳当，把菜放在桌上时没有发出一丝声响。倒酒的人也训练有素——从客人身后绕过来，手腕一转，酒就注满了杯子，不多不少，刚好八分满，而且没有一滴洒在桌面上。

沈知远没有怎么动筷。不是菜不好，是他不习惯在这种场合放开了吃。他是末席，是被人顺带叫来的，不是这里的主人。他的筷子在碗边停了几次，夹了一两片菜叶，慢慢嚼了，咽下去。席间有人劝酒，他推说自己不善饮，以茶代了——端起茶杯来喝了一口，茶水是温的，泡得恰到好处，不是苦的。

喝到一半的时候，有人提起了边镇的事。

说话的是一个穿着绯色官服的中年人，面色有些发红，已经喝了不少。他的声音不小，整桌人都能听到："突厥降俘安置在河曲，妥当不妥当？那些人刚放下刀，让他们住在边境上——万一哪天又乱了呢？"

"乱不了。"另一个人接话很快，语气笃定，像是在说一件确定无疑的事。"颉利已经被俘了，突厥散了。草原上已经没有能战的部落了。"

"未必。"第三个人接了一句。这人说话的声音低沉，像是压在喉咙里，不响亮，但内容很有分量。"安置得不好，迟早会出事。那些人在草原上打了一辈子仗，你让他们放下刀去放羊，他们放不惯。"

话题在席间传开了。有人同意安置在河曲的说法，认为这是分化瓦解突厥残余势力最好的方式。有人反对，认为应该把他们打散之后分到各州去，不能让他们聚在一起。还有人提出应该把这些俘虏都迁到岭南去，远离边境，隔断他们和草原的联系。每个人都有自己的观点，但每条观点的背后都没有实际的第一手经验——都是坐在长安的厅堂里用推测和想象来补全的。

争论的声音不高，但很多。每一桌都在讨论这件事。

沈知远坐在末席，低头喝茶，没有说话。他听着那些争论，把每一个人的观点和用词记在心里。有人说起河曲的时候语气轻描淡写，像是在说一个很远的地方。有人激烈反对的时候，用力放下酒杯，杯中暗红色的液体晃动了几下，洒了几滴在桌上。

他没有开口。

长孙无忌坐在主桌，一直没有开口。他穿着一件深色的便服，不是官服——料子虽好，色调却很低调，既不惹眼也不太暗淡，恰到好处地在人群中既不突出也不被忽略。他手里端着一只酒杯，但几乎不喝，只是偶尔端起来，在鼻尖下面晃一晃，像是在借着酒气听大家说话。他坐在那里，像一尊不动声色的大佛，目光缓缓地扫过厅中的每一张脸，偶尔在一些人身上多停一瞬。

等别人说得差不多了，在争论声渐渐低落下去的一个空档里，他说了一句话。

"朝廷自有安排。"

声音不大。但整桌人都安静了。

不是因为他说话的内容——是因为他开口了。他一开口，那一桌的声音就停了。那一桌的安静像水波一样扩散开来，旁边的几桌也感觉到了异样，声音渐渐小了。最后整个正厅的人都安静下来，目光转向主桌。长孙无忌没有看任何人，端起了酒杯，喝了一口。酒杯放下的时候，杯底落在桌面上的声音很轻，但在这个突然安静下来的厅里，那一声轻响像是放大了十倍，每个人都听到了。

然后话题转了。

有人开始谈论今年的科考，有人开始评价某位新进官员的策论，有人开始讲一个关于某位老臣的笑话。笑声重新在厅里响起来，觥筹交错，杯盘碰撞，又恢复了之前的喧嚣。但沈知远注意到——再也没有人提起河曲的事了。

散席的时候，已经过了亥时。

客人们陆续告退，三三两两地走出长孙府。有人在门口互相作揖道别，说着"改日再聚"之类的客套话。有人的马车已经等在门口了，车夫在旁边提着灯笼等着。车轮碾压在青石路上，咔咔作响，伴着马铃声渐行渐远。

沈知远走在最后。他坐在末席，出门自然在最后。等他走出长孙府大门的时候，夜风迎面扑来，凉的，带着很深的秋意。他在门口站了一会儿，深深地吸了一口冷空气，让那股从宴席上带出来的暖意从身体里退掉。身上的衣服还带着宴席上的酒气、肉味和熏香——那些气味混杂在一起，随着夜风的吹拂，一点一点地散开。他感觉到冷意从衣领和袖口渗进来，让皮肤收紧。

他沿着街道往回走。

夜里的长安很安静。坊门已经关了，但长孙府在永宁坊里，不需要出坊就能走回他住的地方——出了永宁坊，穿过两条无人的街巷，就是崇仁坊。两侧的高墙挡住了大部分的风，走在巷子里，能听到自己的脚步声在两侧墙壁之间来反弹，清脆的，一步一步。头顶是一线天，能看到深蓝色的夜空和几颗星星。

走回小院的时候，远远就看到韩慎坐在门槛上。

韩慎还没有睡。他坐在门槛上，手里没有拿东西，就那么坐着，在黑暗中。看到沈知远推门进来，他没有站起来，只是抬头看了他一眼。秋天的月光照在院子里，把韩慎的影子拉得很长。

"回来了？"

"嗯。"

韩慎的目光在沈知远身上上下打量了一下——不是看他有没有受伤，是看他的表情，看他的姿态。韩慎坐在黑暗中，月光照在他的侧脸上，照出脸上深深浅浅的皱纹。

"今天去了哪里？"

"长孙府。"

韩慎没有立刻说话。他沉默了一会儿，像是把这三个字放在嘴里嚼了嚼，品了品滋味。

"长孙无忌？"

"嗯。"

韩慎在黑暗中咂了一下嘴——那是他在思考的下意识动作。风从巷子里灌进来，吹起韩慎的衣角，他用手按了按。

"那个人请你吃饭，不是白吃的。"

沈知远站在院子里。夜风吹着他的衣摆，衣服上还沾着宴席上的气味。"我知道。"他说。

韩慎没有再多说什么。他站起来，拍了拍袍子上的灰，走进里屋去了。他的脚步声在里屋响了几声，然后床板发出一声轻响——他躺下了。

沈知远站在院子里，没有立刻进去。他坐在韩慎刚才坐过的门槛上。月亮挂在墙头，半圆的。他在想着宴席上长孙无忌说的那句话——"朝廷自有安排。"那句话是在回应席间那些人的争论，在给那些高谈阔论做了总结。沈知远想了一会儿，发现自己绕不开这个意思：那句话本身没有给出任何答案。没有方略，没有时间，没有具体措施。它唯一的功能是结束讨论。它的内容等于什么都没说——但他说出来之后，就没有人再敢问了。

这就是权力的样子。不在于你说了什么，在于你开口的时候，别人都闭上了嘴。

他坐了一会儿，站起来，走进屋里，关上了门。

第二天一大早，他去了秘书省。

坐到桌前，铺开纸，开始校书。笔尖在纸上游走，一行一行，很稳。但脑子里的画面是昨晚的——紫色的官服在烛光里晃动、酒杯碰撞的清脆声响，和那些关于边镇的高谈阔论。还有长孙无忌那句"朝廷自有安排"。

他放下笔，从架子上抽出一卷书，摊开。那是前几天他放进去的关于河曲地理的旧档。窗外，早晨的阳光照在纸页上，那些字在光线里很清晰。他低着头，手指在纸页上慢慢移动，把每一行关于地形、水源、道路的信息都读进去，记在心里。

书页在他面前摊开着。河曲。他在地图上看到过这个地方——黄河在这里拐了一个大弯，形成了一个半包围的河套区域。水草丰美，地势开阔，适合放牧，但无险可守。冬天冷，风大，雪厚。

他合上书，看了一会儿窗外。院子里那棵梧桐树上的叶子已经落得差不多了，只剩下光秃秃的枝干，在天空下像一幅用墨线画出来的骨架图。

他继续校书，没有再想河曲的事。但他心里知道——他还会再想起它的。
