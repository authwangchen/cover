# 第四十四章 私人笔记

策论留中备览的消息传出来三天后，一纸宣召将他唤入了甘露殿。太宗没有提那三条建议——只问了他一个问题：“你写的那些，你自己信吗？”

沈知远答了四个字：“臣信其理。”

太宗没有追问。但也没有说信。他只是看了他一眼，那一眼里有审视，有考量，但也有一些别的东西——像是把一个人的名字记在了心里，然后让他走了。

从甘露殿回来之后，沈知远开始认真写一份他真正想写的策论。

不是删改过的，不是适合现在发表的——是他真正想写的那一份。他把自己关在小院里，请了三天假。韩慎没有问他为什么请假——他只是每天早上在灶台上放一壶热水和两个饼，然后出门去巷口坐着。他知道沈知远需要一个人待着。

沈知远坐在桌前，铺开纸，拿起笔。这一次他没有斟酌措辞。没有想"这句话递上去谁会反对"。没有把"当改"改成"可议"。他写的是他在崇文馆旧档里看到的那些数字，在京兆府文书里发现的那笔对不上的账，在渭河堤上亲眼见到的那些被抽走的粮食。

他写他真正想写的东西——不是给贞观三年的皇帝看的。是留给以后的人看的。他也不知道这些字将来谁会看到——也许谁也不会。但他还是写了。

他写边将久任的根源，不在边将本身，在朝廷对边境的控制力逐年衰减。他写府兵制的裂隙，不在兵员不足，在均田制从根上开始松动——没有田的府兵不是府兵，是穿着军装的流民。他写粮政的漏洞，不在仓曹的账目不清，在从地方到中央的每一条运输线上都有一个可以伸手的缝隙，这些缝隙被制度默许了太久，已经变成了制度的一部分。

他写得很顺。那些在脑子里存了一年多的东西终于找到一个出口，流出来的时候几乎不需要停顿。笔尖在纸上移动的声音在安静的屋子里沙沙地响。从早晨写到傍晚，中间只停下来喝了两口水。

写完最后一个字的时候，天已经黑了。他放下笔，把纸页一张一张地叠好。没有再改。他知道这份策论不可能在这个时代递上去。但如果有一天——一百年后、两百年后——有人翻到这份手稿，希望那个人能看懂。他把纸页用油纸包好，塞进墙缝那块松动的砖后面。和从崇文馆带回来的那卷卷轴放在一起。

他站起来，推开门。韩慎坐在门槛上，背对着门，手里握着一卷旧纸。听到门响，他没有回头。

"——写完了？"

"——写完了。"

韩慎站起来，拍了拍袍子上的灰。月光照在他的白发上，泛着一层柔和的光。他没有问写了什么，只是转身走进灶房："饭还热着。"

沈知远在门槛上坐下来。夜风吹过来，冷的，但院子里没有风的那一小片地方，月光照在地上，像一层薄薄的水。他坐在那里，看着月亮从东边升起来，慢慢地爬过院墙，爬上枣树的枝头。他知道他今天写的东西可能永远不会被人看到。但至少——有人写过了。
