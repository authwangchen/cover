# 第十七章 粮仓暗账

九月末，渭河堤修完了。

沈知远回到秘书省继续校书。值房里的光景和走之前一样——桌上堆着未校完的书卷，砚台里的残墨已经干透了，结成一块深黑色的硬壳。他坐下来，把墨重新研开，墨条在砚台上转圈，发出均匀的摩擦声。墨香在安静的空气里散开，淡淡的，像记忆里某种熟悉的气味。

他翻开之前校到一半的那卷书，打算接上。

上午无事。他坐在桌前，眼睛看着书卷上的墨字，手握着笔。时间很安静，像一池静止的水，只有偶尔翻动纸页的声音打破它。他校了一卷，又校了一卷。没有人来打扰他。值房里和他一起当值的，是一个姓谢的老吏，头发花白，整天不说一句话，只是埋头做事。

快到午时的时候，一个人的出现打破了这种安静。

戴胄。

戴胄走进来的时候，沈知远没有马上认出他——他很少见到戴胄本人，只在几次文书的署名上看到过这个名字。但那个人走进来的步态和神情，让他一下子就知道了来者是谁。

不疾不徐，目光平视，手里拿着一叠文书。

他站在沈知远桌前，把那叠文书放在桌上。纸落在桌面上，发出一声轻响——不大，但沈知远觉得那声音在安静的值房里格外清晰。

"渭河堤的粮账，你经手过多少。"

沈知远心里微微一动。

他抬头看戴胄。戴胄没有看他，目光落在窗外。窗外的天是灰白的，没有什么好看的，但戴胄就那么看着窗外，像是在等他回答。

"不多。"沈知远说。

"那就好。"

戴胄说完这句话，拿起文书，转身走了。他的脚步声在廊道里渐渐远去，从清晰变得模糊，然后彻底消失了。

沈知远坐在那里，没有动。

他听着那个脚步声走远，直到完全听不见。值房里的光线从门外照进来，落在地面上，像一块白色的布。他看着那块光，心里有一种说不清的感觉。

戴胄不是来问他的。

是来提醒他的。

有人在查粮仓的账。而那本记在他心里的账——那些数字、那些名字、那些日期——此刻比任何时候都沉。

他没有去想为什么戴胄会来提醒他。也许只是出于一个老吏的本能，看出他心里有事。也许是一场试探。也许是别的什么原因。他坐在那里，把前因后果在脑子里过了一遍，没有得出结论。

他站起来。走到书架前，目光扫过那些书脊。他的手没有去拿任何一本书，只是站在那里，让目光从一卷一卷书脊上滑过去。

在渭河堤上看到的那些事，那个链条——从仓曹到押运到司账——只在渭河的那个链条上发生吗？还是同样的链条，在其他地方也在转？

他走到仓曹的旧档架前。

仓曹的卷宗不归秘书省管，但有一部分旧档——贞观元年以前的——因为移交手续不全，暂时存放在秘书省的偏房里。这个信息是他刚来那天翻书目时顺手看到的，当时没有放在心上。现在他想起来了。

偏房的门是锁着的。他去找管钥匙的老吏，说自己校书需要查一些旧年度的土地统计数据。老吏看了他一眼，从腰间的钥匙串上卸下一把铜钥匙递给他，什么也没说。

他拿着钥匙走到偏房门口。铜钥匙插入铁锁的孔里，转了一下——咔嗒一声，锁开了。他推开门，一股陈旧的空气迎面而来——纸张、灰尘、木头和潮气的混合气味，像一口被封闭了很久的枯井。

偏房很小，没有窗，只能靠门口透进来的光照明。靠墙摆着几排木架，架上堆着一卷一卷没有整理的文书，捆着发黄的麻绳。灰尘很厚，他踩在地面上，扬起了一小片灰尘，在光线里漂浮。

他走到靠里的那排架子前，蹲下来，开始翻。

他没有目的地翻。他只是想看看那些旧档里有什么。一卷，两卷，三卷。麻绳解开又系上。他的手在纸页间穿梭，那些纸张在他指下发出干燥的沙沙声。

翻到第四卷的时候，他的手停住了。

贞观元年腊月。

某仓出粮若干。后面跟着签收人的名字——当时的仓曹参军。签名和花押，格式齐全。他放下这页，拿起了另一样东西——三天前他在秘书省整理过的一份文书。他把两份文书放在一起，对比上面的签名和花押。

笔迹一模一样。

他看了三遍。

每一遍都告诉他同一件事：那签名不是模仿的，也不是偶然相像——是同一个人的笔迹。字的起笔、收笔、转折、力度——全完一样。一模一样。

但那个仓曹参军在贞观元年十一月已经死了。他翻过前几页的死亡记录，黑白分明地记着：某年某月某日卒。他不放心，又往前翻了几页，从另一份公文里找到了一条佐证——那个参军的职位在贞观元年腊月之前就已经由别人接替了，接替的公文上有吏部的印章和日期。

一个人死了三年，他的笔迹又出现了。

他坐在地上，背靠着木架的立柱。偏房里很暗，只有门口那一片光。他把两份文书并排放在膝盖上，低着头看了很久。膝盖上的纸冰凉，透过单薄的布料，能感觉到纸的凉意渗进皮肤里。

他把那页旧档轻轻放了回去。

他花了整整两个时辰来排列那些文书。

不是按年份排——是按签名人排。他把同一人签名的文书堆成一叠，然后再按时间顺序把每一叠排开。他把那几十份文书分成了七叠，对应七个不同的签收人。每一叠他都从头翻到尾，仔细比对每一个字的起笔、收笔和转折，不放过任何一个细节。

翻到第三叠的时候，他停了下来。

那叠文书属于一个叫孙令言的仓曹佐史。前五份的签名笔迹流畅自然，字的间距和力度都很一致——是一个人多年不变的习惯。但从第六份开始，签名变了。不是那种人老了手抖的轻微变化，也不是墨色浓淡造成的差异——是换了一个人写的。

笔迹几乎一模一样。但有一个细节不一样。

原人写"言"字，最后一笔会往上勾一下，像是一个不自觉的小习惯。模仿的人模仿得很像，但那个勾，他忘了写。

他又回头翻了翻其他几叠，找出了类似的问题。不止一处。他在每一处做了标记——不是写在纸上，是用指甲在页角轻轻压了一下，留下一个几乎看不见的痕迹。这个痕迹只有他自己知道在哪里。

他把那几份有问题的文书抽出来，单独放在一边。但很快又改变了主意。他把它们放回了原处。让它们留在原处，比带在身上更安全。他只是记住了它们的编号和位置。

然后把其余的文件重新叠好，捆上麻绳，放回架子上原来的位置。他把一切恢复成他进来时的样子——灰尘的分布、卷宗的顺序、麻绳的系法——一切都被小心翼翼地复原了。

他站起来，拍了拍膝盖上的灰。在偏房里站得太久，站起来的时候腿有些发麻。他扶着架子站了一会儿，等腿上的麻木退去。

然后把钥匙还给了老吏。

老吏接过钥匙，没有看他，也没有问他在里面找到了什么。老吏只是把钥匙挂回了腰间的那串铜匙上，在叮当的轻响中，继续低头做他自己的事。

沈知远回到桌前，坐下。他面前的砚台里，墨已经研好了，乌黑的，在午后的光线里泛着微微的光。他拿起笔，蘸了墨，继续校那一卷没校完的书。

他知道那些旧档里的数字会一直留在那里，等着有人去发现。

而他只是最早到的那个人。
