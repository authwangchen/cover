# 第十九章 韩慎的告诫

深秋。天凉透了。

院子里的槐树已经落尽了叶子，光秃秃的枝丫伸向灰白的天空，像一具被剥尽了血肉的骨架。地上积了一层落叶，风一吹就哗啦啦地滚动，碰到墙角就停住了，挤成一堆焦褐色的碎屑。

韩慎病了一场。

不是很大的病——就是咳嗽。但拖了很久。一开始只是夜里咳几声，谁都没当回事。过了几天，他白天也开始咳了，而且越咳越厉害。那种咳法不一样——不是清嗓子那种，是从肺里翻上来的，沉沉的，像有东西堵在喉咙口，怎么都咳不干净。

沈知远注意到的时候，韩慎已经咳了好几天了。他自己不说，每天还是照常起来，去院子里洗漱，去灶前烧水。但他走路的时候会扶一下墙——很短暂的一下，像是忽然手边需要找一个支撑。沈知远看到了，没有问。他知道问了也没用。像韩慎这样的人，你问他好没好，他永远说好了。

但夜里韩慎睡不好。咳嗽声穿过薄薄的板壁传过来，一阵一阵的，有时候半夜醒来能咳上一刻钟。沈知远躺在自己的床上，听着那个声音，睡不着。黑暗里，那些咳嗽声像有人在远处敲一块朽木，咚咚的，闷，没有回音。

有一天早上，韩慎坐在床边，咳完之后用手背擦了一下嘴角。沈知远看到手背上有血迹——淡淡的，混在唾液里，像把一滴红墨水滴进了一杯浊水里。

沈知远说："我去请大夫。"

韩慎说："不用。"

沈知远没有再跟他争。他穿上外袍，揣上钱袋，走出了院子。

东市的药铺在城东南角。他穿过几条巷子和一座桥，走了小半个时辰才到。街道两旁的铺子都开门了，有卖布的，有卖铁的，有卖饼的。他穿过人群，走到那家药铺门口。

药铺不大，门口挂着一块褪色的木招牌，上面写着"济生堂"三个字。屋里弥漫着草药的气味，干燥的、带着苦味的、浓得几乎化不开的气息。柜台上铺着一层灰褐色的药渣，厚厚的一层，踩上去软软的。柜台后面站着一个老伙计，戴着顶旧布帽，正在用小秤称药。

沈知远把韩慎的方子放在柜台上。

老伙计拿起来看了看，眯着眼，把方子对着窗口的光照了照。窗外的天光透过蒙了一层灰的窗纸射进来，落在方纸上。老伙计看了一会儿，把方子放下，说了一句：

"这副药不便宜。"

沈知远没有说话。他从袖子里掏出刚领到的一个月俸钱，放在柜台上。铜钱碰到木板，发出一声清脆的碰撞声。他数都没数，就那么一捧放在那里。

老伙计看了那堆铜钱一眼，又看了沈知远一眼。他没有再多说什么，转过身去抓药了。他拉开身后一个接一个的小抽屉，从每个里面抓出一点东西，放到小秤上称一称，然后倒在柜台上的药纸上。药材的干燥气味随着他的动作飘散开来，当归、甘草、陈皮、半夏——每一种都有自己独特的气味，混在一起变成了一种浓郁而苦涩的底味。

沈知远站在柜台前等着。药铺里很安静，只有秤砣碰在秤盘上的叮当声和老伙计偶尔的咳嗽声。

药抓好之后，老伙计用麻绳把纸包捆好，递给他。

"三碗水煎成一碗。"

沈知远接过药包，又把方子收好。转身走出药铺。外面的阳光比刚才亮了一些，但依然是那种深秋的阳光——明亮，但不暖和。光照在街道上，拉出长长的影子，人们的影子交错着流过青石板路面。

他走回住处，把药放在灶台上。把泥炉子搬到灶前，添了水，点着了火。火苗从炉口窜上来，舔着锅底，发出噗噗的声响。他把药材倒进砂锅，盖上盖子，蹲在炉子旁边守着。

水开了之后，他把火调小了一些，让药汤慢慢熬。药香从锅盖的缝隙里溢出来，混着水汽在屋子里弥漫——苦苦的，涩涩的，和平时煮粥的气味完全不同。他在旁边蹲了一会儿，看着锅盖边缘冒出的白气和跳动的火苗。

小半个时辰后，他把药汤倒进碗里。褐色的药汤，滚烫的，表面还浮着细小的药渣。他端起来，烫手，用布垫着，走进韩慎的屋子。

韩慎躺在床上，闭着眼，盖着一张打了补丁的旧棉被。他的脸色不太好，皱纹在昏暗的光线里显得更深了，嘴唇的颜色也不对——不是那种健康的红，而是一种近于灰白的颜色，像冬天冻过的树叶。他的呼吸不太均匀，有一搭没一搭的。

"义父，药。"

韩慎睁开眼。他的眼睛在昏暗里显得很亮，浑浊而亮。他看了看那碗药，又看了看沈知远。他的目光像是先落在药碗上，确认了那是什么，然后才移到沈知远的脸上。

"你自己喝了吗。"

"喝了。"

韩慎没有追问。他用手撑着身体慢慢坐起来。坐起来的时候呼吸变得急促了一些，咳了两声，用手背掩住嘴。等咳嗽平息了，他接过药碗，端起来，慢慢地喝。

沈知远坐在旁边的矮凳上，没有开口。韩慎喝得很慢，一小口一小口地喝，每一口都在嘴里含一会儿才咽下去。药汤的热气腾起来，模糊了他的脸。

药喝完了。韩慎把空碗放回床头。他坐了一会儿，像是在等药力在身体里慢慢散开。然后他又躺了下去，闭上眼。

沈知远站起来，准备拿走空碗。

韩慎睁开眼，开口了。

"我以前在秘书省的时候，有一个同僚。隋朝的事。"

沈知远重新坐下来。屋里的光线更暗了一些。他把碗放回床头，坐在矮凳上，安静地听。

"那人姓张。管粮仓的。"

韩慎的声音很轻，比平时小很多，像一个被磨损了太久的零件，发出的声音断断续续。

"有一年灾。他往上报了缺粮，上面没理。他又报，还是没理。"

他停顿了一下。沈知远看到他的目光定在屋顶的某处，像在看很远的地方。

"第三次他没报——他把自己那份口粮分出去了。分了三个月。后来饿死了。"

韩慎说完这个故事，闭上了眼睛。

屋里安静下来。安静得像那间药铺里弥漫的草药味，像那锅熬干了水的药渣。只有韩慎不太均匀的呼吸声，像风穿过开裂的板壁，发出微微的嘶响。

沈知远坐在床边，没有动。他把两只手放在膝盖上，坐得很直。他没有抬头去看韩慎，也没有说话。他只是坐在那里，让那句话在空气里慢慢落定，像一枚石子沉入井底。

过了一会儿，韩慎又开口了。声音小，但字字清晰。

"穿官衣的人，不可轻信。"

沈知远抬起头，看了韩慎一眼。韩慎的眼睛还是闭着的。他的嘴唇微微动着，像是还想说什么，但最终没有说出来。

沈知远没有说话。他站起来，把空碗收起来，端出屋去。

走到院子里，他放下碗，站在院中央。

外面已经全黑了。天上的星星很密，密密地铺满了整个夜空。没有月亮，星光就显得格外明亮。那些星星的光落在院子里，给地面镀上了一层淡淡的、几乎不可见的银色。他站在那里，感受着夜风吹在脸上的凉意，和身后屋里透出来的微弱灯光。

风吹过来，冷的，像一把细密的刀片刮过裸露的皮肤。院子里有一棵半枯的枣树，光秃秃的枝条在风里微微晃动，影子在墙面上摇来摇去。

他想着韩慎说的那句话——穿官衣的人，不可轻信。

他不确定韩慎说的是不是也包括他自己。他现在也穿着官衣，虽然只是从九品——一个在朝堂上连站的位置都没有的品级——但他已经在体制里了。他每天穿的是官服，吃的是官俸，走进的是官署。他已经是这个体系的一部分了。

他也想起了那个饿死的张姓粮仓吏。

那个人也是穿官衣的。他在自己的位置上死了。没有人记得他的名字，没有人知道他做过什么。只有韩慎还记得他，记得他往上报了三次，记得他把自己的口粮分出去了，记得他是怎么死的。

沈知远在院里站了很久。

星光很细，很冷。他仰起头，看着那些密布在夜空中的星星。那些星星跟他在洛阳城外逃荒时看到的是一样的。那时候他躺在干裂的地上，头顶的星星也是这样密，这样冷。那时候他不知道自己能不能活到第二天。他只是躺着，看着那些星星，等着天亮。

现在他站在一个有屋顶的院子里，穿着官衣，还有一碗热药可以送给生病的人。

他想，那个姓张的粮仓吏做的那些事——往上报不用别人的口粮，用自己的口粮去救别人——也许不是傻。是因为他和他的那些粮食之间，只有他自己的命那么薄的一层关系。粮食不是他的。但命是他的。

他转回屋去。

韩慎已经睡着了。呼吸平稳了一些，比白天均匀。沈知远站在床边看了一会儿，把被子往上拉了拉——棉被下露出韩慎的手，手指枯瘦，骨节突出，指甲泛着不健康的灰白色。他把那只手塞回被子里，然后转身走出屋去。

他回到自己的屋子，没有点灯。在黑暗里坐了一会儿，然后躺下。

他没有睡着。他听着隔壁传来的咳嗽声——比前几天少了一些，但偶尔还是会咳两下。他在黑暗里睁着眼睛，想着那个姓张的人。想着那三次往上报告都没有得到回应的经历。想着他最后用自己的口粮去分给别人，然后自己饿死了。

那些被那个人救活的人，应该也不知道他的名字。

沈知远翻了一个身，把被子裹紧了一些。

秋夜的院子很安静。风从墙缝里钻进来，带着干枯树叶的气味和远处某户人家烧柴的烟味。他闭上眼睛。

明天他还要去秘书省校书。

校书的时候，他可能会在旧档里再看到什么。可能不会。但他知道，那些账还会在那里，等某个人去看它们。
