# 第三十三章 房玄龄的功课

冬天渐渐深了。秘书省的日子大多数时候是安静的——研墨，铺纸，校书，周而复始。沈知远坐在值房里，窗外偶尔传来风吹枯枝的声音，和远处街市上模糊的人声。那卷从崇文馆带回来的卷轴，他已经看完了。里面没有他预想中的惊天秘密——只是一份旧档案，记录了武德年间到贞观初年的几桩人事调动。但读完之后，他在窗前坐了很久。

有些事不是写在明面上的。那份调动名单的格式本身就在告诉他一件事：有一只看不见的手，在朝堂之下悄悄调整着一些人的位置，幅度极小，每一次都像是正常的人事安排，但放在一起看——那些被调动的人，几乎都是同一类人。

他没有把这些写在任何地方。他把卷轴重新捆好，打算下次去崇文馆时还回去。

几天后，房玄龄把他叫到了政事堂。

不是吃饭——是批文书。沈知远到的时候，房玄龄正坐在案后，面前摊着一幅地图——长城沿线的边防图。地图很大，几乎铺满了整张案面，纸张已经泛黄，边角卷起。山川河流用墨线勾勒，城塞关隘用朱砂圈出——从凉州到幽州，沿着长城蜿蜒的弧线，散落着十几个朱红色的圆圈。房玄龄没有抬头。他的手指沿着地图上的长城线从西向东缓缓滑过——从凉州滑到甘州，滑过肃州、灵州、夏州，一路向东，直到幽州。

“从凉州到幽州，大唐在边境上设了九个都督府。每个都督府管几个州的军事。你猜——这些都督的任期是多久？”

沈知远的目光跟着房玄龄的手指走了一遍。他在秘书省看过这些都督府的军册——每个人的名字、到任年份、出身背景——心里已经大体有数。

“——没有定例。有的三年，有的五年，有的十来年了。”

“对。”房玄龄抬起头。他的眼睛在午后的光线下显得有些疲惫——眼角的皱纹比去年深了一些。“凉州都督李大亮，贞观元年到任，到现在快三年了。幽州都督——从武德年间就一直在任上。你知道为什么？”

“——因为没人愿意换？”

“不是没人愿意换，是不敢换。”房玄龄的手指用力在地图上点了一下，“幽州北接突厥，东临契丹。换一个不熟悉边情的人去——万一出事，谁也担不起。”

沈知远明白了。那不是制度的问题——是现实的选择。在太平年月你可以从容地安排轮换，但在边境上，一着不慎就是战争。没有人愿意为"轮换"这个制度付出战争的代价。房玄龄看了他一眼——那一眼不是在考校他，而是一种更接近于"你说到了关键处"的认可。他站起来，走到窗边，背对着沈知远，沉默了一会儿。然后他开口了，声音比刚才低了一些：“我去年在整理奏章时，发现一件怪事。幽州都督每年的边防奏报——内容几乎一模一样。”他转过身来。阳光从他背后照过来，让他的面容半隐在阴影里。“你明白我的意思吗？”

沈知远的手指收紧了。奏报内容几乎一模一样——三年的边防奏报，用词有变化，但说的都是同一句话：没问题。

“——奏报是抄的？”

“——没有证据。”房玄龄的声音不带任何情绪，“但三年用同样的措辞说'边患已平，防务牢固'——你觉得，真的牢固吗？”

屋子里安静了片刻。窗外有小吏的脚步声由远及近，又由近及远。房玄龄走回案前，没有继续这个话题。他从案上拿起另一卷文书递过来：“你看看这个。是贞观元年的灾情奏报。当时的处置办法——你看了，有什么想法，写给我。”

沈知远接过来。纸页已经泛黄了，边角起了毛，但字迹还很清楚。上面的批注他认得——是房玄龄的笔迹。字很稳，不急不慢。他在那些批注里看到了一些他没有想到的东西——不是简单的准或不准，而是具体的调整意见：为什么减了三成而不是五成，为什么先拨粮而不是先免税。每一条都有原因。

他小心地把那卷文书折好收进怀里，走出政事堂。回到值房，他坐下来铺开纸，开始读那份奏报。读完之后他没有立刻写。他把那卷文书又翻了一遍，然后闭上眼，在脑子里过了一下贞观元年的处置之理——比他想象的更务实、更保守、也更谨慎。他睁开眼，拿起笔开始写。

写完之后，他没有立刻送回去。他把那卷文书和边防图的事放在一起想了一会儿。幽州都督的奏报是抄的，这件事房玄龄知道，但选择了不声张——不是不作为，而是在等。等一个合适的时机，或者等一个合适的人。沈知远把笔放下。窗外天已经暗下来了。他站起来，把那卷文书收好，披上外衣走出值房。走廊里有人在走动，他低着头让开路，没有和任何人交换目光。但他知道，房玄龄今天给他看的那些东西——地图、奏报、批注——都不是随便选的。

他在寒冬的长安城里走着，脑子里反复转着那些地图上的朱红色圆圈。从凉州到幽州，漫长的防线像一根勒在手指上的线——不是今天会断，但也不远了。
