# 第二章 破庙与老书吏

沈知远盯着那团黑影，喉咙发紧。

他想站起来，但腿软得像面条。

破庙外传来脚步声。

很轻，但在这死寂的破庙里，清晰得像敲鼓。

一个老人出现在门口。

六十多岁，头发花白，穿着洗得发白的旧袍，手里提着个破篮子。

老人看见沈知远，愣了一下。

"醒了？"

声音沙哑，但不冷。

沈知远点头，发现自己连说话的力气都没有。

老人走进来，把篮子放在地上，从里面拿出一个粗面饼子，递给他。

"吃吧。"

沈知远接过饼子，手在抖。

他咬了一口。

硬，糙，咽下去的时候刮得喉咙疼。

但他吃得很快，像怕被人抢走。

老人看着他吃，没说话。

等沈知远吃完，老人才开口：

"老朽姓韩，名慎。曾是隋秘书省小吏。"

"这破庙，是老朽栖身之所。"

"你……"韩慎顿了顿，"你是从哪来的？"

沈知远张了张嘴。

他能说什么？

说他是后世之人？

说他知道大唐将亡于藩镇？

说他知道贞观盛世之后是武周革命？

他低下头："学生……不记得了。"

"只记得……姓沈。"

韩慎看了他很久。

最后叹了口气：

"罢了。这世道，记不得也好。"

"你若无处可去，便留下吧。"

"老朽无子，你……便当是义子。"

沈知远抬起头。

韩慎的眼里有种东西。

不是怜悯。

是某种更复杂的东西——像是见过太多生死，已经麻木，却又忍不住伸手。

沈知远跪下，磕了三个头。

"义父。"

韩慎没说话，只是拍了拍他的肩。

那只手很轻，很暖。
