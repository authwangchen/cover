# 第一百九十五章 沉默

永徽二年，春。

沈最后一次站在朝会上。

不是作为记录者——他没有记录的工作了。他只是去站一站。因为他还有朝参的资格。朝参资格没有取消，但也没有人再提醒他去。他是在一份旧通知上看到朝会日期的，然后就去了。

太极殿里还是老样子。光线从高处的窗棂照进来，在殿中央投下一道道光束。光束里有浮尘在飞舞。大臣们按品级站好，朝服的颜色一片深紫浅红在光束中微微发亮。沈站在角落里——他在朝会上一直站在角落里。以前是因为工作位置在那里，现在是因为那里不引人注意。

朝会的内容他听着。但没有人问他任何问题。以前在朝会上，偶尔会有大臣转过头来问他一句——"沈起居郎，贞观某年的旧例是怎样的？"他会回答。现在没有人问。贞观年间的旧例——新朝有新朝的规矩。没有人需要旧例了。

他站在那里，听着新上任的官员们讨论着新朝的政策。他们声音洪亮，措辞果断，充满了年轻人特有的自信。他听着，什么也没有说。

朝会散了。大臣们鱼贯而出。沈走在人群的最后面。他走出太极殿的时候，春日的阳光正烈。他眯了眯眼，在台阶上站了一下。台阶上有人走过——没有人停下。

他走下台阶，穿过庭院，回到自己的值房。他关上门，坐下来，没有做任何事。他就那么坐着，听着窗外传来的声音——风吹树叶的声音、远处官员说话的声音、更远处街市上的叫卖声。

他想起太宗。想起马周。想起房玄龄。想起韩慎。这些人都不在了。他们才是那个时代的人。他自己——他不属于新朝。他知道这一点，新朝也知道。

他拿起笔，在纸上写了一行字：

"永徽二年，春。朝参如常。无人问臣。臣亦无言。"

他看了一遍，把纸折好，放进暗格。然后他吹了灯，在黑暗中坐了很久。

窗外有鸟叫。春天了。
