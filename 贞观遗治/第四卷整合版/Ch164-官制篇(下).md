# 第一百六十四章 官制篇（下）

贞观十九年，秋。

秘书省的旧档库里，一个久未开启的木柜被打开了。

沈站在柜前，手里举着一盏油灯。柜子里整整齐齐地码着一卷一卷的旧档，纸页发黄，灰尘积了厚厚一层。这里是秘书省的"故纸库"——存放着贞观元年以来所有抄录的前朝史料副本。很少有人来翻这些了，但沈是例外。

他今天翻的是一卷东汉永平年间的廷议记录。

他不是来翻东汉的。他是来确认一件事——三省制在中国历史上不是凭空出现的，它有演变的过程。尚书——门下——中书，这三个部门从汉代开始逐步分化，到隋唐才定型为三省。他想在自己写官制篇的理论部分时，把这段演变写清楚，让后人知道三省制不是某一个皇帝拍脑袋想出来的，而是花了数百年的时间，经过无数次的试错才最终形成的。

他在永平年间的记录中找到了他想要的东西——一份廷尉署的公文，上面出现了"尚书仆射"的批注。那是东汉明帝时期，尚书台已经初步具备了决策职能。

他拿出自己带来的纸，把相关内容抄了下来。

抄完之后他坐下来，在油灯下看了一遍自己的抄录。秘书省的档案库里很安静，只有风吹过屋顶瓦缝的呜呜声。油灯的光照在旧纸上，把纸面照成了温润的琥珀色。

他放下笔，靠在绳床靠背上。

他想起自己第一次走进这个档案库是什么时候——贞观二年，他刚被分配到秘书省当正字。那时候他十九岁，什么都不懂，第一次看到满屋子的旧档案心里想着：这些东西有用吗？十年后的他知道了答案。每一卷旧档都是在说话的人。只要你听得够久，他们就会告诉你答案。

但他今天翻旧档，不仅仅是为了官制篇的论述。他还有另一个目的——他想确认自己十年前的一个猜测。

十年前，他在崇文馆校《隋书》的时候，发现了一段关于北周官制的描述。北周仿《周礼》设六官，废三省。隋朝建立后恢复三省制。史料上这样写：

"隋文帝践祚，乃废六官，复三省。"

沈当时觉得这个描述过于简略了。北周的六官制用了二十多年，三省制中断了这么久，隋朝是怎么恢复的？中间经历了什么？他当时在崇文馆的笔记中写下了一行字：

"隋复三省，必有曲折。当查。"

但后来他一直没有找到机会去查。秘书省的档虽多，但隋朝的档案大部分在隋末战乱中遗失了。他以为这个疑问永远找不到答案了。

直到今天。

他在故纸库最里面的一个角落里，发现了一只未上锁的木箱，盖子歪斜着，落满了灰。他打开一看——里面是贞观初年秘书省从洛阳收集来的一批残档，全是隋朝旧物。没有人整理过，也没有人分类，就那样堆在箱子里。

沈把油灯放在地上，蹲下来，一卷一卷地翻。

翻到第三卷的时候，他找到了他要的东西——一份隋朝开皇年间的官制讨论记录。

记录显示，隋文帝恢复三省制的过程中，遭到了北周旧臣的强烈反对。反对的理由很直接：三省制是南朝的东西，北周用六官制用了二十多年，为什么要学南朝的？

隋文帝的回答很简练：因为三省制比六官制好用。

这份记录的真实性无法考证——它可能是后人伪造的，可能是抄写时添油加醋的。但沈不在意真假。他在意的是——原来一千年前的人已经争论过同样的问题了。三省和六官的争论，中央集权和地方分权的争论，皇权与相权的争论——每一次朝代更迭，这些争论都会重新出现，仿佛从来没有被讨论过一样。

他在油灯下把那卷记录抄了下来。笔在纸上走着，发出沙沙的声音，像秋天的雨打在树叶上。

他抄着抄着，忽然想起一句话。那句他写在秘书省校书笔记边批上的话——

"阉宦之祸，祸在掌兵。"

现在他要把这句批注变成遗制的一部分。他要把那些在旧档中听到的声音——东汉的、北周的、隋朝的——全部写进官制篇。不是给现在的人看的。是给以后的人看的。让他们知道，他们遇到的问题，前人已经遇到过一百遍了。

他在官制篇的最后加了一段话：

"历代以来，官制之弊，不在制度之不备，而在行之不久。一行即改，一改即乱。愿后之治大唐者，知制度之可贵，亦知其不可轻改。"

然后他合上了稿子。

他把隋朝的那份记录小心地收好，放进自己的布囊里，系紧袋口。走出秘书省的值房时已经是傍晚了。秋天的长安城笼罩在夕阳中，城墙、屋瓦、街道，都被镀上了一层金红色的光。远处的钟声响了，沉沉的，一声接一声。

他站在门口，深深吸了一口秋天干燥的空气。夕阳把他身后的影子拉得很长，一直延伸到档案库的台阶下面。他往前迈了一步，影子跟着动了一下。他走下了台阶。

官制篇，定稿。
