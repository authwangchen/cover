# 第五十三章 降俘入城

两个月后的三月中旬。

沈知远到秘书省的时候天还没有大亮。这几天长安城一直处在一种奇异的躁动中。捷报带来的狂欢还没有完全散去，街上偶尔还能看见前一天晚上贴上去的纸符——有人用红纸写了「天下太平」贴在坊门上。但空气中多了一种说不清的东西。几天前的那种纯粹的兴奋消失了，取而代之的是一种更复杂的情绪——似乎是所有人都在等什么。鼓声早就停了，但人们在街口站着，不再笑，而是伸长了脖子往南边看。

降俘入城的消息是前一天夜里传出来的。没有正式布告，但长安城的消息从来不需要布告。市场上、茶铺里、巷口的井边，消息如水一般从地底下渗出来。第一批突厥俘虏明天押到。沈知远知道这个消息的时候正在值房里整理存档，一个来送文书的杂役顺口提了一句，语气平淡得如在说明天的天气。沈知远没有应声，只是把手里的纸页翻过一页。

他当时想，这一天终于来了。军报上的那些名字、那些放在匣子里的档案，现在变成了活生生的人，正从几百里外走过来。

他值了不到半个时辰的班，街上的声音起来了。

不是鼓声，是另一种声音。低沉的、绵延不断的、如闷雷从远处滚过来的那种声响——是大量的人聚集在一起时发出的嗡嗡声，几十个人说话的声音叠在一起，传到远处就变成了一种低沉的轰鸣。沈知远放下笔，站起来，推门走出去。他没有往朱雀大街的方向走——他没有那个习惯。他站在秘书省大门的石阶上，朝南边望了一眼。

明德门的方向，人群的轮廓在晨光中隐约可见。正月清晨的光线很淡，照在石板路上泛着一层浅浅的青白色，远处的人影被这层光线拉得又细又长。有人裹着厚袄蹲在路边，双手拢在袖子里，嘴里呵出的白气在面前起起落落——很多人天没亮就来了，等了已经不止一个时辰。几个穿官服的人从他身边快步走过，脚步匆忙却不出声，袍角带起一阵冷风。沈知远在他们脸上看到的不是兴奋——那天捷报入京时的兴奋已经退了。取而代之的是一种沉沉的、说不清道不明的期待。

他走下石阶，往朱雀大街的方向走过去。

路不远。秘书省在皇城的西南角，穿过一条夹道就到了朱雀大街的北段。他走得不快也不慢，仿佛是要去办一件寻常公事的人。路上遇到的人都在往同一个方向走——有穿官服的，有穿便服的，有穿粗麻短褐的老百姓。没有人说话，所有人都沉默着往前走，脚步声踏在石板路上发出细碎而密集的声响。

朱雀大街两侧已经站满了人。

他在人群外围找了一个稍微高一点的位置——一块被鞋底磨得光滑了的大青石。他站上去，视线越过前面乌压压的人头，落在明德门的门洞上。两侧的坊墙上爬满了人——有人爬到了屋顶上，有人攀着坊墙的砖缝扒在墙上，膝盖和手肘的衣服被磨破了也不在乎。几棵老槐树的枝丫上也骑了人，树枝被压得弯下来，每动一下都咯吱咯吱地响，旁边的人仰头朝树上喊「小心别掉下来」，树上的少年猴子一样荡了一下，咧嘴笑。

没有风。阳光没有温度。所有人的呼吸在冷空气中结成淡淡的雾，浮在人群上方，久久散不去。空气中有一股气味——衣服上的灰尘、头油、隔夜的烟火味，还有早起的人吃了蒜和葱蒜的味道——几千个人的气味混在一起，涌过来，又散去，再涌过来。

人群忽然安静了。

那种安静不是从某一个人开始的，而是一层一层地传过来的——前面的人先收了声，似乎是看到了什么，沉默如水波一般向后面扩散，越扩越大。扩到沈知远所站的位置附近时，已经没有人在说话了。几千人站在大街上，安静如一片石滩。

明德门门洞里涌出一队人。

先是骑兵，大唐的甲士。玄甲红巾，执长槊。马蹄踏在石板地上，声音整齐而沉闷，一下一下的，缓慢而坚决。骑兵的马走得非常慢，不是小跑，是在步行速度上踱步。马蹄铁每一次落下去都如在敲击地面，发出清脆的、一下一下的金属响声。晨光从侧面照过来，照亮了骑兵的铠甲——那上面的红漆在晨光中如干涸的血。

骑兵通过之后，俘虏出现了。

先是一小群，然后是第二条灰色的线从门洞里涌出来，紧接着是第三条、第四条——很快变成了一条不间断的灰色的人流，从明德门门洞里面源源不断地往外流淌。他们穿着统一的灰白色粗麻衣，新发的，料子粗得能看见经纬之间的缝隙，风吹过去麻布贴在身上又鼓起来，显出下面瘦削的骨架。所有人的手被一根长长的绳索串着，像一串被线穿起来的珠子，绳索在清晨的冷空气中绷得很直，偶尔晃一下又沉下去。走在队伍前面的俘虏低着头，几乎拖着脚在走——不是不想抬头，是抬头也没有用，看到的只有长安城的坊墙和远处殿阁的屋顶。人群中没有人说话，只有千层底踩在石板地上的沙沙声和绳索摩擦时发出的细细的、令人牙酸的声响。

沈知远注意到队伍的排列并非完全随机。走在前面的是身材高大、体格强壮一些的，后面跟着老弱和妇孺。最末尾是几个受了伤的，有人用布条缠着头，有人一条胳膊空荡荡地垂在身侧。队伍中有几个妇人和孩子——有些孩子大一些，扶着母亲的手臂走；有些孩子小到要母亲抱在怀里，那只抱着孩子的手同时也被绳索串着，绳扣勒在手腕上。

然后有人喊了一声。

「胡狗！」

那声音从人群中炸开，又尖又利，像一把刀划开了这片沉默。紧跟其后，一团黄色的东西从人群中飞出去——干草拌着泥，准确地砸在一个俘虏的背上，散开。那个被砸的俘虏没有回头，只是肩膀微微缩了一下，又恢复了原来的姿势。

紧接着又有东西飞了出去——有人扔了半块胡饼，胡饼砸在一个俘虏的后脑勺上，碎成几瓣落在地上。有人扔了一小块石子，没有打中人，骨碌碌地滚到路中间停下了。唾沫星子在空气中飞舞，骂声从四面八方涌过来——有人在喊「胡狗滚回去」，有人在骂「让你们烧杀抢掠」，有人喊的话他甚至来不及分辨是什么。人群的笑声和骂声搅在一起，像是闹市中有一团大火烧了起来，火光映在每个人的脸上。那些喊得最响的人自己也不知道为什么要喊——他们不认得这群俘虏中的任何一个，也没有被突厥人抢过什么。但他们喊了，因为周围的人都在喊。不喊就觉得少了什么。

被骂的俘虏中有人低下了头，有人没有。低着头的人肩膀微微弓着，像在抵抗什么看不见的东西向下压。没有低头的人则直直地站着——同时直直地往前走，目光落在面前某个无形的点上，仿佛那些飞过来的骂声和秽物撞在他们身前的一堵墙上就自动碎掉了。

沈知远站在青石上，没有动。

他注意到一个人的目光。第二批俘虏走过来的时候，有一个人从他前面大约十步的地方经过。那人走在队列的中间偏后，约莫三十出头的年纪。和前面那些低着头、打着趔趄的俘虏不同，他没有低头。他的头微微抬着，目光平视前方。肩膀上有一道伤口，从肩胛骨一直延伸到后颈的位置，血迹已经在粗麻衣上凝成了黑褐色的印子，边缘的布料被干血粘得发硬。那人的目光掠过人群，没有愤怒，没有恐惧，甚至没有屈辱。那目光像是一块石头——不是被砸碎了的石头的目光，而是一块完整的、还没有碎开的石头的目光。

那人走过沈知远面前的时候，往人群里扫了一眼。

只是一瞬。像是漫无目的地扫过一排陌生面孔。但沈知远感觉到那一眼掠过自己身上的时候停留了一下——说不上停留，更像是那道目光在自己站的方向上慢了千分之一个呼吸。

然后那人转回头，继续往前走。那个肩膀上的伤口在他迈步的时候微微牵动了一下，麻衣上渗出一丝新鲜的血色，像一滴墨落进水里，很快就被底色淹没了。

然后他继续往前走。那个肩膀上的伤口在他迈步的时候微微牵动了一下，麻衣上渗出一丝新鲜的血色，很快就被底色淹没了。

俘虏的队伍很长。一批接一批，仿佛永远走不完。沈知远一直站在那块青石上，看着这条灰白色的人流从明德门门洞里源源不断地涌出来，流过朱雀大街，向北蜿蜒而去。他想到名单上那二十几个名字——那不过是最上面的一层。底下还有更多的人，他们没有名字，没有面孔，在档案上只被记作「突厥降俘若干口」。

队伍走到一半的时候，一个小男孩从人群里冲出来。大约七八岁，穿着打了补丁的棉袄，跑得太快，手里攥着的那串冰糖葫芦在空气中甩出一道弧线。他跑到路边，踮起脚，朝俘虏队伍里看了一眼。

一个俘虏恰好走到那里——三十来岁的胡人，胡子已经很久没刮了，乱蓬蓬地纠结在一起。他低着头走着，听到孩子的脚步声，抬了一下眼睛。那个小孩子和他的目光对上了。俘虏看了那个孩子一眼，眼神里没有恶意，只是淡淡的——像一个走了很多路的人在路边停下来看了一眼风景。

孩子往后退了一步。手里的冰糖葫芦掉在地上，糖衣摔裂了，露出里面暗红色的山楂。

没有人捡。那根糖葫芦就躺在石板地上，糖衣的碎片在晨光中闪闪发光。孩子的母亲从人群里冲出来，一把把孩子拉回身边，蹲下来抱住他的头，把他按在自己怀里——不让他看俘虏，也不让俘虏看他。孩子的脸被压在母亲肩膀上，眼睛睁着，看着远处，手里的空竹签不知道什么时候掉到了地上。

糖葫芦很快就被后面的人踩了过去。糖衣碎裂了，沾上了泥土的印子。山楂滚到路边，在一个水坑旁边停住了。沈知远看着那根破碎的冰糖葫芦，说不清是一种什么感觉堵在胸口。那个孩子举起冰糖葫芦的动作，那个俘虏抬了一下眼皮的目光——它们本来没有什么关系，只是此时此地恰好撞到了一起。但就因为恰好撞到了一起，就成了这个早晨最让人放不下的一件事。

他想到档案。档案上会记下人数、姓名、年龄、安置地点。但不会有那个冰糖葫芦碎在地上的样子，不会有孩子被母亲按进怀里时睁着的眼睛，不会有那个俘虏抬起的眼皮里映出的晨光。那些细节不会被写进任何一份存档里。它们像那根碎掉的冰糖葫芦一样，落在石板地上，被踩过去，消失了。

沈知远转身往回走。

他走得不快。正月长安的风吹在脸上，生冷干燥。穿过夹道的时候，路边一个卖热汤的老妇人蹲在炉子后面，见有人走过，低声问了一句「要不要碗热的」。沈知远摇了摇头。老妇人也不再多说，垂下眼睛继续看她的炉火。

回到秘书省，他推开值房的门。门轴转动的时候发出一声干涩的吱呀——这间屋子太冷了，每天早上推门都是这个声音。

他在案前坐下来。靴底踩过门槛时带回了一些城外土路上的干泥，碎在砖地上。他拿起笔，蘸墨，在存档簿上写下一行字——

「贞观四年三月中旬，突厥降俘至长安。」

纸面光滑，他写得很用力，笔划一笔一顿，像在纸上刻字。

写完这一行，他放下笔。看了看窗外。天已经转阴了，云层压得很低，没有阳光了。刚才街上的声音还没有完全散去——隐约还能听到远处有人在高声说话，但已经分辨不出具体的内容了，像水底传来的声音一样模糊。

他站起来，准备把那卷存档归入库房。

走到门口的时候，他看到王缉站在廊下。

王缉的姿态和那天捷报入京时一模一样——站在同一个位置，面朝同一个方向。他听到脚步声，没有回头，只是低声说了一句：

「那么多人。」

「嗯。」沈知远说。

王缉沉默了一会儿。他的目光朝归义坊的方向偏了偏——那个方向藏着专门安置降俘的坊区。

「那边，」王缉的声音更低了，「有人在哭。」

沈知远没有看那个方向。他也知道有人在哭。归义坊里住着上一批被安置的降俘——前些年陆续来的吐蕃人、吐谷浑人。他们看到今天这支队伍，大概想起了自己当年走进长安时的样子。他们和今天这些俘虏说着同一类语言，信着同一个长生天。亲人已经在长安了，但隔着几条坊街，隔着几堵坊墙，没有人知道他们在哭。

「我知道。」沈知远说。

王缉看了他一眼。那种目光里有探究的意味——一个同僚对一个不太理解的同僚的探究。沈知远没有回看。王缉站了一会儿，没有再说什么，转身回了自己的值房。他的脚步声在廊道里渐渐远去，和那天一样，无声无息的，像猫一样消失在转角。

沈知远站在廊下。长安城的天空越来越灰，冷意从四面八方渗进骨头缝里。他站了许久，直到一个杂役抱着一摞文书从廊道那头走过来，侧身从他旁边绕过去，他才微微动了一下。

他回到值房，坐到案前。

天色已经暗下来了。他还没有点灯。屋子里只有窗外透进来的最后一缕灰白色的天光，把桌椅和书架的轮廓勾勒出来，像一个水渍印子留在墙上的那种模糊的形状。他的手指碰到桌上摊开的纸页——那是一卷遗制的草稿，白天他批注了一半。纸边被风吹得卷了起来，摸上去凉凉的，像一片秋天干透的树叶。

他把那卷草稿往自己的方向拉了一下。手指在纸边上停了一下。

然后他收回手，靠在椅背上，在黑暗中闭上了眼睛。
