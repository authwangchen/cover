# 《贞观遗治》质检规约（QC Checklist）

> 生效范围：第三卷起所有章节 | 更新规则：每轮质检发现新问题类型即追加

---

## 一、写前准备（每次启动新卷/新批次的子进程前执行）

### 1.1 时间线基准表

每个子进程开始前，共享当前卷的**精确时间锚点表格**，确保所有进程使用同一基准：
```
卷号 | 章节区间 | 年份 | 季节/月份 | 关键历史事件
-----|---------|------|----------|------------
Vol X| ChXX-YY | 贞观X年 | 春/夏/秋/冬 | 事件名
```

**规则**：子进程不许自行设定时间锚点，必须从基准表中取。

### 1.2 称谓/器物对照表（子进程附带）

```
唐代常用器物对照：
- 坐具 → 坐榻/席/墩（严禁：椅子/凳子）
- 纸张 → 麻纸/竹纸（严禁：现代的纸）
- 油灯 → 灯/烛（严禁：电灯之类）

唐代称谓对照：
- 对皇帝 → 臣、微臣
- 对上级（私下）→ 下官、晚辈、某
- 对同辈/下位 → 我、吾
- 对尊长 → 学生、晚辈
- 称呼官员 → 某公（如房公）、官职（如侍郎）
- 严禁：爷（唐代"爷"只称父亲）
```

### 1.3 禁用词表（子进程中grep拦截）

**一级禁用（绝对不可出现）：**
- 椅子、凳子、沙发 → 坐榻/席
- 玉米、花生、土豆、红薯、辣椒 → 粟/麦/葱/姜
- 系统（表机构/机制时）→ 流程/格局/法度
- 电脑、手机、网络、微信、微博 → 全禁

**二级注意（应替换）：**
- 程序（表规程时）→ 规程/条例
- 信息（表消息时）→ 消息/音讯/风声
- 方案 → 方略/办法/策
- 评估 → 考量/估量
- 机制 → 法度/规矩
- 推进 → 推行/推动
- 问题（抽象议论时）→ 弊/患/关碍/疑

## 二、写后即时扫描（每产出10章后执行）

### 2.1 禁用词grep

```bash
grep -nE '椅子|凳子|沙发|玉米|花生|土豆|红薯|辣椒|系统|电脑|手机|网络|微信|微博' *.md
```

发现即改，不留存量。

### 2.2 "臣"在私人对话中的排查

```bash
# 在非朝堂/非面圣的对话中，"臣"应改为"下官"
grep -n '"臣\|"微臣' *.md | grep -v '甘露殿\|太极宫\|陛下\|御前\|朝会\|殿上'
```

### 2.3 "安史之乱"排查

全书任何章节不得出现"安史之乱"四字，必须用含蓄表达替代（参见质检规约附录）。

### 2.4 "一千多年后"类穿越暗示排查

沈知远的独白中不得出现明确指向穿越身份的表达。应改为"读史书时读到""从旧档中发现"等合理化表述。

## 三、每10章衔接扫描（合并时执行）

### 3.1 逐对检查清单

对每一对 ChN→ChN+1：

- [ ] 时间是否倒流？ChN+1的时间不能比ChN早
- [ ] 季节/天气是否矛盾？（不能"上一章雪停了下一章桃花开了"）
- [ ] 沈的位置/状态是否一致？（不能"上一章在值房下一章在城外无过渡"）
- [ ] 上一章结尾的事件，是否被下一章开头重复叙述？（同一场景不能从两个角度写两次）
- [ ] 如果时间跳跃过大（>1个月），是否有过渡句？（"一个月后""春天过去了"等）

### 3.2 已知高风险衔接模式

| 模式 | 问题 | 修复方式 |
|------|------|---------|
| 幕间收束→新幕开篇 | 子进程时间线打架 | 幕间收束章末加"几个月后"，新幕首句对齐 |
| 事件A→事件B（同一时段） | 并行事件被写成前后顺序 | 加"与此同时"或明确时间标注 |
| 夜间→次日 | 缺"第二天"标注 | 加明确时间过渡 |

## 四、每次全卷终审（写完全卷50章后）

### 4.1 伏笔清单核对

逐条核对伏笔回收状态：

```
Vol1 伏笔清单：
- [ ] 武德旧档"被抹掉的人"（Ch8埋）→ 预期回收卷：__
- [ ] 仓曹签名代签（Ch17埋）→ 预期回收卷：__
- [ ] 崔元甫县令（Ch18埋）→ 回收情况：__
- [ ] 归义坊胡人小孩（Ch26埋）→ 回收情况：__
- [ ] 遗策/私人笔记（Ch44埋）→ 回收情况：__

Vol2 伏笔清单：
- [ ] 归义坊车辙印+粟特文（Ch64埋）→ 预期回收卷：__
- [ ] 长孙无忌+韦家联盟（Ch86埋）→ 预期回收卷：__
```

### 4.2 情感曲线检查

绘制整卷"希望值"曲线（0-10），检查：
- [ ] 最低点持续是否超过3章？（应避免）
- [ ] 最高点→最低点之间是否有过渡？（避免断崖）
- [ ] 卷末是否留有续卷接口？（下一卷的开篇空间）

### 4.3 主题密度扫盲区

扫描全卷"制度vs人治"核心主题出现频次：
- [ ] 是否有连续20章以上的主题荒漠区？
- [ ] 核心金句"制度是把好人当普通人用"是否已登场？（若卷次已到应有位置）

### 4.4 章节字数检查

- [ ] 最短章节是否 < 3000字？（应避免，需扩写）
- [ ] 最长章节是否 > 8000字？（可接受，但注意节奏）
- [ ] 五幕之间字数是否均衡？（偏差不宜超过30%）

## 五、子进程质量管控（团队协作规则）

### 5.1 任务指令模板

每个子进程启动时，任务描述中必须包含：
1. **时间锚点**：当前章节在整卷中的精确位置
2. **禁用词清单**：第1.3节内容
3. **称谓对照**：第1.2节内容
4. **风格指令**："冷峻克制史书风，用动作代替心理，环境描写丰富"
5. **批处理数量**：建议每批上限5-7章（过多则质量下降）

### 5.2 产出验收标准

子进程完成后，必须验证：
- [ ] 所有禁用词已清除
- [ ] 时间锚点与基准表一致
- [ ] 章末→章首不重叠/不倒流
- [ ] 核心事件无遗漏
- [ ] 文风与第一卷基准章节一致（抽样对比）

### 5.3 常见拒收情形

| 情形 | 处理 |
|------|------|
| 现代词≥3处 | 退回重改 |
| 时间倒流 | 退回重设锚点 |
| 章节字数 < 3000 | 退回扩写 |
| 人物OOC（性格偏离） | 退回重写 |

### 7.0 新增：比喻密度控制（2026-05-21 追加）

**问题**：Vol2平均每章15次"像"字明喻，最高章42次。冷峻史书风应少用明喻。

**规则**：
- 每章"像"字比喻 ≤ 10处（理想） / ≤ 15处（上限）
- 高频"像"章节产出后，应做一轮削减：保留关键意象（≤全书5处左右的精品比喻），删除填充性比喻
- 禁止连续两行出现"像"比喻

**检查命令**：
```bash
grep -c '像' *.md | sort -t: -k2 -rn | head -10
# 找出超标章节，逐章削减
```

**示例对比**：
- ❌ "街上的人流像一条灰色的河，缓缓向南涌动。"
- ✅ "街上的人流顺着街道向南涌动。"
- ❌ "他坐在那里，像一尊被遗忘的石像。"
- ✅ "他坐在那里，一动不动的。"
