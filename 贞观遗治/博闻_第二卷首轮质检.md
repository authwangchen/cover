## 一、与第一卷的连续性（共6项）

### 1. ✅ 韩慎病情：Ch51"春雪"提及 → 完美承接

- Vol1 Ch38-39：韩慎贞观三年冬病重，太宗赐药，病情在Vol1末得到控制。
- Vol2 Ch51（春雪）：沈知远清晨醒来时，文中描写韩慎在隔壁"均匀的呼吸声"——不过问"昨晚睡得好不好"，以行动照常照顾沈的生活（做饭、洗衣）。韩慎在Ch51中没有明确的"病后恢复"描写，但此后各章均通过"韩慎还在"（Ch59、Ch78、Ch86、Ch98）的持续性存在传递了病情已控制住的信息。
- Ch59"韩慎的故人"：韩慎主动出门见人（走访灵州归来的老友），说明身体已恢复到可外出的程度。
- Ch78"韩慎旧事"：韩慎在院子里收衣服、做饭、讲故事（隋朝旧事），身体仅表现为"背微微驼、动作不如以前快"——合理的衰老而非疾病复发。
- **建议**：可在Ch51或Ch52中增加一两句韩慎的日常状态描写（如"咳嗽少了"或"吃饭比前些日子多了一些"），使"病愈"的交代更显性化。当前写法偏隐晦，读者若不参照Vol1可能未意识到承接关系。

### 2. ✅ 马周关系：Vol1 Ch13/31建立 → Ch96升格为政治搭档

- Vol1 Ch13（寒门与世家）：马周在秘书省廊下与沈知远第一次对话——"你批注的《隋书》，我看了" → "写得好。"马周的出场点到即止，如寒门君子。
- Vol1 Ch31（入冬策论）：马周再次出现，与沈清谈关于治国理念，关系进一步深化。
- Vol2 Ch96（升迁）：马周来门下省窗口看沈知远——"起居郎，好位置" / "近水楼台" / "知道近水楼台的人，最容易淹死"——对话简短但分量极重，体现了政治搭档的默契。
- Vol2 Ch97（黑名单）：马周深夜送来长孙无忌黑名单，这已超出普通朋友关系，是深度政治同盟的信号。
- **评价**：过渡极为自然，从Vol1的"认识的同僚"→ Vol2的"互信的信息渠道+支持者"完全成立。

### 3. ✅ 戴胄关系：Vol1中提携者 → Vol2 Ch88延续

- Vol1中戴胄（京兆尹）是沈知远进入官僚系统的引路人，多次保护，Ch50警告"别再往下写了"。
- Vol2 Ch88"戴胄的劝告"：戴胄在尚书省廊下拦住沈知远，告诉他"第二层，是圣人（太宗）"——即太宗在背后看着沈。这暗示戴胄仍有保护性角色，但关系已从"监护人"升格为"在更深层面提供关键信息的人"。
- **评价**：戴胄在Vol2中的戏份虽少（仅Ch88），但关键性强，每出场都在关键时刻提供决定性信息。关系深化合理。

### 4. ⚠️ 崔元甫伏笔：Vol1 Ch18埋名 → Vol2 Ch76回收情况存疑

- **骨架记载**：Ch76（房玄龄斡旋）应回收崔元甫伏笔（调任进京）。
- **实际文本**：Ch76的主要情节是房玄龄推动分署办公试点（陇州）的斡旋过程。全文未出现"崔元甫"三字，也未找到崔元甫调任进京的任何暗示。
- **分析**：可能存在两种情况：
  - (a) 崔元甫的伏笔被移到了其他章节（需全文检索确认）
  - (b) 此伏笔暂未回收，留待第三卷处理
- **建议**：确认崔元甫伏笔的回收计划。如果Vol2未回收，请在《第二卷整合方案》中标注"崔元甫伏笔延至第三卷"。
