# 《贞观遗制》300 章结构总纲

---

## 一、全书节奏设计（非常关键）

整本书不是平均推进，而是**"三段式加速结构"**：

### 第一段（1—80 章）：入局与立足
- 主角进入体系
- 获得初级权力
- 第一次制度试探

👉 **特点：** 现实感 + 轻压迫 + 慢建立

### 第二段（81—180 章）：制度博弈
- 正式进入朝堂权力中心边缘
- 与关陇集团全面对抗
- 制度开始成形

👉 **特点：** 权谋密度最高

### 第三段（181—300 章）：时间碾压
- 主角逐渐失势或退场
- 制度独立运行
- 历史验证开始

👉 **特点：** 悲剧 + 史诗感爆发

## 三、主线升级路径（非常重要）

**沈知远权力曲线：**

```
破庙 → 抄书郎 → 正字 → 制度参与者 → 规则设计者 → 历史见证者 → 被历史遗忘的人
```

| 阶段 | 身份 | 权力等级 |
|------|------|----------|
| 1—10 章 | 破庙流民 | 无 |
| 11—30 章 | 书肆抄书郎 | 民间 |
| 31—50 章 | 崇文馆抄书郎 | 边缘官僚 |
| 51—80 章 | 秘书省正字 | 初级文官 |
| 81—120 章 | 著作佐郎 | 中级文官 |
| 121—180 章 | 制度参与者 | 影响力上升 |
| 181—240 章 | 规则设计者 | 影响力巅峰 |
| 241—260 章 | 历史见证者 | 边缘化 |
| 261—300 章 | 被历史遗忘的人 | 退场 |

## 四、三大爆点设计（确保能火）

### 爆点 1（第 1 卷末，约第 50 章）
**太宗第一次认真听一个寒门书生讲"百年之后"**

场景：崇文馆，太宗巡馆，主角在抄录《隋书》批注。

太宗："卿以为隋亡之鉴，最当警惕者何？"

主角："臣忧三事：一曰府兵负担过重，恐难持久；二曰边将久任，易生私兵；三曰胡汉杂处，恩威难测。"

太宗深以为然。

---

### 爆点 2（第 3 卷，约第 130 章）
**魏征问："你如何知道未来？"**
**主角答："臣不知未来，臣知人性。"**

场景：魏征深夜拜访主角，二人对谈。

魏征："卿所言制度，皆防百年之后。百年之事，卿何以知之？"

主角："臣非知百年，乃知人性。权力所在，必生腐化；兵权所在，必生割据。陛下在，无人敢反；陛下之后呢？"

魏征沉默良久。

---

### 爆点 3（第 6 卷，约第 295 章）
**安史之乱爆发时，皇帝读到二十年前他写的制度批注**

场景：马嵬坡，乱军之中，老太监呈上《贞观遗制》残卷。

玄宗翻阅，看到太宗朱批：
> "边将兼统，国之贼也；胡将专兵，乱之本也。后世子孙，慎之戒之。"

玄宗痛哭：**"朕负祖宗，朕负知远！"**
