# 第一百五十七章 凌烟阁

贞观十七年，正月。

凌烟阁的画像是从入冬就开始准备的。

沈知远第一次注意到这件事，是在贞观十六年的十一月。那天他路过将作监的院子，看到几个匠人在搬运木料——都是上好的楠木，纹理细密，油脂饱满，在冬日的阳光下泛着一层淡淡的琥珀色光泽。他停下来问了一句，领头的匠人说："奉旨造阁。"

他没有多问。长安城里每天都在造各种各样的东西，亭台楼阁，庙宇宅邸。一座新阁算不了什么。

但两个月后，他知道了那座阁的名字——凌烟阁。

贞观十七年正月十五。朝会。太宗在太极殿上正式下诏：命画家阎立本绘二十四功臣像，悬于凌烟阁。勋臣排名，以长孙无忌为首，依次而下。从太原起兵到玄武门之变，从平定突厥到安抚四方——二十四个人，二十四幅画像，记录了他从秦王到大唐皇帝的全部历程。

朝会散去的时候，沈知远在人群中听到了窃窃私语的声音。有人在低声讨论排名——谁在前面，谁在后面。有人说长孙无忌排第一是理所应当。有人在问为什么某些人没有入选。声音很低，混在散朝的脚步声中，像溪水底部的泥沙，只在暗处流动。

沈知远没有参与那些讨论。他走出太极殿，往凌烟阁的方向去。

凌烟阁建在太极宫的西北角，紧挨着三清殿。是一座三层的楼阁，飞檐翘角，斗拱层叠。檐下的彩绘还没有完全干透，颜料的气味在冬日的冷空气中格外清晰——一种混合了朱砂、石青、藤黄的气味，浓郁而辛辣。阁前的台阶上还散落着木屑和碎瓦，施工的痕迹还没有完全清理干净。

凌烟阁还没有正式开放。门前没有人守卫。沈知远站在阁前，没有进去。他站在台阶下面，仰头看着那座新落成的建筑。

阁门紧闭。透过门缝，他能看到里面隐约的光线——是烛火的光，隔着一扇门，光线微弱而摇曳。阁里有匠人在做最后的装裱工作。他听到里面传来人声——很低，像在讨论什么画的布局。

"——往左一点。"

"——再高两寸。"

"——不行，长孙仆射的像要居中最上首。"

那些声音隔着门板传出来，模糊而遥远。

沈知远没有站在那里太久。他开始绕着凌烟阁走。一圈，从正面到侧面。阁的墙壁是白色的，新刷的石灰还没有完全干透，手按上去会有轻微的潮意。他走到侧面的一扇窗下。窗户是关着的，但窗户上的纸还没有糊严，露出了一条细缝。他透过那条细缝往里看。

他看到了一个侧影。

是画在墙壁上的。一个穿着朝服的人，面目模糊——从这条细缝里只能看到轮廓。但那轮廓——他认识。是房玄龄。房玄龄的画像在第二排的某个位置。他站在那里，穿着他日常上朝时穿的官服，手里没有拿笏板——是垂手站着的姿势。画的不是他年轻时意气风发的模样，是他晚年坐在竹榻上的那个样子。

沈知远把目光移开。

他继续走，走完了一圈，回到了正门前。他没有再往门缝里看。

他知道二十四个人里面不会有他。他对此没有任何不满。这不是谦虚，也不是故作淡然——是事实。他只是中书侍郎，没有军功，没有开国之功，没有在玄武门做出过任何贡献。他在这座朝堂上存在的理由不是那二十四幅画——是他这些年写出去了的那些文书。那些文书没有名字，没有署名。它们被送到了各个州县，被执行，被归档，然后被遗忘。

他站在凌烟阁前的广场上。午后的阳光斜照过来，被阁楼的飞檐挡住，在地面上投下一大片三角形的阴影。他站在阴影和阳光的交界线上。

他低头看了一眼脚下。阳光照着他的影子——一条细长的、落在石板地面上的影子。那影子没有朝向凌烟阁——它朝着相反的方向。像他的影子本身也知道自己不属于那二十四幅画像中的任何一个。

沈知远站了一会儿，然后转身走了。

他没有回头看凌烟阁。

但他在转过第一个弯的时候，听到了一阵风吹过阁楼飞檐的声音。那声音低沉而悠长，像有人在很远的地方吹着号角。那声音响了三息，然后消失。

他没有停下来。

回到中书省的值房，他在案前坐下。案上有一份新的文书，是秘书省送来的——关于凌烟阁二十四功臣生平简介的初稿，需要中书省审核。他拿起那份文书，一行一行地看下去。

第一个：长孙无忌。赵国公，尚书右仆射。凌烟阁画像，排位第一。

他的目光在那行字上停了一下。

然后他继续往下看。看完了文书的全部内容，他拿起笔，在末尾批了一行字："已核。无误。"

他没有什么要改的。名单不是他定的，排名不是他定的。他只需要确认这份秘书省送来的简介里没有事实错误。这就是他的工作。永远在别人决定的事情后面做确认。永远在故事的边缘提供注脚。但他的名字不在那些注脚里。

他把文书放回案角，拿起下一份。

窗外有人在说话。两个小吏走过走廊，其中一个说："你听说没有——凌烟阁的画像里，没有侯君集。"

另一个说："他早就被贬了，当然不会有。"

"也对。但他以前是功臣。"

"——以前。"

沈知远听着那两个人的脚步声逐渐远去，没有说话。他低头看了看自己的手。那双手写过许多名字。写过长孙无忌的，写过房玄龄的，写过魏徵的，写过侯君集的。此刻，那些名字都挂在了凌烟阁的墙壁上——除了一个。

而他的名字，不在其中任何一个位置上。

但那不重要。他在中书省的案头看到了一份新的文书——是关于今年进士科考试的章程修订。他拿起来，开始批阅。

他在第一页的空白处写了一行批注："试策改为三道，诗赋仍保留，但权重减半。"

他放下笔，吹了吹纸上的墨迹。窗外的天色正在变暗，夕阳把整座长安城染成了暗金色。凌烟阁在远处若隐若现，像一座悬在半空中的楼宇。

他没有再抬头看它。
