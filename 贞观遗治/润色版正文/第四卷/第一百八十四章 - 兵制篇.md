# 第一百八十四章 兵制篇

贞观十九年，四月。

沈知远告了五天假。

不是生病。是请假事——"居家整理旧稿"。中书省的长官看了他的申请，没有多问。沈知远在中书省十六年，从来没有请过假。一次都没有。所以这次他说要请假，没有人拦。他锁上值房的门，把那六页提纲从《贞观政要》中取出来，揣在怀里，走出了中书省的大门。

这是他第一次正式动笔写《贞观遗制》。

他选兵制篇作为第一篇。不是随意的。兵制是所有制度中时效性最强的一种——法令过了十年可以重修，官制过了二十年可以调整，但兵制出了问题，不出三年就会见血。他选兵制篇打头，是因为他想写清楚：现在的大唐军制在靠什么运转，以及为什么不能一直靠这个运转。

他把书桌搬到窗边，让光线从正面照在纸面上。他磨了一池新墨——浓墨。新的笔——狼毫，刚开笔的，笔锋尖锐而有弹性。纸上没有格线，他需要自己控制行距和字距。他坐下，吸了一口气。

他写下的第一句话是：

"大唐军制之盛，不在府兵，不在折冲府，不在十六卫——在太宗。"

写完这句话，他停了片刻。这是一句危险的实话。一个人撑起来的军制，在这个人走了之后就会动摇。他不是在批评太宗——他是在陈述一个所有朝臣都不敢说破的事实：大唐军队现在运转良好，最大的原因是将领们信任太宗的军事判断。但这东西写在制度纸上，就是零。制度不是靠信任运转的。

他继续写。

他写府兵制的基础——折冲府的设置原则。一千多处折冲府分散在各地，三百五十个在关内道——这是重内轻外的布局。他写到了军府的编制：上府一千二百人，中府一千人，下府八百人。这些数字他早就烂熟于胸，但写在纸上时他还是翻了翻旧档核对了一遍。一个数字错了，整篇的可信度就塌了。他不想留任何漏洞给人挑。

他写府兵的来源——"取六品以下子孙及白丁无职役者点充。"他在这句话下面加了一条批注——不是写给现在的人，是写给未来某一天需要修订这条法令的人看的："此条之要害，不在取谁，在不取谁。不取勋官子弟，则军伍不腐。勋官子弟充府兵者，必占肥缺而避苦役，日久则军心溃于内。"他的笔在纸上游走得很快，笔尖在宣纸上发出沙沙的声音——细密的，连续的，像蚕在吃桑叶。墨汁在笔与纸接触的瞬间渗入纤维，留下深黑色的轨迹，每一笔都清晰、果断、没有涂改。

他整整写了一整天。

天黑了，他点起油灯继续写。灯芯在油面上燃烧的声音极轻，偶尔爆出一声响——啪——然后又归于寂静。他的影子被灯光投在墙上，随着笔的动作微微晃动。有时他停下来，不是在思考——是重新蘸墨。

到第二天掌灯时分，兵制篇的初稿完成了。

他放下笔，把写好的纸一张一张摊开来，在地面上铺了整整一排。他蹲下来，从第一张走到最后一张，像走过一座桥。每一张纸上都是密密麻麻的字——正文、夹注、括号里的补充说明。他对自己说：这些规矩，够用三十年。

但三十年后呢？他不知道。他能做的就是在这些纸里留下余地——在每一篇的最后都留了一段空白，写着一行小字："后之执政者，当视时势而损益之。但损益之前，须先通读此篇。"

他收拾好纸页，按页码叠好，用一张更大的宣纸包起来。他忽然想起一件事——对，兵制篇里他写了节度使的权限边界。但他忘了写一个东西。他在那张包裹纸上写了一个备忘录：明天加一条——"边将不得兼任支度使。"管兵就不能管钱。管钱就不能管兵。两权分离，谁也别想吃独食。他写完这个备注，把纸包放进书箱的底层。

然后他站在书桌前，在油灯下看了看自己的手。

手指上沾了一层墨——食指和中指之间的位置，洗不掉的那种印迹。他盯着那道墨痕看了片刻，把它看成了一种标记。他伸手关灯，在黑暗中站了几息，感受着自己的心跳。

跳得不快。很稳。

像战鼓在休战时的节奏。
