# 第一百九十三章 驾崩

贞观二十三年，五月己巳。

翠微宫的上空没有云。天空是一种很淡的蓝色，淡到接近白色，像一块被反复漂洗的旧布，已经看不出原来的颜色了。太阳升起来的时候，把含风殿的屋顶镀上了一层薄薄的金色——但那金色没有温度，只是冷冷地铺在瓦面上。

沈知远在寅时就到了。

他是被内侍从平康坊的宅中叫醒的。他没有更衣——只披了一件外袍就上了马。从长安城到翠微宫的路，他走了二十一年。闭着眼睛都知道哪一段路坡度最陡，哪一段路边的槐树最密，哪一段路上的石板被雨水冲出了缺口，马蹄踩上去会发出两种不同的声响。但今天这条路格外漫长。每一段路都像被拉伸过——走了很久很久，周围的景色却几乎没有变化，像是在原地踏步。马蹄敲在石板上的声音从原来的清脆变成了沉闷，像被什么东西捂住了。

他到达含风殿的时候，太医令已经在殿外站着了。

太医令的袍子在晨风中微微晃动。他的脸色发青——不是在哭，是一整夜没有合眼的那种枯槁。他向沈知远点了点头，没有说话。他的手垂在身侧，指尖微微发颤。那不是恐惧的颤抖——是一个人在同一个地方站了太久之后，肌肉不由自主的痉挛。

“还没有……”沈知远问了一半。

太医令摇头。

沈知远站在含风殿外的台阶上。晨风从山谷中吹过来，带着湿润的、混着草木和泥土的气息。几片早落的槐叶被风卷到他脚边，在地上旋了一两圈，然后就躺在青砖上一动不动了。他捡起一片叶子。叶片还没有完全干枯——边缘卷曲了，但叶脉还保持着弹性。他把叶片放在掌心，看了一会儿，然后放进了袖中。

他不知道为什么要这么做。

殿里的声音传出来了——不是哭声，是宫人走动时衣料摩擦的声音，和一个内侍压低了嗓子说话的声音。那些声音被墙壁和门帘过滤了很多次，到达沈知远耳朵时只剩下一些含混的嗡嗡声，像从水底听到的水面上的动静。

辰时。太阳已经完全升起来了。阳光照在含风殿的琉璃瓦上，反射出刺眼的光。沈知远站在台阶上，没有躲进阴影。阳光晒在他的左半边脸上，让那一侧的皮肤微微发热，而右半边脸留在阴影里，凉着。一条身体上同时感觉到热和冷——中间的分界线从他的眉心经过鼻梁、下巴一直延伸到脖颈，把一个人切成了两半。

殿内忽然安静了。

不是那种“声音渐渐变小”的安静——是一种突如其来的、像什么东西忽然被抽走的安静。原来还在的那些细微的声音——衣料的摩擦、步子的移动、压抑的呼吸——在一瞬间全部消失了，仿佛所有人同时停止了呼吸。

然后他听到了哭泣声。

不是嚎啕大哭，是一个内侍忍不住发出一声后被同伴捂住嘴的那种声音——短促的、憋在喉咙里的呜咽，像被压在堵块下面的一小股水流，拼命想冲出来，但被堵住了。然后更多的声音加入进来——细小而克制的，像雨滴落在瓦面上，然后渐渐密集，然后变成一片。

沈知远站在台阶上没有动。

门被从里面打开了。一个内侍走出来，脸上没有表情——那种刻意维持的没有表情，比任何表情都更难维持。他走到沈知远面前，声音低得几乎听不见：

“沈侍郎——陛下驾崩。”

沈知远点了一下头。

他听到自己的喉咙里发出一声“嗯”——很短，很轻，像是一个正常的回应。他把手伸进袖中，摸到了那片槐叶。叶子的边缘已经在他的体温中微微变软了。他握着它，没有拿出来。

然后他走进殿去。

含风殿里的空气是凝固的。炉中的炭火还在燃着——没人想到去熄灭它——但整个房间的温度仿佛在这一刻降了下去，所有的热气都被抽走了。病榻上，太宗侧卧着。姿势和昨夜他离开时几乎一样——一只手蜷在胸前，另一只手搭在被面上。脸色是灰白色的——不是苍白，是灰白，像一块石板在被水浸湿后又迅速风干后的颜色。嘴唇微微张开着，露出了牙齿，像是想把最后一口呼吸留得更久一些。

沈知远在榻前站了很久。

他想到了一件事——这件他完全没有预料到的事，像一个不敲门就闯进来的人：

贞观二十三年了。他这辈子见过的人，从二十三年之前开始一个一个地离开。韩慎。魏徵。房玄龄。现在轮到皇帝了。下一个是谁？

他低下头。影子的边缘落在太宗的被面上，和皇帝的遗体重叠在一起，分不清是谁的。

他伸出手——不是去触摸——他用手背轻轻碰了一下太宗的手背。隔着被面。只是碰了一下，感受不到温度——只有布料下某个固体形状的轮廓。然后他收回手。

他转身，走出寝殿。

含风殿外的走廊上，宫人们已经跪了一地。晨光越过房檐的阴影，在东侧的墙面上投下一道斜斜的金色光带——像一把刚刚抽出的剑，还没有完全出鞘，剑刃上就已经映出了天光。有人在低声啜泣，有人在低声传话，有人在奔跑。脚步声从四面八方传来，又向四面八方散去——急促的、杂乱的、没有方向的。像一只被捅了的蚁穴。

沈知远站在走廊的阴影里。

他看着这场骚动。他是这个庞大帝国中枢机构的核心官员之一。但他此刻站在那里，什么也没有做。他不知道自己应该做什么。那道发遗诏、发丧、通知太子、安排继位的程序——每一个步骤他都清楚，每一个文书他都写过，每一个流程他都参与过制定。但在这一刻，那些程序好像变成了纸面上的字，不指向任何真实的东西。它们沉在意识底部，像河底的石头——你知道它们在，但你无法伸手去够它们。

阳光又移了一寸。金色的光带从东墙移到了正中的地面上，把跪了一地的宫人的影子拉长，交错，重叠，像地上铺了一层破碎的黑色织物。

一个年轻的官员从走廊那头匆匆跑来，在他面前停下，喘着气，脸上的汗珠顺着鬓角往下淌。

“沈侍郎——元舅那边请您——遗诏——”

沈知远看着他。年轻的脸——不超过三十岁。可能是在贞观十年之后入仕的——那时候他沈知远已经开始被人称“沈侍郎”了。这个人不认识贞观初年的长安。他不知道贞观二年朱雀大街上的雪有多深。他不知道那时候的中书省只有几间旧屋子，屋顶漏雨的时候要用盆接着，盆里的水映着烛火，像一颗滚动的光珠在跳动。

他忽然意识到：这个帝国里，已经有越来越多的人不记得贞观初年了。

而他自己，也很快会成为不记得更多东西的人。

“知道了。”沈知远说。他理了理衣襟，往值房走去。走出三步之后，他停下来，回头看了一眼含风殿的屋顶。阳光照在琉璃瓦上，反射出刺眼的、破碎的光。

屋顶上的脊兽在光中静默着。

他把目光收回来，继续走。

值房里已经有人在等他了。中书令、门下侍中、尚书省的几位长官——还有长孙无忌。长孙无忌站在桌案旁，背对着门，正在看一份已经摊开的诏书。他的肩膀宽厚——不像一个五十多岁的人——但背影里有一种沈知远从未在他身上见过的疲惫。不是身体的疲惫——是一种更深的、从肌肉和骨骼内部渗透出来的沉重。长孙无忌听到脚步声，没有回头。他的手指按在诏书的纸角上，指尖微微泛白，用力按着，像担心纸页会被风吹走。

“沈侍郎。”长孙无忌的声音很平静。

“元舅。”

“遗诏的事，你来起草。”

“是。”

沉默。

沈知远走到另一侧的案前，铺开纸，研墨。墨锭在砚台上转动时发出均匀的摩擦声——单调而绵长，像一个单音节的词被反复念诵。晨光从窗外照进来，照在还没有落笔的白纸上。纸页的边缘微微翘起，被光线照得半透明，几乎可以看到纸的纤维结构——那些细如蛛丝的纹路交织在一起，把一片空白固定在一个完整的轮廓里。

他拿起笔，蘸墨，落笔。

笔尖接触纸面的那一刻，他感到了一股阻力——不是来自纸，是来自那支笔本身的重量。它比平时沉。或者，是他的手腕比平时没有力气。他写下第一个字：“大行皇帝……”

他写得很慢。每一个字都写得比平时更慢。不是因为不熟练——是因为他忽然发现，写了这么多年的诏书，他从不知道最后一份诏书应该用什么语气来写。多一个字是废话，少一个字是亏欠。

窗外有鸟叫。一只，很短促的两声，然后停了。阳光从窗外移进来了一些，把桌案上他正在写的字照亮——那些墨迹还没有干，在光中泛着湿润的、微微凸起的亮痕。他把第二行写完，放下笔。

他听着自己的呼吸声。和笔尖在纸面行走的声音——很轻，像远处有人在下雪。

长孙无忌在他身后说了一句话。声音不大，不知道是说给谁听的：

“一个时代结束了。”

沈知远没有回应。他蘸了第二次墨，笔尖吸满了墨汁，在灯光下闪着湿润的黑色光泽。他落下下一笔。

外面传来钟声。不是长安城里报时的钟——是翠微宫自己敲的丧钟。第一声很突兀，像一个猛然摔碎的东西。然后第二声跟了上来，然后是第三声、第四声。钟声越过山脊，向着长安的方向传去，在山谷之间被拉长、被揉碎、又被重新拼合，最后变成了一个绵延不绝的、低沉的声音，像大地本身在发出轰鸣。

沈知远停下笔，听着钟声。

二十一响。钟声停了。

他又开始写。
