# 第一百三十三章 康洛的告别

康洛回来的时候是贞观十二年的正月。新年刚过，长安城还沉浸在节庆的余温中——坊门上的春联还是新贴的，红纸在冬日的阳光下格外鲜艳，有些人家门前的竹节燃烧过的碎屑还没有扫净，在风里打着旋。

他在一个清晨敲响了沈知远的门。沈知远开门时，看到康洛站在晨光里。他比走的时候瘦了一圈。颧骨高了，眼窝深了，嘴唇干裂，护手被风沙磨得发白，几根断线在护手的接缝处随风飘动。他的外套上有些地方破了口子，露出里面灰色的旧棉絮，在晨风中微微地翻动着。他的腰间挂着一把新刀——不是韩慎棺材上那把，那把他已经留在河西了。

两个人在院子里站了一会儿。康洛的靴底上沾着干裂的泥块——从远处带来的泥土，和长安城的土颜色不同，颜色浅一些，带着沙质的颗粒感。

"查到了。安氏。"

康洛从怀里掏出一张纸——不是新的纸，是揉皱了的旧纸，上面画着几条线和几个地名。纸页被反复折叠过，折痕深得几乎要断裂，边角卷曲发毛。他用手指在纸上点了两个地方："幽州。安氏的后人，现在幽州下属的怀戎县做小吏。姓安，名守义。五十多岁。"

"他和归义坊的事有关吗？"

康洛摇了摇头。"不确定。安守义本人可能什么都不知道。但他的父亲——安守义的父亲——是隋末河西节度使幕府的人。"

沈知远的目光在纸面上停住了。

"和韩慎一样。"

"和韩慎一样。"康洛说，"韩慎和安守义的父亲——在同一个幕府里待过。"

院中安静了一会儿。风吹动院子里那棵槐树的枝条，光秃秃的枝丫互相摩擦着，发出干燥的咿呀声。沈知远握着那张纸卷，纸页的边缘抵着他的指腹——纸张的质感粗糙，带着长途跋涉后沾染的尘土气息，还有一种淡淡的、不属于长安的干燥气味。沈知远的手指在纸页上慢慢收紧了。

安守义的父亲——和韩慎在同一个幕府待过。如果韩慎在最后那卷纸里提到了姓安的人——那就是安守义的父亲。康洛的这条线指向了一个他从未听过的名字。

"安守义的父亲叫什么？"

"安从周。"

两个人在院子里站了很久。晨光从东边的院墙上方照进来，在石桌上形成一块细长的光斑。冬天的阳光落在那张旧纸上，把纸面上的折痕照得格外分明，像是大地的山川在晨光中铺展开来。沈知远把那三个字在心里默念了两遍。安从周。和韩慎同时代的人。他知道什么？他留下了什么？

"康洛。"

"嗯。"

"你接下来打算怎么办？"

康洛没有马上回答。他靠在院墙上，双手抱在胸前——那个姿势和以前一样。但他的目光比以前更远了，像一条已经流过了很多山路的河流，在某个开阔处短暂地放慢了流速，目视着前方更远的方向。

"我还得去一趟幽州。"

"——现在？"

"现在。"康洛说，"正月里城门查得松。我扮成货商，从河东道绕过去。"

"——多久？"

"不知道。可能三个月。可能半年。"

沈知远看着他。他知道康洛一旦说了"要去"，就没有人能拦得住。康洛不是问他的意见——只是在告诉他。

"你路上小心。"

康洛点了点头。他从怀里掏出一样东西——是一块旧骨片，大约半个手掌大小，边缘磨得很光滑，上面刻着几个模糊的符号。他把骨片放在石桌上。骨片接触石面时发出一声极轻的、清脆的响——像一枚棋子落在棋盘上。

"这是韩慎的。"

沈知远低头看着那块骨片。骨片在晨光中泛着一层淡黄色的光泽，表面有一层温润的光亮——像是被抚摸过很多次。

"我在河西找到的——安从周的旧物里夹着一封信。信上提到了韩慎。说韩慎手里有一块刻了某种记号的骨片——和西北某个部族有关。那封信上说——'骨片若现，铁扣必出'。"

沈知远的手指轻轻握住了那块骨片。骨片很凉。表面光滑，但边缘有一些细密的刻痕——不是文字，是一种他看不懂的符号。那些符号像某种古老而隐秘的标记，在晨光中泛着一层淡黄色的、温润的光泽。他用指腹沿着刻痕的走向描了一圈——刻痕的底端有些发暗，像是被什么液体浸染过，在时间的侵蚀中留下了深色的印记。

"铁扣"——那两个字在晨光中格外清晰。

他在袖中悄悄握紧了那块骨片，骨头冰凉坚硬的触感透过布料传到他的皮肤上，像一枚棋子落在了某个他还不知道位置的关键节点上。他能感觉到骨片的纹理——那些细微的不平整的、只有手指才知道的纹理——在他的掌心中慢慢被体温焐热了一小块。

康洛站了起来。他把皮袄裹紧，系好腰间的刀。皮袄的领口处有一块深色的污渍，像是血迹——已经变黑了，干透了。

"我走了。"

沈知远送他到门口。康洛走出两步，停下来。他没有回头，只是背对着沈知远说了一句话。

"你身边——不要放太多东西。"

说完他就走了。沈知远站在门口，看着康洛的背影在晨光中越来越远，最后消失在坊门的拐角。康洛走路的姿势有点跛——右腿似乎比左腿短了一截，大概是长途跋涉造成的，也可能是受了什么伤没有说。

沈知远站在门口，手里的骨片被他的体温焐热了一小块。他回到院子里，拂去石凳上积了薄薄一层的灰尘，坐了下来。他低着头，看着那块骨片，看着骨片上那些他看不懂的符号。晨光在石桌上移动，把骨片的影子照在了石面上——影子的形状和骨片本身一模一样，像一个沉默的、不变的倒映。

"骨片若现，铁扣必出。"

六个字。像六根钉子。

他站起来，走进屋里，把骨片和那枚铁扣放在一起。两只木匣并排放在书架的最上层。铁扣。骨片。两条线索。它们在书架的最高处沉默地紧挨着，像两个在黑暗中各自等待了很久的人，终于被放进了同一个房间里。沈知远把两只木匣的位置摆正，手指在木匣边缘停留了片刻——木头的触感冰冷而坚硬，表面有些粗糙，像是被打磨过的边界。

窗外，正月里的风还在吹着。他关上了书柜的门。柜门在木头与木头的轻轻碰撞中合拢，发出了一声沉闷的、几乎听不见的响。
