# 第一百零七章 空座位

韩慎走后第七天，沈知远回到了门下省。

他像往常一样卯时入省，坐在自己那张小案后面，研墨，铺纸。砚台里的墨很快化开了——他的手指习惯了这套动作，不需要脑子指挥。他翻开了前一天的起居注，逐字逐句地校对着，把一些笔误和措辞不规范的地方一一纠正。纸上的字迹清晰而工整，每一笔都落得稳稳当当，看不出任何情绪。他的笔很稳，稳得像什么都没有发生过。

中午休憩的时候，他沿着秘书省的方向走了一段路。走过那条长廊——廊柱的漆面在风吹日晒中已经褪色了，露出下面灰白色的木质纹理——然后在岔路口停了下来。左转是秘书省的值房，右转是出宫的路。他在岔口站了一会儿，觉得那条左转的路像一条通往陌生地域的通道，他走了太多次，但今天他觉得那边什么也没有。

他没有左转。

他继续往前走，出了宫门。

他没有去韩慎的小院。他在坊门口站了一下，看着那条巷子，然后转身去了集市。集市上人声嘈杂，有人在卖秋天的柿子，黄澄澄的堆了一筐。他买了一斤，拎在手里，在人群中站了一会儿——周围的人都朝各个方向移动，而他站在人流的中央一动不动，像一个被遗忘在棋盘角落里的棋子，四周的棋局还在继续，他已经不再参与任何落子。

然后他把柿子放在路边一个乞丐面前。乞丐抬头看他，他说："吃不了。"然后空着手走了。

接下来的日子，他发现了一些奇怪的小习惯。

比如他每天早晨出门时还是会多带一份早点。他会在巷口停下来，看着那份用油纸包好的胡饼——韩慎喜欢胡饼，每次都要趁热吃，拿在手里颠来倒去地吹气，撕下一小块放进嘴里嚼很久。现在他把油纸打开，自己吃了半块，剩下半块放在路边的墙头上，转身走向宫门的方向。走了两步他停下了——他在风里站了一会儿，风吹着他的脸，带来远处市集的嘈杂声。他没有回头去拿墙头上的半块胡饼，只是继续走。

比如他路过韩慎的小院时，脚步会慢下来——不是停下来，是慢下来。他会侧头看一眼那扇紧闭的门，然后继续走。每次都是同样的停驻频率。

半个月后的一个傍晚，房玄龄在中书省外的廊下叫住了他。

"沈舍人。"

沈知远停下来，转身行礼。房玄龄站在廊柱旁边，手背在身后。秋天的光线斜斜地照在房玄龄的脸上，他的表情在那道光线中显得很平静——但那是一种经过训练后才会有的平静，像一面结了冰的湖面，任谁也不知道冰面以下的真实水温。

"你最近——"房玄龄斟酌了一下，没有说出后半句。

沈知远没有接话。

沉默持续了一下。房玄龄点了点头，没有继续问。他拍了拍沈知远的肩膀——动作很轻，手掌落在沈沈肩头的那一刻几乎是飘落的，像秋风中的一片树叶落在水面上——然后转身走了。

沈知远站在廊下。晚风吹过来，吹动他手中的纸张边缘。他低头看了一眼——那是明天朝会的议程表。密密麻麻的名字，密密麻麻的事项。韩慎的名字不在上面。韩慎的名字再也到不了任何纸上了。

他把议程表折好，放回袖中。

一个月后，沈知远每天早晨出门时不再多带一份早点了。

但他养成了另一个习惯——每天下值后，他会绕一段路，经过韩慎的小院门口。不停下来，不推门，只是从巷口走过。有时候巷子里有人经过，有时候没有。有时候门缝里会有一片落叶被风吹出来，落在他脚边。他每次都会看一眼那片落叶，然后继续走自己的路。

有一次他从门下省出来时天已经黑了。星光很淡，月光被云遮住了大半。他没有绕路——直接回了家。他在床上躺了很久，没有睡着。

他发现自己不能不去走那条路。

那条路不是通往韩慎的——那条路通往一个他已经失去的人。但他仍然需要每天都去确认一次：那个人确实不在了。每一次走过都是确认。确认那道门不会再被推开，确认那棵枣树不会再在秋天之外的日子里开出任何花来，确认院子里的石凳上不会再有一个老人坐着等他。

他翻了个身，窗外的月光从云层缝隙里漏下来。

第二天他照常走了那条路。

和前面四天一样，院门紧闭。

和前面四天一样，他站在巷口，看了一眼，然后走了。

他在心里把这种感觉归结为一个词：习惯。

但他知道这不只是习惯。这是告别——一种每天都要重新进行一次、每天都不够彻底的告别。像是有一个他无法解开的东西，被一根看不见的线系在那扇门后面。每次他试图走远，那根线就会绷紧，把他拉回来。

他不知道自己还要走多久。
