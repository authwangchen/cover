# 第一百零二章 韩慎的咳嗽

入夏后一个黄昏，沈知远从门下省出来，沿着平康坊的巷子往韩慎的小院走。他手里提着一包药——川贝、枇杷叶、甘草，是太医署的人给开的方子。纸包被油浸透了一小块，散发出一种清苦的气味，和巷子里晚饭时间的炊烟混在一起。空气里还有烧柴的味道——有人家在生火，烟气从墙头飘出来，灰白色的，在半空中散开，带着一股干燥的草木焦香。

推门进去时，韩慎正坐在院中的石凳上。他没有在修东西，没有在择菜，只是坐着。手搁在膝盖上，腰微微佝偻着，目光落在院墙角那棵枣树上。枣树正在开花，细碎的淡黄色小花藏在叶隙间，香气若有若无。那香气极淡，要走近了才能闻到——不是扑鼻而来的，是慢慢渗透过来的，像一件旧衣服上残留的熏香。听到门响，他转过头——动作比从前慢了一点，很慢，沈知远能看清他脖子转动的每一步。

"又带药。"不是问句。

"太医说——"

"太医说什么都没用。"韩慎打断他，声音里没有不耐烦，只有一种平静，"老毛病。到了岁数就这样。"

沈知远在他旁边坐下。石凳被晒了一整天，坐上去微微发烫，隔着衣料还能感受到石面上的余温。他把药包放在石桌上，打开纸包，露出里面切成薄片的药材。甘草的甜味混着川贝的苦味一起散开，在暮色中形成一种奇怪的气味——甜和苦纠缠在一起，谁也不肯先退让。

"昨天咳了一夜？"

韩慎没有回答。他伸手拿起一片甘草，放进嘴里含了一会儿，然后嚼碎，咽下去。他咽的时候喉结动了一下，很慢，像一个已经被用了很久的机关，每一次运转都需要比从前多一点时间。他的手指在石桌上摸索了一下，找到了石桌边缘的一道裂缝，指尖沿着那道裂缝来回划了两遍。

"这药太甜了。"他说，"我不喜欢甜的东西。"

"苦的药您又不喝。"

韩慎没有接话。他靠在榻沿上，闭了一会儿眼睛。枣树的花香在暮色中越发浓郁——傍晚的时候最香，像有什么东西在光线退去的过程中释放了自己。几只麻雀在墙头跳来跳去，翅膀扑棱的声音短促而清脆，在安静的院子里显得格外响亮。他闭着眼睛说了一句，声音很轻，像是自言自语：

"我最近总想起一个人。"

沈知远没有打断他。

"隋朝大业九年，河西节度使幕府里有一个录事参军。比我大几岁。他教我怎么看边镇的军报——不是看上面写了什么，是看上面没写什么。他说：'每一份军报都有两行字。一行在纸上，一行在纸和纸之间的缝隙里。'"

他睁开眼睛，看着远处屋檐上的暮色。屋顶上最后一抹余光正在消退，从金红色变成暗红，然后变成紫色，最后融进灰蓝色的天空里，像一滴墨在水中化开。

"那个人后来死了。大业十一年，突厥人打过来的时候，他在前线，没回来。"

院子里安静了一会儿。暮色从深蓝变成了灰蓝，屋檐上的瓦片在最后一点光中呈现出一种深沉的铁灰色。

他递一片甘草给沈知远。沈知远接过来，放进嘴里。甘草的味道在舌尖扩散开来，先是甜，然后是一种深沉的甘苦，在舌根处慢慢聚拢，然后消散。

"我昨天咳嗽的时候，忽然想起他的脸。很奇怪——我已经三十多年没想过他了。咳到喘不上气的那一瞬间，他的脸就出现在我面前——和三十多年前一模一样，穿着那件旧皮甲，侧着脸在看一份军报。然后咳嗽停了，他的脸也消失了。"

沉默了一会儿。院子里有人在远处说话，声音模模糊糊的，像从水底传上来。那声音飘了一会儿，然后被风吹散。

沈知远陪着韩慎在院子里坐到天黑。中间韩慎咳了两回——一次咳得轻，一次咳得重，重的那回他弓着背，一只手撑着石桌边缘，指节发白。指甲嵌进石桌的纹路里，那双手在石桌上留下了一个短暂的、被体温蒸出来的手印，然后慢慢退去。沈知远站起来想去倒水，韩慎摆了摆手，等咳嗽过去，慢慢直起身。

"没事。"

他在石凳上重新坐直，手指在膝盖上轻轻敲了两下——像一个习惯性的动作，像在确认自己的手还能动。

月亮升起来了。月光照在枣树的枝叶上，在院子里投下细碎的黑影。虫鸣声从墙角传来，一阵一阵的，没有固定的节奏，像是某人在暗处反复调试着一把旧琴的琴弦。墙角那只蟋蟀叫了几声，停了，又叫了几声，节奏从急促慢慢变缓，最后完全沉默。夜风从巷子口灌进来，吹动了韩慎额前的几缕白发，他伸手拢了一下，手指在额发上停了一息。

那天晚上沈知远回到家——平康坊的新宅——在院子里坐了很久。他没有点灯。月光把院子里那棵老槐树的影子投在地上，风一吹就晃动，像水面上的倒影。槐树的叶子在夜色中发出细密的沙沙声，断断续续的，像一阵很远的雨在下。

他忽然觉得，他能陪韩慎的日子，不多了。

他在黑暗里坐着，没有动。远处传来夜鼓的声音——咚——咚——闷而缓，在长安城的屋顶上滚过一遍又一遍。衣料里的余温被夜风吹散了，露出布料最初的凉意。他在鼓声里数着自己的呼吸，一下，两下，三下，数到后来忘了数到多少，又重新开始数。地上老槐树的影子在风里晃动了很久，然后安静下来。

有一天他也会像今天这样坐在黑暗中，但那一天的院子里不会再有一个咳嗽的老人等他去看他。

他站起来，月光在他转身时从他肩头滑落到背后。他走进屋里，门在身后关上，发出一声短促的木头的碰撞声，然后被夜色吞没。
