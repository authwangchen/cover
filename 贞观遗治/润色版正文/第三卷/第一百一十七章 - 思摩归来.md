# 第一百一十七章 思摩归来

贞观十一年春，阿史那·思摩随军回京。

他回来那天，沈知远在城门口等他。等了大约一个时辰，才看到远处官道上扬起的尘土——不是大军回京的阵势，是一小队人马，大约二十几个人。走在最前面的那个人骑着一匹杂色马，皮甲上有几处磨损，腰间挂着一把刀——不是唐军的制式横刀，是一把弯刀，刀鞘上镶着几颗绿松石。

是思摩。

沈知远差点没认出来。

思摩瘦了。不是原来那种少年人的清瘦——是一种被风沙和劳顿打磨过的瘦。脸上的线条比从前硬了，颧骨比从前高了，嘴唇干裂着，嘴角有一道没有完全愈合的细小口子。他的肤色比从前深了一个号——草原的日头和风沙在他脸上沉积成一层粗粝的底色。他下马的时候，动作里带着一种沉稳，不再有从前那种急于表现自己的急躁。

但他的眼睛——那双眼睛变了。

变的不是颜色。是看东西的方式。从前思摩看人的时候，目光中带着一丝试探，像一个刚学会走路的人，每走一步都在确认脚下是否结实。现在他看人的目光是直的——不会躲闪，不会游移，像一个已经知道自己站得稳的人。

他在沈知远面前勒住马，翻身下来。动作利落——没有多余的摆动，身体稳稳落地。靴子落在尘土里，发出一声闷响，然后是一个急促的脚步声——他朝沈知远走了两步，然后停住了。

"沈先生。"

他的声音也比从前沉了。

两个人站在城门口。进城的行人在他们身边来来往往，有人牵着驴，有人挑着担，有人赶着羊群。羊群从他们中间穿过，咩咩地叫着，留下一地黑色的粪粒。羊蹄踏在石板路上，发出细碎的嗒嗒声。思摩等羊群过去，笑了一下。他笑起来的时候，嘴角那道没愈合的口子牵动了一下，他下意识地用舌头舔了一下那道口子——尝到了血的味道，但他没有在意。

"我回来了。"他说。

那天晚上，思摩在沈知远家里吃饭。饭菜很简单——一盘煮羊肉，一碟腌菜，一壶酒。思摩在饭桌上沉默的时候比说话的时候多。他吃饭的速度很快，低头一口一口地吃，像在抢时间。筷子夹起羊肉时，肉汁滴在桌面上，他迅速用指腹抹了一下——在战场上养成的习惯，不浪费任何食物。吃到一半他停下来，把筷子放在碗上，看着碗里的羊肉，目光很安静，像在看一样他曾经很熟悉、但现在有些陌生的东西。

他在战场上养成的习惯——吃饭要快。因为不知道下一顿什么时候能吃上。

沈知远给他倒了杯酒。他端起来，没有立刻喝。他晃了晃酒杯，看着酒液在杯中打着转，一圈一圈的，像某种缓慢而持续的回忆在眼前铺展开来。酒液的光在灯下晃动，映在他的瞳孔里，像一小团跳动的火焰。

"战场上是什么样子？"沈知远问。

思摩沉默了一会儿。他抬头看着窗外。窗外是长安城的暮色，远处有炊烟升起来，在灰蓝色的天空里画出一条条歪斜的粉笔线。风从窗缝里钻进来，吹动油灯的火焰，灯影在墙壁上晃动了一下，又稳住了。

"很吵。"他说。

"什么？"

"战场。"思摩把目光收回来，落在酒杯上，"以前我以为战场是安静的——两军对阵，鼓声一响，所有人冲上去。但在那之前，很吵。人喊马嘶，兵器碰撞，有人在骂，有人在哭，有人在喊自己母亲的名字。那些声音混在一起——你分辨不出是谁在发出来的。"

他喝了一口酒。

"我第一次上阵的时候，手在抖。不是害怕——是刀太冷了。那天早上下了霜，刀柄冻得像一块铁。握着握着就不抖了。不是因为不冷了——是因为没时间注意。"

他讲这些的时候语气很平淡，像一个在讲述别人经历的人。他夹起一块羊肉放进嘴里，嚼了很久才咽下去，好像在反复咀嚼那些和羊肉一起回到嘴里的回忆。

沈知远看着他。当年在番学里，思摩会因为背不出《论语》中的一段话而急得脸通红。现在他坐在对面，给沈知远讲杀人的事，语气像在谈论天气——不是冷漠，是一种已经消化了太多的东西之后才会出现的平静。沈知远伸手拿起酒壶，给自己的杯子也倒了一杯。酒液注入杯中时发出细小的声响，在沉默的房间里显得格外清晰。

"你还想回去吗？"

思摩没有立刻回答。他把杯中酒喝完了，又给自己倒了一杯。

"我想过这个问题。"他说，"在战场上，有一次我趴在山坡上，等伏击。天快亮了，我趴在草地里，露水打湿了半边身子。我趴了很久——久到觉得自己已经变成了一块石头。那时候我想的不是打仗的事。"

"想什么？"

思摩看着杯子里的酒。

"想《论语》。"

沈知远愣了一下。

"'学而时习之，不亦说乎。'"思摩轻声念了一句，笑了一下，"趴在那片湿漉漉的草地上，脑子里忽然冒出这一句。然后我就知道——我读过的那些书，已经长在我身上了。打仗不会把它们打掉。杀人也不会。"

夜晚在沉默中慢慢加深。风从窗外吹进来，吹得灯焰歪向一侧，又慢慢直起来。思摩喝完了最后一杯酒，站起来，走到院子里。沈知远跟了出去。

月光很亮，照在院子里的石板地上。月光把石板照得像一面面模糊的镜子，反射着灰白色的光。思摩站在月光里，抬头看着天。他的背挺得很直——不是故意挺直的，是已经习惯了。在军队里待过的人，背会不由自主地挺直。月光沿着他的肩线滑下来，在他站立的地面上投下一道轮廓清晰的影子。

"沈先生。"

"嗯。"

思摩没有回头。他仍然望着天空。

"我变了吗？"

沈知远看着他的背影。那个背影比从前宽了一些。肩膀的线条比从前更加分明，月光照在那些线条上，在护甲覆盖不到的布料接缝处留下细密的阴影。有风吹过来，吹动他的衣摆，衣料拍打在腿上，发出轻微的声响。

"变了。"沈知远说，"但没变的是——你还是那个逼自己读书的人。"

思摩笑了一下。是那种不算高兴、但也不算悲伤的笑——介于坦然和苦涩之间的那种弧度。笑声很短，像一阵风从树梢上掠过。

"那就好。"

那天晚上思摩走后，沈知远一个人站在院子里。月亮已经升到了中天。他想起韩慎说过的话——"你做的那些事，可能你活着的时候看不到结果"。

思摩的变化让他看到了另一件事：有些东西——不管是制度的延续，还是人的成长——都需要时间。而时间本身是一种残酷的东西。它会让好人变老，让制度变脆，让少年变得满手老茧。

他低下头，看了自己的手。手背上也有了细纹——他已经在长安城过了十年了。他翻过手掌，掌心的纹路在月光下清晰可见，像一张被他走过无数遍的地图。

风吹过来。

他转身走回屋里，门在身后合上，发出沉闷的一声响。
