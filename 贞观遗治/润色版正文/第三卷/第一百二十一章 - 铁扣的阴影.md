# 第一百二十一章 铁扣的阴影

夜已经很深了。

沈知远坐在书房里，面前摆着那只木匣。他没有马上打开——每次打开之前他都要坐一会儿，让自己平静下来。他已经学会了不对这只木匣抱着太高的期望。期望越大，失望越深。但他今天还是打开了。

木匣的盖子发出轻微的咯吱声。锁扣弹开时，铁器碰撞的声音在安静的房间里显得格外清脆——像一滴冷水从高处落在一片薄冰上，碎裂成无数细小的回声。

那枚铁扣安静地躺在里面。

它和几年前没有什么变化。铁锈还在那个角度，纹路还在那个位置，那个"侯"字还是歪的——最后一笔明显偏右，像是刻字时手抖了一下。

他把它拿起来。

它很凉。铁的导热性好，即使在初夏的夜晚——它仍然保持着泥土的温度。老宅改建的那天，它在那截烧焦的木桩下面等了二十多年。现在它在沈知远的手心里，像一个沉睡了很久的人终于睁开了眼睛。

他把铁扣翻过来。在指腹下，那些锈蚀的纹路被轻轻地重新辨认——那歪斜的"侯"字，那磨平了的边缘，那在火中变形的棱角。他在几年的时间里反复摸过它无数次，每一个凹凸他都记得。他已经不需要看，只用手就能辨认出它的每一处细节。这枚铁扣像一页他无法合上的书。

他曾经以为有了这枚铁扣，他就有了武器。

但现在他知道——武器和证据不是一回事。

证据是完整的、清晰的、指向唯一的。比如一枚刻着"侯"字的铁扣，在归义坊火灾现场被发现——这可以是证据。但如果侯府说"这枚扣子早就丢了"或者"这是有人栽赃"——那铁扣就只是一块生铁。

他需要的不是一块铁。他需要的是一整条因果链。

他把铁扣放回木匣，但没有合上盖子。铁扣在烛光下泛着一层暗淡的橙黄色光泽，像一件被遗忘在深水底部的物品，被偶尔透过水面射下来的一缕阳光照亮了一下，随即重新沉入黑暗。

康洛说他要去河西查安氏。如果安氏的后人真的在幽州做小吏——那这条线指向的是什么？安氏和侯家之间，有什么联系？和归义坊的火灾又有什么联系？

这些问题没有答案。

他伸手合上木匣的盖子。锁扣咔哒一声扣紧。他把木匣放回书架的最高层——那里他伸手才能摸到，平时几乎不会碰到的地方。

他打开窗。

初夏的夜风从窗口涌进来，带着泥土和草叶的气味。长安城的夜很安静——安静到可以听见远处更夫敲梆子的声音，咚——咚——，两声，是二更天了。那只木匣站在书架的最高处，和旁边的书籍贴在一起，如果不刻意走过去仰头看，几乎发觉不了它的存在。

他吹灭了灯，在黑暗中站了一会儿。

他想，他已经等了太久了。久到自己都开始怀疑——他等的到底是什么。

是等一个完美的时机？还是等一个让自己不再犹豫的理由？

他想起魏徵说过的话。魏徵在他的值房里，端着一杯凉了半天的茶，用一种像沙子从高处滑落的低沉声音说：

"有些事，等不到最好的时机。最好的时机是你决定不再等的那一天。"

沈知远在黑暗中转过身。月光从窗口照进来，照在他的手背上，照亮了一片不规则的白色光斑。

他不再等了。

但他也不会鲁莽。

他会用那枚铁扣——但他要用在对的地方。
