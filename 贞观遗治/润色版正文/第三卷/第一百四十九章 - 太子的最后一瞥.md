# 第一百四十九章 太子的最后一瞥

贞观十三年，冬。

朝会。

沈知远坐在起居郎的位置上——他已经不是起居郎了，但今天前面的起居郎告病，他临时顶班。他已经升了中书舍人，正五品，坐在殿侧角落的记录桌上，笔搁在砚台边缘，墨已研好。殿内烧着炭火，暖意从地砖下升上来，但他握着笔的手指仍是凉的。砖面的热气只到脚踝以上几寸就消散了，往上是一层一层的凉，越往上越冷——像站在一座底部烧着柴火的冰窖里，温度在身体的不同高度上各不相通。他调整了一下坐姿，膝盖在案桌下碰到了桌腿的木面——木料是凉的。

今天的朝会与往常不太一样。

太子李承乾出列奏事。他今年十六岁了，身量已经长成，穿着太子的冕服站在殿中。冕服的垂珠在他说话时轻微晃动，折射着从殿顶漏下的日光，每一粒珠子都在同一节奏中闪烁。他在百官面前陈述他对河北道旱情的处置建议。他的声音很稳，条理清楚，引用了户部的数据和州县呈报的文书。听起来——没什么问题。

但沈知远注意到太宗的表情。太宗坐在御座上，手搁在膝上，姿态与平时无异。但他的目光没有落在太子身上——他落在太子手中的那份奏章上。他的目光不是"在听"的目光，是"在检查"的目光。像一个考官在看一份卷子，不是在欣赏内容，是在找错。

太子说完之后，大殿安静了片刻。

太宗没有立刻回应。那个沉默比平时长了几个呼吸——长到殿内的空气开始变紧绷，长到沈知远能在寂静中听到炭火在铜盆里细微的爆裂声。身边有人的衣料发出了轻微的摩擦声——那是有人在原地小幅度地调整重心。他也听到了自己手腕搁在案上的重量——整个手臂的重量压在手肘上，时间久了，手肘处传来一阵钝痛。太子的手在袖中微微调整了一下——沈知远看不到他的手，但他看到了太子袖口的布料轻轻地颤了一下，像一片被风拂过的水面，抖了一下就归于平静。那颤动太细微了——除了坐在侧面的他，大概没有人能看见。

"河北旱情——"太宗终于开口了，声音不高不低，"你的数字从何而来？"

"回父皇——来自尚书省户部的秋季统计。"

"户部的统计——是何时呈报的？"

"——九月。"

"现在是几月？"

太子沉默了一瞬。那一瞬很短，不到一次呼吸的时间。但在朝堂上，那一瞬比什么都长。沈知远在这一瞬中听到了一阵风穿过殿顶瓦隙的声响——尖细而绵长，像一根被拉紧的铜丝在空气中震颤。他看到太子冕服上的垂珠在这一瞬停止了晃动——那是一个少年全身僵住时，连最细微的晃动都会同时停止的瞬间。

"——十一月。"

"两个月的差。"太宗的声音没有提高，但每一个字都比前一个字更清晰，"两个月，河北的情况会变。你知道变了没有？"

太子没有回答。

沈知远低下头，看着起居注上空白的纸页。他应该记录下这场对话，但他的手没有动。因为那不是他该记录的内容——那是一个父亲用一个问题摧毁了他十六岁儿子的自信。纸页上的方格横平竖直，每一个格子里只有横线和竖线的交叉——像一面空的棋盘，等着某个人在上面放上棋子。但他迟迟没有落笔。

他最终还是写了。笔尖落在纸面上，写下："太子奏河北旱情，陛下问其数据时效，太子不能对。"

他写完之后，没有再看太子。但他听到——有什么东西从太子手中滑落了。不大，应该是笏板的边缘碰到了衣料。不是摔落的声音，只是一个物体从被握紧的状态中滑出一点、碰到了布面的声音。

但他在余光中看到——太子的手在袖中微微颤抖。幅度不大，但持续——像一根弦在被拨动之后尚未完全停止的余震。他想起了一件事：三年前，这个孩子九岁的弟弟坐在御座左侧时，目光在长孙无忌脸上多停了一瞬。那个九岁的孩子，如今正在被他的父亲当着满朝文武的面，一点一点地摧毁。

他低头。起居注的那一行字已经写完了。墨迹还没干，在纸面上反射着微弱的光。他等墨迹干透，然后翻过这一页，开始记录朝会的其他事务。他的笔动得很正常——笔画稳定，字迹工整——和平时没有任何区别。

散朝后，沈知远最后一个走出大殿。

殿门外的风扑面而来，裹着冬天特有的干冷气息，和殿内的炭火温暖形成了几乎是锋利的对比——像从一个世界走进了另一个世界。他走过广场时，看到太子的背影消失在宫门拐角。那孩子走得很快，比平时快，像在逃离什么东西。他身后的披风被风掀起又落下，边缘在灰色的宫墙映衬下反复起落。他没有回头。一次也没有。

他在心里说：我知道你将来会做什么。我知道你为什么会做那些事。但我不能说——因为说出来，才是真正害了你。

他收回目光，走回中书省。手中的那卷起居注，比平时显得重了一些——手腕上的重量感像是比来时多了一卷纸。他握着它的姿势没有变，但每走一步都能感到那卷竹简在手中向下坠的力度，像一块石头被慢慢从水底拉出水面时，在水面上越来越大的重量。一阵风吹过来，他停下来侧了一下身，用手挡了一下风。起居注的边页被风掀起了一角又落回原处。

他没有回头再看那个方向。他继续往前走，走进中书省的院门。进门的时候，他的手指已经冻得不太灵活了——握笔太久的手指，被冷风一吹，指节间的每一个关节都在发出无声的抗议。他用另一只手搓了一下手指，然后推开了值房的门。
