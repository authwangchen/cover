# 第一百四十二章 长孙无忌的拉拢

太子的信在沈知远案头搁了三天。他还没有回复——他在等。

第四天，另一个消息来了。

消息是通过中书省的一个同僚传到他耳朵里的。那个同僚姓陈，和陈咬金是远亲，平时和长孙无忌那边的人有走动。一个午后，陈舍人端着茶碗凑到他旁边，左右看了一下，压低声音说了一句话：

"长孙仆射那边——有人问起你。"

沈知远端着茶碗的手没有晃动。

"——说什么？"

"说你——在中书省做得很不错。说你是个人才。"

陈舍人说完这句话，喝了一口茶，像什么都没有说过一样，转身走回自己的位置去了。

沈知远坐在那里，看着碗里的茶汤一点点凉下去。绿色的叶片在水中慢慢沉底，铺展，像一小片一小片从树梢上脱落、被水流带到河床上的叶子。他在心里把那句话翻来覆去地揣摩着。

"说你是个人才。"

这不是闲聊。这是一句经过选择之后才传出来的话。长孙无忌那边的人在试他——看他对这个"人才"的评价有什么反应。

他想起了朝会上长孙无忌设的那个陷阱。想起了长孙皇后去世那天，长孙无忌站在廊柱旁边的表情——太正常了。正常得让人害怕。

现在长孙无忌在拉拢他。不——不是拉拢。是试探。看他会不会因为太子的接触而倒向太子。如果倒向太子，长孙无忌就需要提前对付他；如果不倒向太子，长孙无忌可能暂时放他一马。

他放下茶碗。茶已经凉了。

午后，他走到庭院中站了一会儿。庭院里种着几株石榴树，正在开花，火红色的花朵在午后的阳光下像一小团一小团的火焰，明艳得有些刺眼。他在石榴树下站定，透过花叶之间的缝隙望着天空——他同时被太子和长孙无忌盯上了。被夹在中间的人，出路不是向左也不是向右——是往前走。

他不会被拉拢。

他不会倒向任何一边。

他只会做他自己要做的事。他的手还有制度要写，有骨片要查，有铁扣未竟的事要继续。他只有保持独立——站在最高处——才能看清整个棋局。一旦成为任何一个人的棋子，他就再也看不到棋盘的全貌了。

风吹过来，几片石榴花的花瓣落在地上。他低头看着那些红色的花瓣——落在灰白色的石板地上，像血迹一样鲜明。他转身走回值房。在案前坐下，拿起笔，铺开纸。太子的信他仍然没有回复。长孙无忌那边的试探他也没有回应。

他在稿纸上继续写着关于"边镇任期"的草案。写了几个字，停了一下，又继续。他知道这样下去，两边的耐心都会耗尽。但他别无选择。

在风暴的中心，唯一的生存方式——就是继续做你该做的事。像一棵在洪水中站直的树——把根扎得更深。

他在那份草案的末尾加了一条备注："边镇都督任期，以三年为限。期满不得连任——惟战时暂缓。战事毕，续期自动废止。"

这是他今天写的最后一行字。
