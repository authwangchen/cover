# 第一百二十三章 房玄龄的老年

贞观十一年的夏天来得格外缓慢。四月了，长安城还裹着春末的凉意，槐花比往年晚开了将近半个月。树梢上那些细小的淡黄色花苞一直在等待一场合适的升温，迟迟不肯绽放。去中书省的路上，他注意到这个细节——也说不上为什么，只是觉得今年的风刮在脸上时还带着一点残冬的锋利，不像往年那样一入四月就温和了。他已经在长安住了十年，对这座城市的气候已经熟悉得如同熟悉自己的呼吸。

他看到房玄龄的时候是五月的一个下午。

那时他正在从中书省回门下省的路上。走过长廊拐角时，房玄龄站在廊下，手扶着廊柱，低着头。不是在看什么东西——只是低着头。他站在那里的姿态和姿势都不仿佛在休息，又仿佛在等某一阵眩晕过去，等视线重新变得稳定。走廊里的穿堂风从他身边经过时，吹动了他官袍的下摆——布料的拂动声在安静的长廊里清晰可闻，如一页发黄的纸在风中被反复翻动。

他停住了脚步。

他没有走过去。他站在长廊的另一端，隔着几根廊柱的距离，看着房玄龄的背影。那个背影比他记忆中瘦了很多——官袍在肩胛骨的地方塌陷下去，形成一个不自然的凹陷，仿佛一件挂在衣架上的衣服被抽掉了架子。夏日午后的光线从屋檐的缝隙中斜射进来，落在那些布满细小灰尘的空气中，形成一道道模糊的、倾斜的光柱。

房玄龄站了大约十几个呼吸的时间。然后他直起身，扶了扶头上的幞头，继续往前走。他的步子还是稳的，但那种稳和从前不一样了——从前的稳是从容，现在的稳是需要用力才能保持的东西。他左脚迈出去时鞋底与地面接触的声音比右脚更响——不是故意的，是身体已经无法均匀分配重量了。

沈知远没有跟上去。

他在原地站了一会儿，然后才继续往门下省走。他注意到廊柱下的石板上有一小块潮湿的痕迹——那是房玄龄刚才站着的时候手心里渗出的汗水滴在地上形成的。他低头看着那块痕迹，没有踩过去，绕了一步。

他把目光移开了。

一个月后，他在一次中书省的值务会议上亲眼看到了房玄龄的衰老。房玄龄在读一份奏章时，声音顿了一下——不是因为内容，是他的嗓子忽然干涩了，发出一声短促的、不受控制的咳嗽。他端起茶杯喝了一口，继续读。但在场的每一个人都注意到了那个停顿。房间里安静了一瞬间——一种短暂的、所有人都心照不宣的安静。没有人看房玄龄，但每个人都在用余光确认自己看到的东西。沈知远听到有人轻微地调整了一下坐姿——那是太紧张之后的反应——竹制的坐席发出一声细微的吱响。

沈知远坐在末席，看着房玄龄。他的目光落在房玄龄握着茶杯的手上——那双手从前握笔时如行云流水，现在指尖发颤，杯中的水面也随之晃动出一道道细密的波纹。水面的反光在天花板上不断晃动，如一道被惊扰的光，找不到安放的位置。

会议结束后他走在房玄龄后面。走廊里没有别人，他快走两步，赶上了房玄龄。脚步声在空荡荡的长廊中回荡着——两个人的脚步交替响起，一个稳重但缓慢，一个年轻而急切。

"房相。"

房玄龄回过头。他的眼睛还是清明的，但眼角有了一些浑浊的痕迹——不是看不见，是看得太久了以后留下的磨损。

"嗯。"

"您的身体——"

"老了。"房玄龄的声音响起。很平淡的两个字。如同在说天要下雨那般平淡。

他沉默了一下。他注意到房玄龄的肩——那件官袍在肩部的位置已经不再平整了，有了一些细小的褶皱，仿佛一间老屋的房梁在一场没人注意到的地震中悄悄移了位置。

"我让太医——"

"不用。"房玄龄摆了摆手。他的手在空气中划过时，衣袖带起一阵极轻的风——落在沈知远的脸上，几乎感觉不到，但他还是感觉到了。"太医看不好老。老不是病。"

他在走廊里走了两步，停下来，回头看着沈知远。他的动作比从前更慢——慢到沈知远能看清楚他转身时每一块肌肉和骨骼的活动，如一架用久了的机器，每一个零件都在发出哀求般的声音。走廊深处的光线照在他的侧脸上，将他苍老的轮廓镀上一层金中带灰的混合色。

"你知道我在你这个年纪的时候在想什么吗？"

"在想什么？"

"在想——我还有多少时间。"房玄龄说，"我十七岁入仕，今年六十三了。四十六年。四十六年——我做了很多事。也错过了很多事。"

他在廊柱边站定。夕阳从西边照过来，把他的影子拉得很长。他的影子一直延伸到走廊的尽头，投在对面的墙壁上，随着他的呼吸微微上下移动着。

"我以为我还能再做十年。但现在我知道——不可能了。"

"房相——"

"我不是在诉苦。"房玄龄打断他，"我是在告诉你一个事实：你的保护伞，一把一把地在收起来。韩慎是一把。魏徵是一把。我也是一把。"

他看着沈知远，目光平静而坦率。

"你得学会没有伞的时候怎么走。"

那天晚上，沈知远没有睡好。他躺在床上，听着窗外夏夜的虫鸣。那些细碎而持续的声音从院子里传进来，没有固定的节奏，仿佛无数细小的齿轮在黑夜的暗处旋转。他在床上翻了个身，竹席擦过皮肤时有一阵轻微的凉意——但很快就被体温驱散了。夜晚的风吹动窗扇时发出极轻的叩击声，仿佛有人在窗外用指节敲着木框。

他想起了很多事情——韩慎的咳嗽，魏徵手掌心里的血，房玄龄扶在廊柱上的手。那些他在几年中依次失去的人，如一排依次熄灭的蜡烛，每一盏都在他面前慢慢暗淡下去，明灭不定。

他不怕失去靠山。

他怕的是——当这些人都消失之后，他还有没有力气继续走完自己没有走完的路。

第二天早上，他在中书省门口遇到了房玄龄。房玄龄穿着一件洗得发白的旧官袍——他平时不穿旧衣服，今天穿了，大概是因为没有来得及换。他的脚步比昨天稳了一些——大概休息了一夜恢复了些许体力。他看到沈知远，没有提昨天的话。他只是点了点头。

沈知远也点了点头。

有些话不需要每天都重复。沉默里的默契，有时比言语更深。两个人在中书省门口站了片刻，谁也没有再开口。晨风吹过，将房玄龄袍子的下摆吹起来一角，又落下。那件洗得发白的旧官袍在晨光中泛着一层柔和的白。

然后房玄龄转过身，朝政事堂的方向走去。他的背影在走廊的尽头渐渐变小，直到消失在一扇门的后面。沈知远看着那道背影消失，才转身走自己的路。
