# 第三十三章 房玄龄的功课

四月底，房玄龄把沈知远叫到了中书省。

这次没有午饭。

沈知远到的时候，房玄龄正坐在案前，面前摊着一幅地图——长城沿线的边防图。地图很大，几乎铺满了整张案面，纸张已经泛黄，边角卷起，看得出用了很多年。山川河流的线条用墨线勾勒，城塞关隘用朱砂圈出——从凉州到幽州，沿着长城蜿蜒的弧线，散落着十几个朱红色的圆圈。

"坐下。"

沈知远坐下。

房玄龄没有抬头。他的手指沿着地图上的长城线从西向东缓缓滑过——骨节分明的食指，指甲修剪得极短，在粗糙的纸面上发出轻微的沙沙声。他从凉州滑到甘州，滑过肃州、灵州、夏州，一路向东，直到幽州。

"从凉州到幽州，大唐在边境上设了九个都督府。每个都督府管几个州的军事。你猜——这些都督的任期是多久？"

沈知远看着那幅地图。他的目光跟着房玄龄的手指走了一遍，从西到东，一条漫长的防线。他在秘书省看过这些都督府的军册——每个人的名字、到任年份、出身背景，他都有印象。

"——没有定例。有的三年，有的五年，有的——十来年了。"

"对的。"房玄龄抬起头。他的眼睛在午后的光线下显得有些疲惫——眼角的皱纹比去年深了一些，鬓边添了几根白发。"凉州都督李大亮，贞观元年到任，到现在快三年了。幽州都督——从武德年间就一直在任上。你知道为什么？"

"——因为没人愿意换？"

"不是没人愿意换，是不敢换。"房玄龄的手指用力在地图上点了一下——指甲在纸面上留下一个浅浅的印记，"幽州北接突厥，东临契丹。换一个不熟悉边情的人去——万一出事，谁也担不起。"

沈知远明白了。那不是制度的决定——是现实的选择。在太平年月，你可以从容地安排官员轮换。但在边境上，一着不慎就是战争。没有人愿意为"轮换"这个制度付出战争的代价。

"——所以边将不换，不是制度的问题，是现实的无奈。"

房玄龄看了他一眼。那一眼和平时不一样——不是传授课业的慈祥，也不是考校学生的审视。那是一种更接近于"你说到了关键处"的认可。

"你说到点子上了。"

他站起来，走到窗边。

窗外的庭院里，几个小吏正抱着一摞公文匆匆走过。中书省的院子比秘书省更安静——没有闲谈声，没有脚步的纷乱，只有纸张翻动的窸窣声从各个值房里传出来。房玄龄背对着沈知远，看着窗外，沉默了一会儿——那种沉默像是在等一个不适合公开说的时刻过去。

然后他开口了。声音比刚才低了一些。

"我去年在整理奏章时，发现一个奇怪的事。幽州都督每年的边防奏报——内容几乎一模一样。"

他转过身来。阳光从他背后照过来，让他的面容半隐在阴影里，看不清表情。但他的声音很冷静——冷静得像在说一件跟自己完全无关的事。

"你明白我的意思吗？"

沈知远愣住了。

奏报内容几乎一模一样。幽州都督三年的边防奏报——"边患已平，防务牢固"——用词有变化，但说的都是同一句话：没问题。

"——奏报是抄的？"

"——没有证据。"房玄龄的声音不带任何情绪，"但三年用同样的措辞说'边患已平，防务牢固'——你觉得，真的'牢固'吗？"

沈知远没有回答。

屋子里安静了片刻。窗外有小吏的脚步声由远及近，又由近及远。房玄龄走回案前，把地图慢慢地卷起来。他的动作很慢，像是在用这个动作争取思考的时间。

地图卷好之后，他抬起头来。

"你写的那份《论边将久任之患》——拿来给我看看。"

沈知远愣住了。

"——房公怎么知道——"

"秘书省的人不嘴紧。"房玄龄的语气平淡得像在说今天天气不错，"你写了策论的事，已经有人在传了。"

沈知远沉默了。

策论他放在住处——藏在墙缝那块松动的砖后面，用油纸裹着，压在砖和土墙之间。他觉得自己的住处足够隐秘——一个城西旧巷子里的小院，门口有一棵枣树，邻居都是普通人家。但房玄龄知道他在写策论——那长孙无忌大概率也知道了。

"——策论还在草稿阶段，学生想再润色一下。"

房玄龄看着他。那目光很淡，但穿透力极强——像是隔着一层薄纱在看一件东西，那层纱很薄，什么都挡不住。

"你是想润色——还是不敢交？"

沈知远没有回答。

房玄龄坐回案前，拿起笔。笔尖在砚台上蘸了蘸，发出一声极轻的吮吸声。他在一张便笺上写了几个字，然后抬起头：

"五天——五天之后，把定稿拿来。"

他放下笔。

"——然后我替你看看。"

沈知远说不出话来。

五天。时间很紧。但他知道——这是房玄龄给他的一个机会。不是一个前辈对后辈的提携——是朝堂上一个掌舵者对一颗棋子的布局。房玄龄也想看看——这份策论递上去之后，会掀起多大的浪。

不是因为房玄龄关心他这个人。

是因为房玄龄也想知道——那份奏报是不是真的在作假。

沈知远站起来，躬身行了一礼："——学生明白了。"

他退出来的时候，中书省的回廊里有风吹过。午后的阳光斜照在廊柱上，在地面上投下一道一道平行的光影。他走在那些光影之间，脚步比来时快了一些。

五天。

他有一整个冬天的草稿。但房玄龄要看的——是他敢不敢把它们变成真正的奏章。
