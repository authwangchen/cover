# 第二十五章 府兵暗访

家宴之后，沈知远决定做一件大胆的事——亲自到京畿的折冲府看一看。

折冲府是大唐府兵制的基层单位，每个折冲府管几百到上千名府兵，平时务农，战时出征。兵器甲胄自备，马匹也是自备——听起来合理，但档案中看到的数目显示：负担正在变得越来越重。那些数字不会说谎——逃亡率、装备合格率、欠缴兵器数——一年比一年触目惊心。

找了一个理由——说秘书省要核实京畿诸府的档案数目。向上级申请去就近的折冲府实地核对。审批出乎意料地顺利，三天后批复就下来了。骑马出了城。

京畿的折冲府设在长安以西四十里。骑了将近两个时辰才到。官道越走越窄，两旁的田野越来越荒凉——有些耕地已经荒了，长满了齐膝高的野草，在早春的风里枯黄地摇。路边的村庄看起来很静，静得不正常——看不到小孩在门口玩耍，看不到烟囱冒烟。有些屋子的门板歪斜着，很久没有人住过了。

折冲府的都尉是一个姓刘的中年汉子——粗壮的关中口音，嗓门大，说话的时候喉结上下滚动。他看到朝廷来人时，先是警惕地上下打量了几遍，狐疑的目光在沈知远的官袍上停了好久，看完文书才放松了一些。

"校书郎——我们这地方小，没什么好看的。"

"我是来核对簿籍的。不妨事。"

刘都尉犹豫了一下，然后带着他转了转。

折冲府的营地在山脚下一片平地上。正中有个校场，不大，但踩得很硬实——土层被无数双脚踩成了深褐色，一块巨大的干泥板。四周是营房——土墙茅顶，墙皮剥落处露出里面的泥砖，有几间已经塌了半边，露出里面东倒西歪的木梁。兵器架上插着一些刀枪，刃口有锈迹。伸手摸了一下其中一把刀的刀脊——粗糙的触感，指腹蹭过的地方留下一道黄褐色的痕迹。

"——这些兵器，是朝廷配发的？"

刘都尉摇头，动作干脆："哪能啊。府兵的兵器是自己打的。朝廷只配一部分——弓、箭镞、长槊的头。刀是自己打，甲也得自己置办。"

"一副甲要多少钱？"

刘都尉想了想，掰着手指头算了一下："好一点的要五千钱。"

五千钱。按唐初的米价，差不多是十石米。一个府兵的家庭，一年种地的收入，除去口粮和赋税，剩下的钱买一副甲要攒好几年。而且甲还会磨损，隔几年就要换——根本买不起。

没有继续问。走到校场边，看到几个老兵坐在地上修弓弦。地上铺着一张破苇席，席上散着弓臂、牛筋和骨片。他们的手很粗，指关节突出，青筋暴起——一看就是常年干体力活的人，指甲缝里嵌着洗不掉的泥和铁锈。

蹲下来："老丈——当了多少年兵了？"

老兵抬头看他，眼神有些浑浊——眼白泛着黄，不知道是年纪大了还是在风沙里待久了："从大业年间就当了。快二十年了。"

"——二十年，那打过仗吗？"

"打过。辽东那一仗，我去了。"

"活着回来了？"

"回来了。"老兵低头继续修弓，牛筋在粗糙的手指间滑动，"去的时候三千人，回来的不到八百。"

沉默了片刻。目光落在地上那些弓臂上——木质发暗，皮革磨得发亮，每一把都有被修复过多次的痕迹。

"——那现在日子好过些了吗？"

老兵停下手里的活，抬起头来，看了他一眼。那个眼神里没有什么特别的情绪——不是愤怒，不是感激，不是抱怨。只是一种被问了很多次相同的问题之后剩下的……麻木。他低头继续修弓。

"——好过？公家不催粮的时候就好过。征人的时候——就不好过。"

说完就不再说话了。手指继续缠绕牛筋，一圈，又一圈。

沈知远站起来。腿蹲得有些麻了，站直的时候膝盖嘎巴响了一声。在营地里又走了一圈——看到很多年轻的面孔，有些看起来不过十六七岁，瘦得只剩骨架，锁骨在领口上高高地突出来。穿着破旧的衣服，脚上踩着草鞋——不是正式的军靴，就是草鞋，用麻绳编的，踩在冻硬的泥地上。冬天还没完全过去，很多人还没有棉衣。

和其中一个少年聊了几句。那孩子说家里有八口人，两亩薄地。他是长子，服兵役可以免一部分赋税，所以家里让他来了。说话的时候一直在摸自己的袖口——袖口已经磨飞了边，露出里面发黑的棉絮。

"你穿这么薄——冬天怎么办？"

"——熬呗。"

没有再问。走出折冲府的时候，天已经有些偏西了。阳光斜照着营地，在那些塌了半边的营房屋顶上投下长长的影子。

刘都尉送他到门口。站在木栅栏边，他犹豫了一下，搓了搓手，说了一句："校书郎——您来这一趟，是做什么的？"

沈知远看着他，想了想，没有说真话："核对档案。"

刘都尉沉默了一会儿。他低下头，用靴尖碾了碾地上的土，然后抬起头来说了一句分量很重的话：

"——官爷，以前也来过核对档案的。核对完就没消息了。"

听出了这句话里的分量。不是一个都尉的抱怨——是地方上所有人对朝廷所有检查的普遍看法。来的时候轰轰烈烈，走了就没了下文。检查的写在公文里，被检查的活在现实里。

没有保证什么。没有说"这次不一样"。只是说——

"这次——会有消息的。"

翻身上马。马打了个响鼻，迈步沿来路返回长安。

路上起了风。早春的风还带着冬天的寒意，吹在脸上又冷又涩。想起那个老兵的话——"去的时候三千人，回来的不到八百。"想起那个少年的话——"熬呗。"想起那些锈迹斑斑的兵器，那些塌了一半的营房，那个都尉送他出门时欲言又止的表情。

回到长安时，夜鼓已经过了。城门的守卒认出了他的官袍，犹豫了一下，还是放了他进城。长安城内的街道已经安静下来，只有几盏路灯还亮着，昏黄的光在水洼里映出一点模糊的倒影。

沈知远没有回家。他直接去了戴胄的府邸。

戴胄已经睡下了，被仆人叫起来，披着一件旧棉袍，趿拉着鞋走出来见他。头发散着，没有束冠，看起来比平时老了好几岁。

"——你这么晚来，出什么事了？"

沈知远站在院子里。夜风把衣摆吹得猎猎响，地上的枯叶被卷起来，在脚边打着旋。

"戴明府——我今天去了折冲府。"

戴胄看着他，等他继续说。

"我在路上看到的事——比在档案里读到的，严重得多。"

说这话的时候，声音很平静。但手指——握成拳，指节发白，指甲掐进掌心。

戴胄沉默了很久。然后他关上了院门，把冷风挡在外面。

"——进来说。"

那一夜，戴胄书房里的灯亮到了三更。
