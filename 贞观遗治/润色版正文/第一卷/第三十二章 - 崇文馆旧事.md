# 第三十二章 崇文馆旧事

四月中旬，沈知远以校书郎的身份回了崇文馆。

不是他主动要来的——是馆丞递了一封信，说有几卷隋末战报的存档需要核验，因年头久远，竹简散了，需要秘书省派人来重新编录。沈知远拿着信看了片刻，把它折好放进怀里。

他已经大半年没有踏进过崇文馆的门了。

从秘书省出来之后，他就没回去过。不是不想——是没有理由。但现在理由送上门了。

他走到馆门口时，守门的隶卒已经换了人——不是去年那个爱打瞌睡的老卒了。新来的年轻隶卒不认识他，伸手拦了一下："什么人？"

"秘书省校书郎沈知远——奉命来核卷宗的。"

隶卒看了他的腰牌，连忙让开。沈知远跨过门槛，脚步在青砖上停顿了一瞬。

崇文馆还是老样子。

墨香混着旧纸的味道——那种干燥的、略带苦涩的气味，是书卷和木架在漫长的岁月中共同发酵出来的。书架顶天立地，一排排延伸到深处的暗影里，每一排都塞满了卷轴和册子。光线从高窗斜斜地落下来，在空气里拉出一道道明亮的光柱，灰尘在光柱中缓缓浮动，像是被时间凝固的金色微粒。

一切和他第一天来时一模一样。

但又什么都不一样了。

他站在门内，没有立刻往里走。

去年秋天他第一次走进这扇门的时候，还是一个刚被房玄龄从京兆府大狱里捞出来的流民书生——穿着韩慎的旧袍子，袖口磨得发白，走路时都不敢抬头看那些书架。他坐的那张案几在第三排靠窗的位置，案面上有一道很深的刀痕，不知道是哪一届的学生刻的。他每天卯时入馆、酉时出馆，像一个沉默的裁缝——一针一针地抄书，不敢多看一眼不该看的东西，不敢多说一句不该说的话。

现在他穿着校书郎的青色官袍回来——品级不高，但那是正儿八经的朝官服色。腰间挂着铜鱼袋，走路时轻轻碰撞，发出细微的声响。馆里新来的学士不认识他，但有人认出来了——一个正在角落里整理卷宗的年轻小吏，看到他时愣了一下，小声对旁边的人说了句什么。旁边的那个抬头看了他一眼，目光里有好奇，有打量——和去年那些人看他的目光完全不同了。

馆丞从里间迎出来——还是那个人，下巴上的那颗痣还在，但头发似乎白了更多。他满脸堆笑："沈校书郎——好久不见，好久不见！"

沈知远拱了拱手。他注意到馆丞的笑容和去年不一样了——去年是"给我好好干活"的那种居高临下的客气，今年是"您升官了以后别忘了老地方"的那种热络。

他看到自己曾经坐过的那张案几。上面已经坐着另一个抄书郎——一个年轻的、瘦削的身影，正低着头伏案写字，姿势和他去年一模一样。连坐的位置都没变——第三排靠窗，阳光从窗外斜照进来，落在那人的手背上。

沈知远看了一会儿，移开了目光。

馆丞把需要核对的卷宗搬出来——是一批隋末的战报存档，竹简确实有些散了，有几根的编绳断了，散成一堆。沈知远在靠窗的——不是他以前的位置，是另一张空着的——坐下来，开始一卷一卷地翻。

他翻得很慢。

不是因为他看不懂。是因为这些战报他太熟悉了——大业十年到十四年的战报，记录的是一座王朝从生病到死亡的全过程。

翻到第五卷的时候，他的手停了。

这是一份大业十三年的战报。

上面记录的是隋将王世充与李密的交战情况。普通的战报——某月某日，某地交战，胜负如何，伤亡多少——和档案架上其他几百份战报没有本质区别。但沈知远注意到一个细节：在战报末尾，附了一份兵员补充清单。

补充的兵源——不是府兵。是"募士"。

大业十三年，正是隋朝全面崩溃的前夜。府兵制已经基本失效——没有足够的田分给府兵了，府兵养不起自己了。各地将领开始自行募兵——用朝廷的名义，花朝廷的钱，但招来的人只认将领的账。募来的兵，跟将帅走，不跟朝廷走。

沈知远把这份战报和那份清单放在一起，在午后的阳光下看了很久。

阳光落在竹简发黄的表面上，那些刻字在光影中格外清晰。他想到一个问题：贞观三年的大唐，和隋大业十三年的洛阳——看起来是两个世界。盛世与末世，中间隔着改朝换代的血火。

但从制度上看——

如果府兵制继续这样走偏下去——如果均田制继续被兼并侵蚀——会不会在某一天，大唐的将领也开始"自行募兵"？

那个日子不是贞观三年，不会是十年内——那会把时间拉得更长，长到在场的人都看不到那一天。但种子已经埋下了。

他轻轻合上卷宗。

然后他打开另一份——崇文馆的借阅登记册。

他翻到最近几个月的记录。在意料之中的是——《隋书》《晋书》《五代史》的借阅频率最高——朝堂上最近在修前朝史，这些书被反复调阅，很正常。

但有一卷书不在他的意料之中。

《河北边防策》——被借阅了三次。借阅人登记册上的记录：长孙府。

他目光在那行字上停留了片刻。长孙无忌在查河北边防的资料。河北——和突厥接壤的地方，和契丹接壤的地方，将来安禄山起兵的地方。

沈知远把登记册合上，放回原处。

他没有再多看。他把需要核对的卷宗清点好，签字交接。

但走出崇文馆大门时，他在台阶上停了一下。午后的阳光有些晃眼，他眯起眼睛。

他脑子里一个念头正在成形——像一颗埋在土里的种子，刚刚顶开第一层泥土。
