# 第二十九章 戴胄的劝告

以工代赈的扩展方案通过后，沈知远忙得脚不沾地。

又回到了工地——这一次是长安到蓝田的官道。冬日的渭北平原一片枯黄，寒风从秦岭方向吹来，刮在脸上刀割一般。每天骑马在两个工地之间来回跑。马是老马，毛色黯淡，跑起来颠得厉害，坐鞍上的皮革磨得发亮。一个冬天下来，手和脸都皴了，颧骨上裂开了几道浅浅的口子，一吹风就疼。

工地上的人比上次更多。将近两千人——男人、女人，还有半大的孩子。他们蹲在冻得发硬的泥地里砸石头、挖土、挑担。有人手上缠着破布条，有人光着手，指节冻得发红。每天到工地第一件事不是看进度——是数人。看今天少了谁。

少了一个人，就是一条命。

少的人不多。大部分人都撑了下来——因为每天能领到一碗热粥、两个饼。粥是粗粮熬的，米粒不多，但烫。烫的粥喝下去，人才能活。

戴胄看在眼里。有一天下工后，天已经完全黑了，工地上的人陆续散去，只剩下几堆篝火还在燃烧。火星在夜风中飘散。戴胄叫住沈知远，让他跟自己走一趟——不是回京兆府，是去了戴胄自己在永宁坊的住处。

戴家在长安的宅子不大，三间正房，一个小院。院子里种着一棵老槐树，树干上挂着一串干茱萸。门是旧的，门轴开关时吱呀作响。

戴胄的妻子迎出来，是个四十来岁的妇人，衣着朴素，头上簪着一根银簪，簪头已经磨得发亮。她看到沈知远，没有多问，只是点了点头，转身进了厨房。过了一会儿，端出一碗热气腾腾的面汤来。

面汤里有几片羊肉，飘着葱花和姜末的香气。坐在堂屋里，端着碗，手还在发抖——骑马骑的，冷得。面汤的热气扑在脸上，烫得鼻尖发红。低头喝了一口——咸淡正好，肉香在舌头上化开。忽然意识到，这是这个冬天吃到的第一口像样的饭。

戴胄在他对面坐下。他没有吃饭，面前只有一杯茶。等沈知远喝了三口汤，才开口。

"你太急了。"

端着碗，没有回应。

"我不是说你做事急——做事急是对的。我是说你——在错的时间里，做了太多对的事。"

放下碗，碗底碰在桌面上发出一声轻响："——什么是对的时间？"

"别人做好准备的时间。"戴胄说，"你每做成一件好事，就有一批人不高兴。那些不高兴的人——现在还没出手，不是因为认可你。"

他端起茶杯，喝了一口，目光越过杯沿看着沈知远。

"是因为还没到出手的时候。"

看着碗里的面汤。热气模糊了视线，但没有擦眼睛。沉默了很久，窗外的风从窗缝里挤进来，吹得油灯的火焰晃了一下。

"——戴明府，我知道我的处境。但有些事情——如果现在不做，以后就没有机会了。"

"什么意思？"

"——天灾不等人。受灾的人不等人。朝堂上的机会——也不等人。"

戴胄沉默了。

他把茶杯放在桌上，没有喝。他低下头，看着桌面上一道陈旧的木纹，看一件很久以前就认识的东西。

"你是我举荐的人。你出了问题——我脱不了干系。"

"——学生知道。"

"知道你还不停？"

抬起头，看着戴胄。油灯的光正好落在他的半张脸上——他的眼角已经有了皱纹，鬓角也有了几根白发。他是那种看起来不太像大官的人——衣着朴素，面容清瘦，坐在自己家的堂屋里，一个教了一辈子书的先生。

"——戴明府，您当初为什么举荐我？"

戴胄没有回答。

替他说了："因为您知道——有些事情，需要一个不怕死的人去做。"

院子里安静了。

炭火在角落里噼啪地响了一声——有什么东西在火里炸开了，溅出一小簇火星。隔壁屋里传来戴胄的妻子收拾碗筷的细微水声，瓷碗碰撞的声响轻而清脆。

戴胄放下茶碗。他的力气用得比平时大了一点，碗底磕在桌面上，发出沉闷的一响。

"——你说得对。"

"我举荐你，是因为我自己做过太多怕死的事。"

没有说话。

"我在隋朝做官的时候——"戴胄的声音很缓慢，说一件很久没有对人说起的事，"看着朝廷一天天烂下去。我知道不对。但我不敢说。"

他低着头，目光落在自己放在桌面的双手上。

"说了，会丢官。丢官了，家里就没有收入。没有收入——家里人就要挨饿。"

"——所以我什么都没说。"

"后来隋朝亡了。我活着。但那些死了的人——"

他停顿了一下。

"——不会原谅我。"

堂屋里很安静。油灯里的灯芯烧出一个火花，又缩了回去。看着戴胄的手——那是一双写了大半辈子公文的手，指节粗大，握笔的地方有厚茧。这双手参加过隋朝的科考，写过隋朝的奏章，然后看着那个朝代亡了。现在它们写着大唐的文书。

戴胄抬起头，看着沈知远。他的目光不像平时那样平静——有一种什么东西在里面，很深的地方，在油灯光下微微晃动。

"你跟我年轻时一模一样。唯一的区别是——你现在就敢说，我等了半辈子才敢说。"

端起那碗面汤。汤已经不烫了——温的，正好入口。低头喝了一口，在嘴里含了很久才咽下去。

"——那您觉得，我该怎么走接下来的路？"

戴胄想了想。他拿起桌上的茶杯，发现茶已经凉了，又放下。

"两条路。一是——继续这样冲下去。能冲多远冲多远。但要做好准备——随时被人按下去。"

"——二呢？"

"学会借力。"

抬起头。

"你现在做事，靠的是你自己。但一个人能做的事是有限的。你需要——"戴胄停了停，"让别人帮你做。"

"——谁能帮我？"

戴胄没有直接回答。他低下头，用指尖在桌面上画了一个圈——圈的中心，什么都没有，但圈周围压着几根看不见的手指。

"——房玄龄。"

"——他已经在帮你了。"

"——但你要学会，让他帮得更多。"

离开戴家时，夜已经很深了。

戴胄送到门口。门外的巷子里很黑，只有远处一盏灯笼在夜风中摇晃，发出昏黄的光。戴胄站在门槛上，拍了拍沈知远的肩。那只手停在他肩上，停了两三息——不重，但很有力。

"路上小心。"

点了点头。走进黑暗里。

走在回家的路上，脑子里一直在想那句话——"让他帮得更多。"

怎么才能让房玄龄多帮他？房玄龄已经是他最直接的靠山了。但戴胄的意思可能是——他需要一个更正式的位置。一个让房玄龄有理由为他说话的位置。不是一个后辈对前辈的请求——是朝堂上一个不可或缺的人对另一个人的需要。

想起魏徵说过的话——"著作佐郎可以上朝。"

著作佐郎。从六品上。可以站到太极殿里。

抬头看了看长安的夜空。没有月亮，但星星很亮——冬天的星星格外清晰，钉在深蓝色的天幕上。

加快了脚步。

冷风灌进领口，但没有缩脖子。

知道接下来该做什么了。
