# 第四十六章 策论上奏

长孙无忌的警告不是空话。

第二天清晨，沈知远刚到秘书省，就看见房玄龄已经在值房里等他了。不是坐在案前——是站在窗边，背对着门，手里捏着一封没有封口的信。窗外的天灰蒙蒙的，阴沉欲雨。

沈知远进门的时候，房玄龄没有转身。他听着脚步声，等沈知远走到身后两步远的地方，才开口。声音里有一种沈知远从未听过的果断：

"你那篇策论——明天之前递上去。"

没有寒暄，没有商量。是命令。

站在原地。手不自觉地攥紧了——有人在朝会上准备好了对他发难。如果等对方先出手，他就被动。必须先下手——用一篇无法被忽视的策论，让太宗站在他这一边。长孙无忌昨天给的不是警告——是闹钟。告诉他发难的时间，却没有告诉他谁会在那天出手。

没有多问。转身走出值房。脚步声在长廊里急促地响过，越走越快，后来几乎是在跑。

他回到小院，推开院门。韩慎正在院子里择菜——今天早上刚从市上买的青菜，还带着露水。他抬头看到沈知远的表情，没有说话，只是把菜放进篮子里，站起来，走进厨房，关上了门。

蹲下身，从床底下拖出韩慎的旧木箱。箱盖没有锁，但上面压着一摞书——是他自己摞上去的，为了挡住别人的视线。他把书一本一本搬开，手指有些发抖。书放得不太稳，有一本滑下去，啪地掉在地上。

他没有捡。他掀开箱盖。

干荷叶裹好的策论还在最底下。

他把它拿出来。入手的一瞬间，他感到一种奇怪的安定——像握住了一件应该握在手里的东西。

他站起来。院子里，天空堆着厚厚的云。风停了，空气似乎凝固了一般。远处隐隐有雷声，从南边滚过来，低沉的，仿佛车轮碾过石板路。

他锁上院门，快步去了房玄龄的值房。

房玄龄坐在案前，手里拿着一杯已经凉透的茶。沈知远把干荷叶解开，把策论放在案上。

房玄龄看了他一眼，然后低头看策论。他看得很慢。非常慢。

站在一旁，看着房玄龄的目光一行一行地移过去。那些字他写了三天，每一个措辞都反复斟酌过。此刻，那些字正在接受最后的审判。房玄龄翻到最后一页，读完了第三部分的最后一行，放下策论，沉默了很久。窗外有一阵风灌进来，吹动了案上的纸页，又安静了。

然后他说了一句话：

"——这次一个字都不用改。"

他站起来，把策论折好，放进袖中。

沈知远站在那里，胸口一种说不清的情绪涌上来——不是高兴，是一种混杂着释然和恐惧的东西。站在悬崖边，终于迈出了一只脚——收不回来了。

他走出值房。六月的天空压得很低，乌云如铅块般从西天堆过来。他站在秘书省的院子里，感觉到第一滴雨落在额头上。

凉凉的。

然后第二滴。第三滴。

夏天的第一声雷从远天滚了过来——低沉，厚重，如同巨兽在云层深处翻了个身。雨点开始密集起来，噼里啪啦地砸在院子里的青砖上，溅起一阵尘土的气息。

——

次日朝会。

沈知远没有资格上朝。他坐在秘书省自己的案前，像往常一样校勘卷宗。但他的手一直没有暖起来。春末夏初的天气不冷，但他指尖冰凉。

他把一卷《晋书》打开，又合上，打开，又合上。字怎么也看不进去。他干脆放下书，坐着看向窗外的雨——昨天那场雨下了一夜，到现在还没有停的意思。雨水顺着屋檐流下来，在廊下汇成一道道细细的水流，滴落在青砖上，发出滴滴答答的声音。

午时，走廊里传来急促的脚步声。

沈知远抬起头。谷遂从门外冲进来，官袍的下摆湿了一大截，脸上分不清是雨水还是汗水。他站在门口喘了几口气，然后用一种仿佛从喉咙里挤出来的声音说：

"——兄弟——你的策论——在朝会上炸了。"

放下手中的笔。

谷遂往前走了一步，语速越来越快：

"房玄龄把你的策论呈上去了。陛下看了，当朝传阅。好几个人看了，看完都没说话。然后长孙无忌站出来了——他没说反对，也没说赞成，把策论放在案上，说了一句'臣以为此事当细议'。"

谷遂喘了一口。

"然后侯君集当场拍了桌子。"

拳头在案下不自觉地握紧了。

"他说——一个秘书省的校书郎，无权议论兵部事务。说这是越职言事。按律当罢。"

谷遂没有给沈知远缓冲的时间，继续说下去：

"房玄龄说——'论事不论权——即使是庶民，也有开口的权利。更何况他调的每一卷案卷，都是尚书省存档的可公开文书。'"

"那魏徵呢？"

"魏徵一开始没说话。后来侯君集说——'一介书生，知道什么叫打仗？'——魏徵才站起来。他说：'臣不知道他知不知道什么叫打仗。但臣看过他在策论中引用的隋史数据——那些数据没有错。臣查过。'"

心猛地跳了一下。魏徵查过他的数据——不为帮谁，只是验证事实。这就是魏徵的方式。

"结果呢？"

"结果——"谷遂咽了一口唾沫，"陛下说了一句话。"

他认真地模仿了一下太宗的语气——不高不低，却压得住一切：

"——'留下，朕细看。'"

手松开了。

留下。细看。

不是驳回。不是采纳。但李世民愿意"细看"——说明他没有否决，说明他在认真考虑。对于一个校书郎的策论来说，这已经是超规格的待遇。

沈知远坐在案前。窗外，雨还在下——比刚才大了一些，雨点打在院子里干燥的地面上，溅起水花。整个秘书省的院子笼罩在雨幕之中，檐水如帘。

放下笔，走到窗边。雨从屋檐上倾泻下来，在廊下形成一道水帘。隔着水帘，秘书省院子里的槐树在雨中摇动，叶子被雨水打得上下翻飞。空气里有雨水的味道——清新中带着泥土的腥气，还有远处飘来的草木被淋湿后的味道。

站在窗前，让带着水汽的风吹到脸上。

这是一场夏天的暴雨。

他不知道自己策论的最终命运会是什么。但他知道——自己已经在这盘棋上，落下了一颗无法收回的棋子。

他伸手出去，接了一掌心的雨水。雨水顺着指缝流下去，落在脚下的青砖上，很快就不见了。

棋盘上有棋。他是个下棋的人——不是一个棋子。这一点，今天就够了。
