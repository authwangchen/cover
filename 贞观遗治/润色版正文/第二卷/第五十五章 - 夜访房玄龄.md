# 第五十五章 夜访房玄龄

房玄龄的宅子在崇仁坊西南角，不大，和他中书令的身份不太相称。

宅门是普通的黑漆木门，没有门当，没有石狮，门环是铁的，已经被风雨磨得发亮——不是铜的，是铁的，生了锈又被磨亮，再锈再磨，周而复始，门环下的铁托上有一道深深的磨痕。门口也没有守卫，只有一个老仆在门房里打盹儿，听到敲门声，半天才应。

沈知远报了姓名，老仆进去通报，过了一会儿出来说："房公在书房等您。"

书房在后院。

沈知远穿过一个月亮门，走在青砖铺的甬道上。两旁的树光秃秃的，枝丫在月光下投出细碎的黑影，落在他的肩头又滑落。一只猫从墙头跳下来，无声地落在地上，看了他一眼，转身走了，尾巴尖在拐角处消失。

房玄龄的书房亮着灯。

门开着半扇，暖黄色的光从门缝里漫出来，在青砖地上铺了一小片。沈知远走近了，闻到一股淡淡的茶香——不是那种昂贵的贡茶，是普通的粗茶，煮得久了，香味里带着一点焦苦。

他敲门。

"进来。"

房玄龄坐在书案后面，面前摊着一卷公文，旁边放着一碗茶——茶汤已经凉了，表面凝了一层薄薄的膜。他看到沈知远进来，也没有起身，只是抬了抬下巴，示意他在对面的椅子上坐下。

"这么晚了。"房玄龄说。不是问句。

"臣有一些想法，想向房公请教。"沈知远从袖中取出那三张纸，铺在案上。

房玄龄没有立刻看。他把目光从公文上移开，落在沈知远脸上，停留了几个呼吸。那目光不重，但很沉，像一只手搭在他的肩膀上，在掂量着什么。然后他才低头看那三张纸。

书房里安静下来。只有烛花偶尔爆裂的声响——啪，像一粒小小的火花炸开在寂静里，随即又被黑暗吞噬。

房玄龄看得很慢。第一策看完，他没有翻页，而是闭上眼睛想了一会儿，然后睁开，继续看第二策。沈知远坐在对面，呼吸放得很轻，能听到自己的心跳声在耳膜里鼓动。手指在膝盖上无意识地蜷了蜷，又舒展开。

第三策看完，房玄龄把三张纸叠好，放在案角，端起那碗冷茶喝了一口。

"你知道你写的是什么吗？"他问。

"知道。"

"第一策，分散安置，分于六州。"房玄龄把茶碗放下，手指在碗沿上轻轻敲了两下，"这个可能行得通。第二策——胡人可为卒不可为将。这个……"他顿了一下，"会让很多人不高兴。"

"臣知道。"

"第三策——设番学，教经史。三代之后，胡即为汉。"房玄龄看着他，目光里有种说不清的东西——不是赞许，不是反对，更像是一种复杂的审视，"三代是六十年。你考虑过六十年以后的事？"

沈知远没有直接回答。他沉默了一会儿，然后说：

"臣考虑过一百年以后的。"

房玄龄的手指停住了。

他没再说话，把那三张纸拿起来，又看了一遍。这一次看得更快——像是在已经读过的内容中寻找什么特定的东西。窗外的风从门缝里渗进来，烛火晃了一下，然后稳住。房玄龄的影子在墙上随之摇动，又定住。

看完之后，他把纸折好，没有还给沈知远，而是放进了自己的袖中。

"留在老夫这里。"

沈知远的心跳了一下——不是紧张，是一种混合着希望和忐忑的复杂感受。留在房玄龄手里，意味着他会替自己往上递。

"房公——"

"不要说谢。"房玄龄打断他，"你的三策，老夫会帮你递上去。但是——"他抬起头看着沈知远，目光忽然变得很平静，平静得像深水，"你这三策，每一策都在告诉天下人一个道理：胡人不可信。但你知道你自己是谁吗？"

沈知远一愣。

"你——"房玄龄的声音忽然放低了，低到几乎像自言自语，"你是谁？你从哪里来？你的学问是哪来的？你的见识是哪来的？"

沈知远的后背骤然绷紧。

房玄龄没有继续追问。他低下头，重新拿起那卷公文，像刚才什么都没发生过。

"回去吧。明天还有朝会。"

沈知远站起来，行了一礼，转身往外走。

走到门口时，房玄龄的声音从背后传来，很轻，几乎被门外的风声盖住：

"三策是好策。但你要记住——任何制度，都要有人来执行。而人的问题，比制度的问题更难。"

沈知远在门口停了一下。他没有回头，只是微微点了点头，然后走进夜色里。

月亮被云遮住了大半，院子里很暗。他走过甬道，推开门，走进巷子。巷子里没有人，只有一只猫蹲在墙根下，眼睛在黑暗中反着幽绿的光。他走远了，猫才站起来，无声地朝相反的方向走了。

他走出崇仁坊时，夜风迎面吹来，冷得刺骨。

他在空无一人的大街上停下来，抬头看了看天。云层很厚，看不到星星，只有天边隐约有一点微光，不知是月亮的透亮还是城外的什么亮光，像一个快要熄灭的念头，悬在黑茫茫的天幕上。

他想：房玄龄知道什么？

他不知道。但他知道——他不该再问下去了。
