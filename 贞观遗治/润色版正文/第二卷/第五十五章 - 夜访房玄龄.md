# 第五十五章 夜访房玄龄

房玄龄的宅子在崇仁坊西南角，不大，和他中书令的身份不太相称。

宅门是普通的黑漆木门，没有门当，没有石狮，门环是铁的，已经被风雨磨得发亮——生了锈又被磨亮，再锈再磨，周而复始，门环下的铁托上有一道深深的磨痕。门口也没有守卫，只有一个老仆在门房里打盹儿，听到敲门声，半天才应。老仆揉着眼睛出来时，灯笼的光从他身后漫出来，照亮了门前的青砖地——砖缝里长着几丛枯草，被风吹得伏倒在地。

沈知远报了姓名。老仆进去通报，过了一会儿出来说："房公在书房等您。"

书房在后院。

沈知远穿过一个月亮门，走在青砖铺的甬道上。两旁的树光秃秃的，枝丫在月光下投出细碎的黑影，落在他的肩头又滑落。一只猫从墙头跳下来，无声地落在地上，看了他一眼，转身走了，尾巴尖在拐角处消失。

房玄龄的书房亮着灯。

门开着半扇，暖黄色的光从门缝里漫出来，在青砖地上铺了一小片。沈知远走近了，闻到一股茶香——不是那种昂贵的贡茶，是普通的粗茶，煮得久了，香味里带着一点焦苦。屋里陈设很简单：一面墙的书架，架上的卷宗摞得整整齐齐；案角的笔架上挂着几支笔，笔杆已经磨得发亮，最常用的那一支笔杆上布满了细密的牙痕——是思考时咬出来的。另一面墙上挂着一幅字，纸已发黄，墨迹淡了，但还能看清是"慎独"两个字，笔力沉厚。

他敲门。

"进来。"

房玄龄坐在书案后面，面前摊着一卷公文，旁边放着一碗茶——茶汤已经凉了，表面凝了一层薄薄的膜。那碗是普通的白瓷碗，边沿有一个小小的缺口，不大，但刚好在嘴唇碰到的位置——房玄龄大概已经习惯了，知道怎么避开它。他看到沈知远进来，没有起身，只是抬了抬下巴，示意他在对面的椅子上坐下。

椅子是普通的木椅，没有铺垫子，坐上去有些硬，冰凉的感觉隔着冬衣透过来。椅面已经被坐得光滑了，边缘被磨得发亮。

"这么晚了。"房玄龄说。不是问句。

"晚辈有一些想法，想向房公请教。"沈知远从袖中取出那三张纸，铺在案上。

房玄龄没有立刻看。他把目光从公文上移开，落在沈知远脸上，停留了几个呼吸。那目光不重，但很沉，像一只手搭在他的肩膀上，在掂量着什么。

然后他低头看那三张纸。

他看得很慢。第一策看完，他没有翻页，而是闭上眼睛想了一会儿。他的眼睑合上时，脸上的轮廓忽然变得很安静——那种安静不是休息，是一种思考，像一扇门关上了，里面在发生什么，外面看不到。然后他睁开眼，继续看第二策。沈知远坐在对面，呼吸放得很轻，手指在膝盖上无意识地蜷了蜷，又舒展开。

第三策看完，房玄龄把三张纸叠好，放在案角，端起那碗冷茶喝了一口。他喝得很慢，先抿了一小口，停一下，再喝第二口——像是在尝什么，又像是在拖延什么。碗沿上那个缺口对着他的嘴唇，他精准地避开了它。茶汤入口时，他的喉结滚动了一下，然后他放下茶碗，手指在碗沿上敲了两下。

"你知道你写的是什么吗？"他问。

"知道。"

"第一策，分散安置，分于六州。"房玄龄把茶碗放下，"这个可能行得通。第二策——胡人可为卒不可为将。这个……"他顿了一下，"会让很多人不高兴。"

"晚辈知道。"

"第三策——设番学，教经史。三代之后，胡即为汉。"房玄龄看着他，目光里有种说不清的东西——不是赞许，不是反对，更像是一种复杂的审视，"三代是六十年。你考虑过六十年以后的事？"

沈知远没有直接回答。窗外传来一声夜鸟的啼叫，短促，尖锐，像一根针划破绸缎，然后消失了，夜色又合拢如初。

他沉默了一会儿，然后说：

"晚辈考虑过一百年以后的。"

房玄龄的手指停住了。

他没有立刻说话。他垂下目光，看着面前那三张纸，像是在重新衡量它们的分量。烛火在他脸上投下明暗交错的影子，他的表情在光影中几不可察地变化了一下——眉头收紧了一瞬，然后松开。

他没再说话，把那三张纸拿起来，又看了一遍。这一次看得更快——像是在已经读过的内容中寻找什么特定的东西。窗外的风从门缝里渗进来，烛火晃了一下，然后稳住。房玄龄的影子在墙上随之摇动，又定住。

看完之后，他把纸折好，没有还给沈知远，而是放进了自己的袖中。

"留在老夫这里。"

沈知远的心跳了一下。留在房玄龄手里——意味着他会替自己往上递。纸边擦过布料的纤维，发出一声细微的悉索声，像一个承诺落地的声音。

"房公——"

"不要说谢。"房玄龄打断他。他的语气没有加重，但目光变得很专注，落在沈知远脸上，像在确认什么，"你的三策，老夫会帮你递上去。但是——"他抬起头，目光忽然变得很平静，平静得像深水，看不清底下有什么，"你这三策，每一策都在告诉天下人一个道理：胡人不可信。但你知道你自己是谁吗？"

沈知远一愣。

房玄龄的目光没有移开，像两根钉子钉在他的脸上。那目光里没有敌意，但有一种穿透力——像在看一个他努力想看懂的人。

"你——"房玄龄的声音忽然放低了，低到几乎像自言自语，"你是谁？你从哪里来？你的学问是哪来的？你的见识是哪来的？"

沈知远的后背骤然绷紧。

那三个问题像三根针，很细，很轻，但扎得很深。他的后背在发僵——不是冷，是一种从内部生出来的紧绷感，像一张弓被拉开。他的手指在膝盖上握紧了一下，又松开。

房玄龄没有继续追问。他没有等答案。他低下头，重新拿起那卷公文，手指翻开纸页，目光落回文字上。

"回去吧。明天还有朝会。"

沈知远站起来，行了一礼，转身往外走。

他的脚步骤了一瞬——迈出第一步时，膝盖有些发软，像踩在一团棉絮上。他稳住自己，继续走。衣袖在身侧摆动，带起一阵细风，拂过案角那叠空白的纸，纸张的边缘颤动了一下。

走到门口时，房玄龄的声音从背后传来，很轻，几乎被门外的风声盖住：

"三策是好策。但你要记住——任何制度，都要有人来执行。而人的问题，比制度的问题更难。"

沈知远在门口停了一下。他没有回头，只是微微点了点头——那动作很小，大概只有房玄龄能看到。然后他推开门，走进夜色里。

门在身后合上时，发出轻微的咔嗒声。铜质的门锁舌弹回锁槽，像一个句号落在纸面上。

月亮被云遮住了大半，院子里很暗。他走过甬道，推开院门，走进巷子。巷子里没有人，只有一只猫蹲在墙根下，眼睛在黑暗中反着幽绿的光。沈知远走远了，猫才站起来，无声地朝相反的方向走了。

走出崇仁坊时，夜风迎面吹来，冷得刺骨。风从他的领口灌进去，贴着脖子向下蔓延。巷口的灯笼在风中摇晃，光影来回摆动，把他的影子拉长又缩短。

他在空无一人的大街上停下来，抬头看天。云层很厚，看不到星星，只有天边隐约有一点微光，悬在黑茫茫的天幕上。那点光太远了，远到几乎不存在——但盯着它看的时候，它就在那里，微弱但固执。

他不再往下想了。继续走。

脚步声在空荡荡的街道上回响，一步一步，从近到远，消失在夜色深处。
