# 第五十三章 降俘将至

二月初，颉利可汗被押送到长安的消息确认了。与此同时，十几万突厥部众正从漠南被分批南迁。贞观一朝最大的朝堂争论——降俘处置之议——即将开场。

沈知远在秘书省的工作突然多了一项：调阅前朝安置降俘的档案。

调档指令上盖着中书省的印，朱红方正，印泥在纸纹里渗开。沈知远没有去想这是谁安排的——答案已经写在纸上了。

他用了三天时间，把秘书省能找到的相关档案翻了一遍。

存放档案的屋子在西厢最尽头，平时很少有人进去。门推开时，一股积年的灰尘味扑面而来。阳光从高处的窄窗照进来，光束里浮着无数细小的颗粒，缓缓上下浮动，像一场没有声音的雪。手指拂过纸面时，能感觉到纸张的厚度不均匀——有些地方厚，有些地方薄，是手工抄纸留下的痕迹。

汉代匈奴降众的安置——呼韩邪单于率部归附，宣帝置之于塞下。档案原文很短，但后面有人用蝇头小楷写了一行批注："塞下之地，膏腴者鲜，降众多而地狭，贫不能自给，官府岁费巨万。"墨色比正文淡，笔迹偏瘦。南匈奴内迁，最终酿成永嘉之乱——中间夹着一张发黄的签条，边角卷曲："五部匈奴入居塞内，晋武帝时已见端倪。"没有署名。

前秦苻坚安置鲜卑慕容部——淝水之战后慕容部反叛，前秦崩溃。档案里附了一张地图，纸已经破损，折痕处磨出了白线。图上墨线画出鲜卑各部迁徙的路线，线条粗细不一，有些地方断开又接上，像河流在不同年代改道又汇合。沈知远的手指沿一条墨线移动，从辽东到关中，再到河北，最后在洛阳附近停住了，墨迹在那里洇开了一小片。

隋朝安置东突厥启民可汗部众，大业年间启民之子始毕可汗反隋，炀帝被困雁门。沈知远翻到最后一页，看到一行朱笔批语："纳降易，安降难。"四个字，笔力遒劲，捺画收得很重。没有署名。

案上的纸摞成了厚厚一叠。边角批注的墨迹越来越密，像一场无声的对话在不同时代的纸页间展开。笔迹各异，时间跨度从汉到隋。沈知远翻完最后一卷，合上时，封面上细细的灰尘被他的手指抹开一道痕迹，露出下面纸的本色。

聚则生患，散则无虞。

他把这句话写在自己的本子上。窗外传来几声鸟鸣，冬天的麻雀在光秃秃的枝丫间跳来跳去，脚爪在冰凉的树皮上抓出细微的声响，然后飞走了。

三日后，朝会正式开始讨论突厥降俘处置。

沈知远以著作佐郎的身份列席——位置在殿末，比上次稍稍往前挪了两排。他前面是国子监的博士和太常寺的礼官。

殿内的空气比上次朝贺时更冷。正月末的寒气还没有退尽，从殿门的缝隙里渗进来，贴着地面流动。香炉里的烟升得比平时更直——殿内空气凝滞，没有风，烟雾笔直上升，在高处分作两缕，一左一右，各自飘散。

温彦博先发言。他的声音不高，但很清楚：

"臣以为，突厥既降，宜仿汉武故事，置降众于河南之地。塞下空旷，足以安置。使其为中原屏障，以御北狄。"

这是"内附派"的主张——把突厥人安置在长城沿线，作为藩属和缓冲区。

温彦博说话时，双手握着笏板，姿态端正。但他握着笏板的手指收紧了一下——拇指在笏板的边缘按了一下，留下一个浅浅的印子，随即松开。

话音未落，魏徵出列。

他走出来的步子不快，但每一步都很稳。官靴踏在竹席上，发出轻微的声响——竹篾被重量压下去又弹起来，吱，吱。他在殿中央站定，躬身行礼，然后开口：

"臣反对。"

魏徵的声音比温彦博高了半度。不是激动——是他的声音天生就带着一种不容置疑的硬度，像石头碰石头。他的下颌收紧，喉结滑动了一下——在把涌到嘴边的话压一压，挑最重要的说出来。

"突厥非我族类，其心必异。今置之塞下，是养虎于侧。若日后有变，河南之地即成敌境。臣请遣返漠北，使复其国。"

温彦博没有立刻反驳。他沉默了两个呼吸的时间，那沉默让殿内的空气又冷了几分。然后开口，语气平静，但节奏略快：

"王者之政，怀柔远人。杀之不义，纵之生患。内附则恩威并施——三代之后，胡即为汉。"

说到"三代之后"时，他的目光转向了魏徵——斜过去的，眼角的余光落在魏徵的侧脸上，停留了一瞬，又收回来。

争论持续了整整一个时辰。温彦博举汉朝例子，魏徵举南北朝例子。一个说"怀柔"，一个说"养患"。谁也说服不了谁。

沈知远站在末列，手心已渗出一层薄汗。

整个辩论过程中，太宗没有说过一个字。皇帝端坐在殿上，身体微微前倾，一只手放在膝盖上，另一只手的手指在扶手上敲着——敲一下，停顿两个呼吸，再敲一下。不紧不慢的，像一面太鼓在遥远的地方被一下一下地敲响。

长孙无忌站在文官前列，从头到尾没有插话。他的目光落在地砖上，一动不动。但在魏徵说到"始毕可汗围雁门"时，他的眼皮绷紧了一瞬，然后松开。

房玄龄一直垂着眼，手指在笏板边缘摩挲。他握着笏板的手背上，青筋凸起了一下，又消下去。

队列前方的几位将军脊背挺直，没有人开口。程咬金的手在腰侧的剑柄上摩挲了一下，拇指沿着剑柄的纹理来回滑了一次，然后放了下来。

朝会在没有结论的情况下散了。太宗没有表态——让各方充分争论，他自己在最后做决定。

散朝时，注意到太宗站起来时比平时慢了一些——手在御座的沿口上撑了一下才起身。那个停顿里藏着一种沉甸甸的思虑，让起身的动作都变得沉重了几分。

沈知远走出大殿时，午后的阳光刺眼。

从昏暗的殿内走到阳光下，眼睛一时适应不过来。石阶被晒得发烫——隔着靴底能感觉到那种温热，和殿内的阴冷形成鲜明的对比。他站在石阶上，闭了一会儿眼睛。眼皮后面是一片橙红色的光晕。

台阶两侧的石栏上蹲着几只石兽，被风蚀得面目模糊。有一只石兽的耳朵已经磨平了，只留下一个圆钝的突起。

他睁开眼，看到温彦博和魏徵从他身边走过。

两人谁也没看谁，各自走向不同的方向。温彦博的背影很直，步子不紧不慢。魏徵走得更快一些，官袍的下摆被风带起，露出底下的皂靴——靴底边缘磨得有些发白了，露出里面的粗麻衬底。一个连靴底都磨白了的谏议大夫。

沈知远收回目光，沿着石阶往下走。

一只野猫蹲在石阶尽头的阴影里，前爪并拢，一动不动地看着人流散去。沈知远走下最后一级台阶时，猫眨了眨眼睛，站起来，转身走进了墙角的阴影里。

今晚要去见一个人——房玄龄。
