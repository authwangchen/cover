# 第九十章 条款复活

一个月后，房玄龄在修律组的例会上，"顺带"提起了第六章第十七条。

例会设在政事堂东厢的大屋里。那天清晨下了场小雨，屋外石板地上的水渍还没干透，暗色的一块一块，像从屋顶漏下来的墨斑。开会的人陆续到齐，各自坐定。有人翻看手中的卷宗，纸张在安静中发出脆响。有人低声交谈几句，又沉默下去。房玄龄坐在主位上，面前摊着草案，一页一页地翻过去，动作很慢，像一个在整理旧物时偶然发现了一份被遗忘的底稿的读书人。

"这条——老夫觉得措辞还需再斟酌一下。"房玄龄翻到某一页，手指在纸页上慢慢划过，从右到左，在页面的末端停住，指尖压在纸面上，没有抬起来，"诸位看看——'都督掌兵，刺史掌民，转运使掌财'。这条的立意是什么？"

没有人立刻回答。屋里安静了几息——纸张翻动声停了，窃窃私语声也停了，只有屋外檐角残留的雨水滴落在石阶上的声音，嗒，嗒，间隔很长，像一只缓慢的钟。

长孙无忌不在场——他那天没有参加例会。兵制组的几位编修面面相觑，有人想说什么，看了一眼对面的杜郎中，又咽了回去。杜郎中的脸上没有任何表情，像一面没有纹路的铜镜，把所有的光线都收进去，不反射任何东西。

杜郎中沉默了片刻，然后开口了：

"这条的立意是——防止一州之权集于一人。"

他的声音不大，但在安静的屋子里每一个字都很清晰。没有多余的解释，没有铺垫，就一句话。

"——你觉得怎么样？"

"——可行。"

这两个字从杜郎中嘴里说出来，分量不一样。像一块石头落进了称盘，发出沉闷的一声。杜郎中在修律组里的分量——他平日话最少，但他说的每一个字都经过了比他年长许多的官场生涯的考验。他说"可行"，意味着这条条款不仅在制度逻辑上站得住，在朝堂的政治风向上也不会有太大的阻力。

房玄龄点点头。

"那——就保留。"

没有辩论。没有反对。一条曾经引发弹劾的条款——一条让沈知远差一点被逐出修律组的条款——在长孙无忌缺席的例会上，被房玄龄和杜郎中两个人，用两句话就敲定了。

屋里响起翻页的声音。案卷翻了过去。没有人再提起这件事。但坐在角落里的编修有人放下了笔，有人抬头看了一眼房玄龄，又低下了头。每个人的脸上都看不出什么，但屋里的空气变了——像一扇被推开了一点点缝隙的窗，冷风从外面渗了进来。

消息传到沈知远耳朵里时，他正在秘书省校勘文稿。来传话的是房玄龄府上的一个老仆，没有进院子，只是在门口把话递给了守门的吏员。吏员走到沈知远案前，低声说了几句。沈知远听完，点了一下头，继续埋头校对。但翻动纸页的手指在那一页的边角上轻轻停了一下——拇指和食指夹着纸角，停在那里，像一个忽然间定格的念头。然后他翻了过去。

一个多月后，《贞观律》草案正式定稿送呈。送呈那天，太极殿前的铜钟敲了三响，声音浑厚低沉，从宫城中央一波一波地扩散出去，越过长安城大大小小的坊墙和街道，直到消失在远处的天际线。

沈知远没有参加送呈仪式。他坐在秘书省的案前，像往常一样校勘手头的文稿。窗外有脚步声匆匆经过，有人在低声交谈，有人小跑着去传话。但他没有抬头。他知道他不需要去现场——那卷送呈的草案里的每一个字，他都见过。他的笔，蘸了墨，一笔一画地写过那些字。墨迹在纸上留下微微凸起的痕迹，手指摸上去能感觉到笔画的走向。

送呈太宗的那一卷草案里，"分署办公"四个字，写在第六章第十七条。白纸黑字。墨迹已干。日光从窗外照进来，照在秘书省的地面上——秋日的光，温热而不灼，带着一丝淡淡的金色，铺在青砖上，整间屋子都笼在那片光里。
