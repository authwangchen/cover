# 第六十三章 番学设立

番学是在贞观四年三月正式开课的。

地点设在崇文馆东侧的一座小院里——三间连通的正屋，粉刷一新，白灰的墙面还微微发潮。窗外种了一棵新移的槐树，树干上还缠着防寒的草绳。没有挂匾，只在门框上方贴了一张纸，上面写着"番学"两个字，字是沈知远的笔迹。

第一批学生只有二十三人。大部分是留在长安的突厥贵族子弟——颉利可汗的亲属、各部酋长的儿子和侄子。年龄从八岁到十八岁不等。他们穿着京兆府统一发放的深青色麻布袍子，和他们从前穿的皮裘和锦袍截然不同。有些人穿着新衣局促不安，不停地拽袖口和衣领，像那些松垮的布料和他们的身体之间隔着一层说不清的东西。另一些人则带着明显的不屑——嘴角下撇，眼神从眼角斜过来打量这间教舍。

沈知远站在院子门口，看着那些孩子一个一个走进去。有些孩子回头看了他一眼，目光里有好奇，有敌意，更多的是一种"你凭什么教我"的审视。

他知道这些孩子心里在想什么。他们是被打败的一方的后代。他们的父辈曾经驰骋在漠北草原上，现在却要坐在一间汉人的屋子里，读汉人的书，写汉人的字。换作是他自己——他也不会高兴。

番学没有专门的老师。沈知远兼课，崇文馆的学士也轮流来教。教材是从秘书省调来的《论语》和《孝经》简抄本——每页的字都很大，行距很宽，用纸也是最便宜的那种粗黄纸，边角起毛，指腹滑过时有细微的涩感。

第一天上课，沈知远站在讲台上，面对二十三个沉默的突厥少年。有人趴在桌上，有人靠在墙上，有人望着窗外。只有一个男孩坐得端正——不是出于尊敬，更像是在用端正的姿态表达一种不屑。"我坐好，但我不想听你说话"式的不屑。那男孩大约十五六岁，眉骨很高，眼睛很深，轮廓像用刀削出来的。

沈知远翻开《论语》第一页。

"学而时习之，不亦说乎——"

他读了一遍，用官话。然后他停顿了一下，用突厥语又读了一遍。那是他花了一周时间学的——死记硬背，用唐人记音的突厥语短语，舌头打结，像含着一块石头在说话。

教室里安静了。

那个端正坐着的男孩——他抬起了眼睛。那不是好奇——是一种"你居然会说我们的语言"的不信任。他的视线像一根竖起来的刺。

沈知远没有解释。他只是继续读下去。一段汉话，一段突厥语翻译。他读得不快，偶尔结巴一下，但坚持把四句全部读完。有几个少年开始交换眼神了——这是他们今天第一次看彼此的脸。

下课之后，那个男孩没有走。他坐在座位上，等所有人都离开了，才站起来。

"你读错了。"他说。官话很生硬，但能听懂。

"哪里错了？"

"'有朋自远方来'——你翻译成'远方的兄弟'。不对。'朋'不是'兄弟'。'朋'是——"他想了想，没找到合适的词，"是跟你不一样的人。"

沈知远看着他。

"跟你不一样的人"。——他记住了这句话。一个突厥少年在纠正他对《论语》的翻译。

"你叫什么名字？"

"阿史那·思摩。"

沈知远没有说话，只是点了一下头。然后他收拾起桌上的书卷，跟那个少年一前一后走出了教室。

门外，院子里那棵新栽的槐树在春风中摇着稀疏的枝条。有些枝条上已经冒出了嫩芽——很小，几乎是芥子大小，在午后的光线下透着一种半透明的淡绿色。
