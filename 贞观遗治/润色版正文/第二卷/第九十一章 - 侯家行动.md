# 第九十一章 侯家行动

修律草案送呈之后，长安城安静了几天。然后侯公子——侯君集之子——在长安的酒楼里，散出了一句让人不安的话：

"那个姓沈的秘书省官，非议府兵乃国之根本。他说府兵养不起，将来要改募兵——你们说，这是不是在说陛下的制度不好？"

这句话像一粒火星掉进了干草堆。两天之内，长安城的酒肆茶馆里都在议论这件事。沈知远在秘书省的同事开始用一种打量异类的目光看他——不是敌意，是距离，像一条街上的住户忽然发现隔壁住着一个患有传染病的人。

沈知远在案前听到了外面的风声，没有动。他摊开一卷空白纸，在上面写了几行字，又停住了。

他以前在史书里读到过"造谣"二字。现在他亲身经历了一次。

高明的谣言不需要完全虚假——只需要把真实的话扭曲一点点：他确实在奏疏中分析过府兵制负担过重的问题，但他从未说过"陛下制度不好"。侯公子只是把"府兵负担过重"偷换成"陛下制度不好"，就把一盆脏水泼在了他身上。

他没有去自辩。自辩只会让谣言传得更广。

他选择了另一条路——他去找了戴胄。不是请戴胄帮他澄清——是请戴胄帮他查一件事：侯公子在归义坊火灾当晚的行踪。

"你想干什么？"

"不干什么。只是留着。"

戴胄沉默了一会儿："留着——等到有用的时候？"

沈知远没有回答。但他知道他等的是什么——不是报复，是证据。在朝堂上，清白不能自证，只能用比对方更确凿的事实来覆盖对方的话。

他走出京兆府时，天已经黑透了。长安城的初冬，风从西北方向吹过来，穿过棋盘一样整齐的坊巷，刮在脸上，又冷又硬。

他知道，从这一刻起，游戏升级了。不再是制度和制度的辩争，是人与人之间的搏杀。
