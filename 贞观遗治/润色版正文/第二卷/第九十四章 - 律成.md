# 第九十四章 律成

贞观五年腊月，《贞观律》正式颁行天下。

颁行典礼在太极殿举行。太宗亲临，百官朝服列班。沈知远站在秘书省的队列里，穿着深绿色的官服。他的位置在殿末，前面有四排官员的背影挡住了他大部分视线。但从人缝里，他还能看到殿上太宗的身影——冕服庄严，十二旒在日光中轻轻晃动，与一年前突厥捷报入京时的景象重叠在一起。一年前他们在这里庆祝战争的胜利。今天他们在这里见证制度的确立。

典礼结束后，有赐宴。他同样没有入席的资格——六品以下，照例是一份食盒。他提着食盒走出宫门时，在承天门外遇到了杜郎中。

杜郎中站在门洞的阴影里，像在等什么人。看到沈知远出来，他什么也没有说，只是微微点了点头。像两个在石阶上相遇的人，不需要言语来确认——他们知道那条路上，两人曾经并肩走过一段。然后杜郎中转身走了。沈知远目送他的背影消失在午后的阳光里。

他回到秘书省，把食盒放在案上，没有打开。

他一个人在案前坐了一会儿。窗外有人在放爆竹——腊月了，长安城里已经开始有过年的气氛。远处的爆竹声噼里啪啦的，像有什么东西在干燥的空气里层层碎裂又聚合。阳光从窗外透进来，照在案上那本新颁的《贞观律》抄本上。封皮是崭新的蓝青色，书脊用白线装订，线头整齐，纸页散发出油墨和纸张混合的气味。

他翻开抄本，找到第六章第十七条。

他一个字一个字地读了一遍。每一个字都是他反复推敲过的，每一个标点他都记得自己是在哪个夜晚加上的。

他合上书。

他不知道百年后这条律法还在不在。但他知道——它现在在。在这个它诞生的时刻，在这个属于他和这个时代共有的下午。
