# 第八十章 第二幕收束

番学风波平息后，贞观五年的春天快过完了。

崇文馆院子里那棵新栽的槐树长得很快。去年还只有一人多高，今年已经窜到了屋檐，树干也比去年粗了一圈，树皮上裂开细细的纹路。叶子从嫩绿变成了深绿，在午后的阳光下投下一大片浓荫，树影在院墙上随着微风轻轻晃动。蝉开始叫了——第一声总是拖得很长，像一个沙哑的老人在试着嗓子，试探着叫了几声之后，才慢慢打开了音量。

沈知远站在树荫下，看着番学的学生们下课走出教室。阿史那·思摩走在最前面，脚步沉稳，手里夹着一卷书，走到门口时侧身让后面的同学先过。阿史那·咄苾走在他后面，还是那副不太驯服的表情，下巴微微扬起，但脚步没有从前那么冲撞了——以前的他是用肩膀撞开门走出去的，现在他会伸手推一下门板。有些东西确实在变，变得很慢，但每一分变化都能看到痕迹。

他数了数出去的人——二十一个。比最初少了两个。离开的两个人，一个是因为家里要搬去洛阳，另一个是学了两个月觉得"汉人的书没意思"，自己走的。剩下的二十一个，有些人开始用汉字在纸上写自己的名字——那些歪歪扭扭的笔画，横不平竖不直，但每一个字都在努力向方正的形状靠拢。有些人学会了举手等老师点名再说话——不是每次都能做到，但至少他们开始记着这个规矩了。还有一两个会课后主动找他问问题——问的也不是什么了不得的事，但问题是汉字写出来的。

他回到书房，打开木匣。木匣里多了一样东西——韩慎那卷文书的抄本。他把原物还给了韩慎，但自己抄了一份留着。纸上的字迹是他自己的笔迹，写得认真，一笔一画。他把抄本拿出来，放在桌面上，翻开。

灵州。凉州。四万二千人。

他合上抄本，然后拿起一张空白的纸，开始写。

不是写奏疏。是写笔记。他把这几个月学到的东西整理出来——边镇体制的漏洞在哪里，番学的经验教训是什么，朝堂上各方势力的态度变化，韩慎提供的隋朝案例里哪些可以借鉴。笔尖在纸上移动，时而快时而慢。有些地方他写了又划掉，在旁边重新写。纸面上渐渐布满了修改的痕迹，像一个正在被不断修正的思想的底稿。

他知道这些笔记总有一天会用上——不是作为奏疏的素材，而是作为一部更大作品的准备工作。一部他现在还说不清楚形状的作品，但它的轮廓正在他的脑子里一点一点地显现出来，像一幅画在黑暗中被慢慢点燃的蜡烛照亮。

他在这页笔记的末尾写下了一行字：

"制度的敌人不是某个人，是时间。但时间也是制度的朋友——只要有人每一代都重新捍卫它。"

写完之后，他把笔搁下，靠在椅背上。椅背发出一声轻微的吱呀，像在回应他的重量。窗外响起了晚钟，声音悠长，从远处寺庙的方向传来，一波一波地散入渐浓的夜色。钟声穿过层层叠叠的屋顶和坊墙，到达他耳中时已经变得很轻很柔，像有人在远处用指尖敲击一只铜碗的边缘。他没有点灯，就那么在昏暗里坐了一会儿。暮色从窗外流进来，填满了他和书桌之间的所有空隙。他把双手叠放在桌面上，感觉到手心下面压着的纸张边角微微翘起，像活的东西在呼吸。
