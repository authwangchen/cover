# 第六十四章 归义坊夜火

番学开课后的第十天，归义坊失火了。

火是在半夜烧起来的。

沈知远被坊门的急鼓声惊醒。他在黑暗中坐起来，耳膜还在嗡鸣——鼓声太急，敲得人心头一紧。外面有人在跑，脚步声杂沓而沉重，从巷口碾过去，又从更远的街面上碾回来。有人在喊，声音混杂在一起，分不清内容，但每一嗓子都带着一种不正常的尖利，像被什么掐住了喉咙挤出来的。窗纸上映着一种不正常的红光——不是月光，是火光。那红色在纸面上浮动、跳跃，时而深得像血，时而亮得像烧透的铁。他披上衣服冲到门口，拉开门的瞬间，一股热浪夹杂着焦糊味扑面而来——像有一只巨大的手掌捂住了他的口鼻。那股热不是干燥的热，是带着水汽的蒸热，像盛夏正午掀开蒸笼的一瞬。焦糊味里混着几层不同的味道——最浓的是木料被烧透的焦甜味，底下压着一层布料烧过的酸涩，还有一种更细、更尖锐的气味，像是毛发烧焦后的腥味。西边的天空被染成了暗红色——归义坊的方向。那片暗红在天幕上扩散着，边缘处泛着金黄色的光晕，像一块烧红的烙铁搁在布上，正缓慢地将附近的夜空都烫出焦痕来。

他朝着那片红光跑起来。脚下的石板路被夜露打湿了，鞋底在石面上打滑了几次。越靠近归义坊，空气就越热。到坊门附近时，他已经能感觉到迎面扑来的热浪像一堵墙，每一步都像是往火里走。皮肤上细小的汗毛被热浪燎过，有一种酥麻的刺痛。喉咙也开始发干，每吸一口气都像在往肺里灌热气。

他到的时候，火已经烧了小半个坊。

京兆府的救火兵丁已经到了，正在拆毁火场周围的房屋以阻断火势蔓延。斧头劈在木梁上的声音沉闷而急促——闷响之后是木材断裂的嘎吱声，然后是瓦片落地的碎裂。有几片碎瓦飞溅到沈知远脚边，碎茬上还嵌着没完全熄灭的火星，在夜色中一明一灭。火焰的颜色并不均匀——底层是暗红色，贴着未被完全吞噬的木料；中层是橘黄色，火舌舔舐着房梁和窗框；最上层翻卷着金白色的焰尖，在夜风中一晃一晃地摇着，把整片坊墙都照得像一块烧透的砖。

热浪一波接一波地涌过来。沈知远能感觉到自己脸上的皮肤在发烫，像在冬日里凑近了火盆太久的那种灼感。有什么东西从天上飘下来，稀稀疏疏的——是灰烬，像一场颠倒的雪，从火焰升腾的气流中飞向夜空，又缓缓坠落。有一片落在他手背上，带着一点余温，他低头看时，那片灰烬已经碎成了一小撮粉末，在他皮肤上留下一道浅浅的灰痕。焦糊味变得更浓了——木头的焦甜与布料的酸涩之外，多了一层说不清的气味，又腻又腥，像是什么油脂被烧着了。

哭声从不同的距离传来。最近的是身边一个中年妇人，瘫坐在地上，怀里抱着一个包袱，发出那种压抑不住的、断断续续的呜咽。稍远一些的巷子里有人在喊一个名字——反复地喊，像在叫一个不会回应的人。更远处，烈火吞噬木料发出的噼啪声连绵不绝，像是在烧着一座巨大的篝火。那些声音在窄巷里来回碰撞，一层叠一层，分不清远近，像整个坊都在呻吟。

归义坊的居民在巷子里挤成一团，抱着包袱，拖着孩子。有人蹲在地上埋头哭泣，有人拖着水桶往火场方向跑，有一个光着脚的女人冲过去拉住了正在拆房的兵丁，喊着她家老人还在屋里——兵丁甩开她的手，说来不及了。更多的人只是站在街边，表情空白。火光映在他们褐色的瞳孔里，每一只眼睛都像一小片燃烧着的湖面，水面上晃动着跳动的火焰倒影。

沈知远在人群中寻找一个人。他的目光从一张张被火光映亮的面孔上扫过——惊恐的、麻木的、哭泣的——然后他看到了。康洛站在巷口的一棵槐树下，没有救火，没有搬东西，只是站着，看着火光。那棵槐树的叶子被热浪烤得卷了起来，边缘开始发焦，散发出一股植物被炙烤的青涩气味。康洛就站在那片正在焦卷的树荫下，纹丝不动，像一尊被遗忘在火场边的石像。

沈知远走到他身边。

"怎么起火的？"

"不知道。"康洛的声音很平静，平静得不正常，"已经烧了大半个时辰了。"

沈知远看着火势。火从坊中心烧起来，借着春风向西蔓延，已经烧毁了七八间屋子。火光里不时传来屋顶坍塌的闷响——轰的一声，然后一蓬火星像烟花一样炸开，升上去，又落下来，撒在周围几丈之内。有几粒火星落在沈知远的衣袍上，烧出了几个小洞，布料的边缘卷起来，烧成了一小圈褐色的焦痕。他拍了一下，指尖触到烫手的余温，有一瞬间的刺痛。

他转过头，正要再问什么——目光落在康洛的袖口内侧。

一道烧焦的痕迹。不大，不超过一根手指的长度。焦痕是新的——布边还在微微卷曲，像是刚被烫出来的，带着一丝烧过的焦糊味。

沈知远没有问。他看了康洛一眼，康洛也看了他一眼。

两个人的目光在火光中碰到一起。康洛的眼神里没有慌张，没有愧疚，甚至没有闪躲——只有一种沈知远读不懂的东西，像是某种古老的、凝固了的疲倦，像这双眼已经见过太多火光了。

两个人都在火光中沉默着。火焰在他们中间烧着，风把灰烬吹到两个人之间那个窄窄的空隙里，堆积成了一道细碎的灰线。

天快亮的时候火被扑灭了。最后几根焦黑的木梁冒着白烟，救火的兵丁用铁钎把还在冒烟的余烬摊开，一桶水浇上去，白烟升腾而起，带着焦木被水激过的酸味。地面上到处是积水、碎瓦和烧焦的杂物，一脚踩下去，水渗进鞋缝，又凉又脏。鞋底踏在碎瓦和灰烬上，发出沙沙的声响，偶尔踩到什么软的东西——不知是烧烂的衣物还是别的什么——沈知远没有往下看。

京兆府的统计结果——烧毁房屋十一间，烧死七人，烧伤二十余人。文书上每一个数字都用浓墨写就，笔画笔直，干干净净的，像是记的不是人命，而是一笔账目。死亡的是七名老弱妇孺——被困在火场中，没能逃出来。死因都是窒息，不是烧伤。那意味着他们是在被火烧到之前就已经在浓烟中失去了意识。沈知远看到那条记录时，眼前浮现出的不是火焰，是浓烟——又黑又厚的烟，贴着房梁灌下来，堵住了每一个呼吸的入口。

天亮后，沈知远进入火场查看。他踩着还在冒烟的灰烬，脚下软绵绵的——不是踩在实地上的感觉，每一步都陷进去，像踩在刚翻过的湿土上。空气又热又呛，肺部每一次呼吸都带着刺痛。那股气味混杂了太多东西——焦木、烧化的油脂、被水浇过的石灰、烧过的织物，还有更深处的、难以辨认的气息，所有东西被高温揉在一起，成了一股厚重而黏腻的味道，附着在鼻腔里和衣服上，怎么都散不掉。灰白色的余烬还在冒着细细的青烟，从废墟的各个角落升起来，像无数根看不见的线在空中飘散。

一具被烧焦的尸体蜷缩在墙角——像一截烧过的木柴，表面的轮廓还依稀可辨是人形。表层已经完全炭化了，呈现出一种漆黑的、龟裂的质地，裂缝里露出底下深褐色的组织。头部微微后仰，嘴张着——那是窒息死亡后肌肉松弛留下的痕迹。沈知远的目光在那张嘴上看了一会儿，然后移开了。他在那具尸体前站了很久。阳光穿过烟雾照下来，被烟尘过滤成了一种昏黄的光线，照在废墟上，给所有的焦黑镀上了一层惨淡的金色。有几只苍蝇开始在废墟上空转着圈飞，嗡嗡的声音在寂静中格外清晰。

烧死的七人中，有一个人他认识——是番学里一个学生的母亲。那个学生叫阿史那·思摩。

他找到那孩子时，正午的阳光已经直直地照下来，把废墟的影子压成窄窄的一条。那孩子跪在烧塌的房屋前，地面上铺着一层厚厚的灰烬和碎瓦。他面前摆着三块石头——大小相近，一字排开——突厥人的祭奠方式。他没有哭，嘴唇紧抿成一条线，嘴角的肌肉在细微地颤抖。眼睛直直地看着前方的废墟，瞳孔被阳光照成了浅褐色，里面映着焦黑的木料和倒塌的土墙。肩膀微微发抖，但身体没有动。那三块石头在正午的阳光下投出三道短而清晰的影子。有一小块灰烬从上方飘落，落在中间那块石头上，碎了，留下一点灰白的粉末。

沈知远在他旁边蹲下。膝盖落在灰烬上，灰烬的余温透过布料渗进来，不烫，但温热，像夏天墙壁在黄昏时存留的温度。灰烬的气味又苦又涩，混着一种像草纸烧过的焦香。

"——节哀。"

阿史那·思摩没有回应。他的眼睛没有从废墟上移开。过了很久，他的嘴唇动了动，声音干涩：

"我娘说——长安的春天很短。还没来得及看花开。"

一阵风吹过来，把废墟上残留的细灰卷起来，从他们两人之间掠过。那阵风带着一种干热的触感——不是火焰的干燥，是灰烬的干燥，比火焰更彻底，连水分都被收走之后剩下的那种干燥。沈知远的眼睛被吹得发涩，眨了一下，感觉到眼角有一点干裂的刺痛。那孩子的睫毛上也落了一层灰，灰色的细尘粘在黑色的睫毛尖端，像沾了晨露的草叶。

沈知远没有接话。他蹲在那里，陪那个少年一起，看着那片还在冒烟的废墟。灰烬的气味弥漫在空气中，又苦又涩。有几片烧焦的纸灰从空中飘过来，落得太慢，像是被空气托着不肯坠落。其中一片落在沈知远的袖口上，边缘卷曲着，还能看到一行残破的字迹的墨痕——不知是谁写的一封书信或是一张账目，现在只剩下手指大的一小片焦纸。他用手捻了一下，那片纸灰碎了，成了更细的粉末，像黑雪一样从他指缝间飘散，落在脚边灰褐色的地面上，再也分不清哪片是纸，哪片是灰。地面上阿史那·思摩的膝盖旁边，有十道平行的细痕——是他攥紧拳头时手指在灰土中反复划过留下的痕迹。

沈知远的目光在那十道痕迹上停了一下，移开了。

火是怎么起的？他不知道。

但他注意到一个细节：起火点旁边，有一间屋顶没有被烧到，但门锁坏了。据邻居说，那是侯公子常去的一间屋子。

沈知远没有把这个发现告诉京兆府。有些证据，在没有力量去揭露之前，知道就是负担。

但他记下了。

火灾的日子。烧死的名字。康洛袖口那道新鲜的灼痕。阿史那·思摩跪在废墟前时，泥土上被十个手指反复抓出的痕迹。

他回到秘书省，在一张空白的纸上写下了一行字：

*"贞观四年三月十七，归义坊火。烧十一间，死七人。"*

他把纸折好，放进了案头的木匣里。木匣里已经有几样东西：以工代赈的账目副本，一封未送出的奏疏草稿，还有一片从渭水工地捡回来的碎陶片——上面有半条裂缝，像是被人故意摔碎的，在烛火下看时，边缘处还挂着干透的泥痕。

他锁好木匣，推开窗。

外面是春天了。
