# 第二百六十七章 朱温

天祐元年。朱温逼迫昭宗迁都洛阳。

这不是一次自愿的迁移。朱温的人拆毁了长安的宫室，把拆下来的木材顺着渭水漂运到洛阳——那些梁柱、窗棂、门板，都成了建设新宫的材料。长安城的居民被强制迁走——推着车、挑着担子、拉扯着哭闹的孩子和不愿离开的老人，沿着通往洛阳的官道缓慢移动。路上有人死去——老人和孩子的遗体被草草地埋在路边，和之前的几批迁民尸体埋在一起。整座城市被拆成了骨架。太极殿的屋顶被掀掉，梁柱被一根一根地撬下来。那些梁柱上的彩绘——贞观年间的工匠一笔一笔绘上去的——在撬抬的过程中被刮花，木屑和颜料碎末落在石基上，被风吹散。只用了不到两个月，长安就变成了一片废墟。长安空了。不是陷落，不是被攻陷——是被它的主人自己拆掉的。

弘文馆在拆迁的名单上。士兵们来搬书时，一个老馆吏拦在门口——他已经太老了，老到不知道自己还能做什么，只能本能地拦在门口。说"这里的书不能动"。士兵把他推开。他摔倒在地上，爬起来，又拦在门口。士兵第二次推他时力道更大了。他倒在地上，后脑撞到了门槛，血顺着石缝渗进了泥土中。他没有再站起来。

士兵们把书架上的书一摞一摞地搬到手推车上。车装满了就推到宫门外，倒进排队等候的牛车中。没有人做记录——不需要，反正这些书到了洛阳也会被重新编号。在混乱中，有些书从车上掉了下去。后来收工的人经过，将那些散落在地上的残书一脚踢进了泥沟。过了几天几场雨，泥沟中的纸浆被冲入下水道，经过排水口汇入渭河，从此没有了任何可以辨认的痕迹。那本《文选》注疏也在搬运的队列中了——被一只手从东六架第四层抽出来，扔上了手推车。车在门槛上颠了一下，书从书堆的最上层滑落——那几片纸从书页间跌出去。书落在车板旁的尘土里。纸片落在泥地上。纸叠着纸，折痕紧贴折痕，保持着被反复夹了百余年后的贴合姿态。押运的士兵踩到了一片纸，但没有停下。纸片粘在他的鞋底上走了几步，然后脱落，翻了个面，字迹朝上摊在泥地中。上面是"存者九，废者三十八"——那张表格，在它被翻到又遗落的上百次之后，终于在空无一人的弘文馆门前的泥地上摊开。字迹完整。但没有人来读它。然后雨来了。雨水浸透了纸片，墨迹洇开，字迹在雨中缓缓模糊。首先是"废"字的三点水，然后是"存"字的短横，然后是"九"字的弯折——一个字一个字地失去了形状。最后只剩下几团灰黑色的墨渍。

《文选》注疏——被装上了另一辆车，被运到洛阳，被重新编号。那几片纸——留在了长安的废墟中。它们的实体在这里结束。它们的内容——还没有。

风从旧纸堆中翻过一页。那些被时间遗忘的字迹，在黑暗中依然保持着写下时的姿态。

天祐四年。朱温废唐哀帝，自立为帝，国号大梁。唐朝结束了。从武德元年到天祐四年，二百八十九年。从贞观元年到天祐四年，二百六十二年。从那行"诸边将不得兼统"到天祐四年，二百五十八年。

制度的最后一张纸被撕掉了。不是那卷《贞观遗制》——它的很多副本分别以不同的方式消散了。是帝国本身——那个让那些制度有可能被执行的帝国——不存在了。但那些制度的意义——如果有的话——并不依赖这个帝国。它们依赖于一个更简单的东西：是否有人愿意约束权力。只要这个愿意还存在，那些文字就还存在——不是作为生效的法律，是作为被保存过的人类判断。这样的判断不会因为帝国终结而失效。它只是暂时失去了它保护的对象。它可以等——等下一个愿意被它保护的人。那个人还没有到来。但在它等待的年岁中，那些被撕掉的纸张和被洇开的墨迹——它们没有消失。它们在它们结束的地方，继续存在着。这就够了。


长安城的灯火在夜色中一盏一盏地熄灭。

历史在无声中翻开下一页。

朱温的名字在史书上被涂了一层又一层的污名。但他在开封修的城墙，确实比长安的厚。

。在开封的城墙地基深处，有一层垫脚的碎砖是从长安的废墟中运来的。那些碎砖上还残留着弘文馆的墙灰和某个书吏的墨迹。城墙立起来了，而垫在它底下的那些字，没有人再见过。
