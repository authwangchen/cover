# 第四十五章 长孙无忌的宴请（二）

六月中，长孙无忌再次设宴。

帖子送来的方式和上次不同。上次是大红色的请帖，礼数周全。这次是一张便笺，只有一行字："明日酉时，老地方。"

沈知远拿着这张便笺，看了很久。

这次的规模比上次小得多。只有四个人——长孙无忌、长孙冲、侯公子、沈知远。

地点不是正堂，是后花园的水榭。池塘里荷花开了一半，有几朵已经盛放。晚风吹过，荷叶翻动，露出底下墨绿色的水面。

长孙无忌今天穿了一件青灰色的家常袍子，看起来不像当朝第一权臣，像一个普通的退休老人。他亲手给沈知远倒了一杯酒。

"今天的酒——不是官里的。是我老家酿的。"

沈知远接过来，喝了一口。比上次的酒烈。

"沈校书——甘露殿那次，见陛下感觉如何？"

沈知远放下酒杯。他知道长孙无忌的消息来源比他想象的更深——他私下面圣的事，长孙无忌不仅知道，而且知道细节。

"——陛下问了几个问题。臣答了几个。"

"问了什么？"

沈知远没有回答。

长孙无忌没有追问。他夹了一筷子凉菜，慢慢嚼完，擦了擦嘴：

"你不说，我也大概知道。"

他放下筷子。

"——陛下是不是问了——边将久任的事？"

沈知远没有说话。但他的沉默本身就是一种回答。

长孙无忌轻轻点了点头。

"——你知道吗，你提出的那三件事——府兵负担、边将久任、胡汉杂处——这些事，朝中不是没有人想过。"

"想过的人是有的。"长孙无忌的声音很淡，"但他们没有写出来——因为写了也没用。你不止写了——你还在做。"

他抬起酒杯，喝了一口。

"——你知道这意味着什么吗？"

"——请仆射指教。"

"意味着——你已经不再是一个"可以忽略"的人了。"

花园里很安静。荷花开得正盛，但傍晚的风已经带了一丝凉意。

沈知远端起杯子，把杯中酒喝完。酒很烈，从喉咙一路烧到胃里。

他没有说"多谢仆射赏识"。他只是把酒杯放下，说了一句：

"——仆射今天请我来——不只是为了告诉我这个吧？"

长孙无忌看着他，目光里有某种东西——像是一条老狐狸在看着一只成长中的小狐狸——带着一丝欣赏，也带着一丝警惕。

"——你猜对了。"

他放下酒杯。

"——三天后朝会，有人会就你在兵部调阅案卷一事提出质问。不是弹劾你——是问你的权限。"

沈知远心里一沉。

"——仆射今天告诉我这个——是让我有所准备？"

长孙无忌没有回答。他站起来，走到栏杆边，背对着沈知远。

"——我告诉你的，已经够多了。剩下的——你自己想。"

沈知远坐在那里，看着长孙无忌的背影。

晚风拂过池塘，荷叶哗啦啦地响了一陣。
