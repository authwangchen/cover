# 第二百一十五章 卒

显庆五年，二月十七。

纸铺的老周发现沈知远没有来买纸。

他平时每隔半个月来一次，买一刀纸——不多不少，正好够他写半个月的札记。老周等了半个月又五天，那个人没有来。他记性不好，特意翻了一下账本，发现上一回收钱是整整十九天前。十九天——那个人以前从来没有超过十五天不出现。

老周去敲他的门。

门没有锁。他推开门。屋子里很安静——像一个人在熟睡时的那种安静。案上还有未收拾的笔和砚台——砚台里已经没有墨了，干涸的墨迹在砚面上形成一圈圈的深色纹路，像干涸的河床。油灯的灯芯已经烧成了灰白色。桌面上积了一层薄灰——灰很细，均匀地铺在所有没有落过东西的平面上，像一场看不见的雪。

他走进卧房。

沈知远躺在床上，像睡着了一样——手放在身侧，面容平静，没有痛苦的表情。老周叫了他两声，没有回应。他走近，伸手碰了一下沈知远的手背——冰凉，比屋里的空气还凉。他站了一会儿，没有惊叫，没有跑出去喊人。他只是在床边站了一下，然后退出屋子，轻轻带上了门。

他报了官。

洛阳县的差役来看了一圈，检查了死者的遗物——几件旧衣服，一方砚台，几支笔，一本发黄的教材，两枚铜印，一叠整理好的旧稿。差役翻了翻那叠旧稿——没有看懂上面写的是什么——大约是某种官场上的文书。他们登记了所有物品，然后问老周：这人在洛阳有没有亲人？

老周说："没有。他从来没有提过。"

差役说："那就按无主处理。"

老周说："等一下——你们不查一下他以前是做什么的吗？"

差役看着他："你知道？"

老周不知道。他只是卖了五年的纸给这个人。这个人每次来买纸，都会在店里站一下，翻一翻新到的书——有时翻开某本，看了几页之后又默默地合上，放回原处；有时什么也不翻，只是把纸捆好，付钱，道一声谢就走了。老周从来没有问过他的名字。不——他问过。那个人说："姓沈。从长安来的。"然后老周就没有再问了。

他忽然觉得，他欠这个人一个名字。

他去找了洛阳县的主簿，翻出沈知远搬来洛阳时登记的户籍资料。上面的内容很简单——"沈知远，前中书侍郎，贞观朝致仕"。老周把那张纸看了很久。

中书侍郎。贞观朝。

他不知道那意味着什么。但他知道——这个人写了一辈子东西。他的遗物里最重要的东西，应该是那些旧稿——而不是被差役当作"无主物品"登记造册的那几只碗和几件衣服。

他回到沈知远的屋子里，把案上那叠旧稿拿走了——连同那本发黄的教材和两枚铜印。他自己掏钱买了一副薄棺，请人把沈知远安葬在洛阳城外的一片空地上——不是什么风水宝地，只是一个不会被翻动的地方，可以让人安静地躺着。他找了块石板，想在上面刻点什么——但他不知道沈知远的生平。他沉默了很久，拿起凿子，在石板上刻了七个字——他唯一能确定、也觉得这个沉默的老人唯一会认可的内容。字刻得歪歪斜斜，不工整——老周的手是做纸的，不是刻字的——但用力很足，每一道都入石三分：

"一个写字的人。"

他把那叠旧稿、教材和印章用一个木盒装着，放在自己铺子的里间。他不知道该交给谁——或者该不该交给谁——只知道不应该和那些旧衣碗碟一起，被洛阳县衙当作无主的杂物封存。

他关上木盒。木料碰撞时发出干燥的、沉闷的声响——像一个人轻轻合上了一本书，合上之后，就没有再打开。

洛阳城外多了一座没有碑文的坟。没有人知道那里睡着谁，那座坟和周围的旧坟混在一起，草色在第二年春天就不再有区别——远看只是一片高出地面不多的隆起，在初春尚未来临的枯草中，像一个被遗忘在时光里的句号。

但那个木盒还在纸铺的里间。盒子里的旧稿，纸页已经发黄。边角卷曲。字迹开始褪色。但它们还在。

他关上木盒。木料碰撞时发出干燥的、沉闷的声响——像一个人轻轻合上了一本书，合上之后，就没有再打开。

洛阳城外多了一座没有碑文的坟。只有一块歪歪斜斜的石板立在地面之上，上面刻着七个字："一个写字的人。"刻得很深，但笔画歪扭——老周的手是做纸的，不是刻字的——可每一道都用足了力。风吹过坟头的荒草。石板在风中纹丝不动。

老周在坟前站了很久。然后他转身走回铺子里。他没有再来过——不是因为不想来，是因为他已经在石头上刻完了所有他能说的话。剩下的，是他刻不出来的。

但那七个字还在石头上。字迹会在风雨中变浅、变得模糊、终至无法辨认。但在它们还能被看见的每一个春天，路过那片荒地的人偶尔会停下来，看一眼那块石板。他们不认识石板上写的是谁。但他们知道，有人在这里结束了他的故事。这就够了。
