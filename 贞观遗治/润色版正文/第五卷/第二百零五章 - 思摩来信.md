# 第二百零五章 思摩来信

永徽三年，春。

信是从凉州送来的。

信封用的是边镇驻军的制式公文封——厚实的黄麻纸，封口处盖着一枚朱红色的火漆印，印文模糊了，只能辨认出"凉州"二字。信封上没有署寄信人的姓名，只有一行地址——"长安中书省转交沈公"。这行字写得端正而用力，像是一个不太熟练的人刻意放慢了速度，在每一个字上落下了比平常更多的注意。信封的边角有些磨损，像是被辗转运送了好几个驿站——从凉州到长安的驿站之间的每次接力，都在它身上留下了压痕和磕碰。封口的火漆上有一道细细的裂纹，像是一个人在信被送出前又犹豫过——然后又决定把它寄出去。

沈知远在值房里看到这封信时，已经是傍晚。门吏送进来时说是三天前到的。他看了一眼信封——只一眼——然后把它放在案角，没有立刻打开。

他把信放在案角，继续批阅那份送来的驿站清册。他的笔尖在纸面上移动，一行一行地划过去，准确地落在每一个应该批注的位置上。纸页的声音在安静的房间里一格一格地响着。然后他放下笔，在暮色中坐了一会儿。

他拿起那封信。火漆已经有些脆了，手指一碰就裂开了细小的缝隙。他用指甲沿着封口轻轻划开，抽出里面的纸。他抽出信纸时，手指微微停顿了一下——不是犹豫，是一种本能的小心，像是在拆一件知道对自己重要的东西。

纸是凉州那边自造的麻纸，比长安用的纸粗糙一些，颜色发灰，纸面上可以见到细小的草茎纤维。但上面的字写得很用力——笔画压得很深，像写的人担心墨水会从粗糙的纸面上滑走，所以每一笔都额外用了几分力。墨迹在纸纤维中渗开，形成了微毛的边缘，像是写了又看、看了又改过的。

他展开信纸。

信的开头没有抬头，没有敬语，没有"沈公台鉴"之类的格式——直接是一句话。

"我还在凉州。"

沈知远看到那五个字时，手指在纸边停了一下。他继续往下读。

"永徽二年，凉州换了新的都督。新都督姓程，是从陇右调来的。他到任第一件事，就是重新调整了各折冲府的防区。

我的校尉职还在，但防区变了——从原来的凉州西界调到了祁连山北麓。那个地方你在地图上找不到——地图上只有一座山的轮廓和一个名的位置。但那里的人和牛羊都知道这个地名。

新的防区里没有城池。没有城墙。营帐搭在风口上，每天晚上都能听到风从山口的缺口处灌进来，把帐篷的布面吹得猎猎作响——像有一群人在远处敲鼓，敲了一整夜，不停。我在那里住了半年，学会了在风声中睡觉。

他们说这里的防务是"巡查蕃部"，意思是我要带着二十个人，骑马沿着祁连山北麓走一遍，看看有没有吐蕃人的探子。这件事我做了二十年了——从贞观十一年离开长安开始。

我不觉得苦。"

沈知远停了一下。他看着"不觉得苦"那四个字。字迹在写到"不"时笔压明显加重了，像是在纸上按下一个确认键——"我知道你会以为我苦。但我不。"

他继续读。

"沈公，有件事我想告诉你。

去年冬天，凉州都督府接到了一道从长安来的文书。是关于边将任期的新制——现在不叫'制'，叫'例'了。文书的措辞很模糊，没有说废止，没有说修改——只说'今后边镇将领之考课升降，以功绩为准，不拘年限'。

不拘年限。

我看到这四个字的时候，想到了你。

我不知道这道文书是你写的，还是别人写的。如果是你写的，我想知道为什么。如果不是——那我想让你知道，有人还在用你在贞观年间定的那把尺子量这件事。"

沈知远的目光在纸上停着。窗外的光线又暗了一些。他没有点灯，在昏暗的光线中继续往下读。

"凉州这边的事情还很多，没有什么值得一提的。这里的春天比长安晚两个月。贞观二十年的柳树——它的枝叶在风中摆动的样子，我还记得。

阿史那·思摩

敬上。"

信纸的末尾没有日期。沈知远把信从头到尾又看了一遍。然后他把信纸折好，放回信封里，放进案下的书箱中。

他在黑暗中坐了很久。

窗外的风在吹——春天的风，和凉州来信中提到的山风不一样——长安的风是湿润的，带着泥土和草木的气味。风穿过窗缝时发出轻微的啸声，像有人在非常远的地方吹着口哨。案上那叠驿站清册的纸页边缘被风吹得轻轻翘起，然后又落下，发出干燥的、反复的声响。

他想起贞观十一年的冬天——思摩离开长安的那个清晨。长安城的北门外，雪还没有化完，路面上的积雪被行人的脚踩成了灰黑色的冰碴。思摩背着一个简单的行囊——包袱皮是灰蓝色的，打着两个结，里面装着不多的东西。他穿着一件新发的军袍——袍子太大了，肩部塌下去一块，像一面半降的旗。他的站在沈的面前，站得很直。

"我走了。"

"到那边，先听，后说。"

"知道了。"

然后思摩就转身走了。走出城门时，他在门洞的暗影中停了一下——不是回头看——只是停了一下，调整了一下行囊的位置，把滑下来的袍肩往上提了提。然后他的背影消失在门洞另一端的光芒里。那光太亮了，把他的轮廓一下子就吞没了。

那时候思摩二十二岁。

现在沈知远坐在永徽三年的值房里，手里握着一封从凉州来的信。信纸的边角已经被他反复摩挲得有些发毛了，纸面上的纤维在指腹下微微隆起。他抬起头，看着窗外——天色已经全黑了。远处有人在敲更鼓，声音沉闷而遥远，像从水底传上来的。

他在黑暗中又坐了很久。久到眼睛适应了黑暗，能分辨出窗格的轮廓和案上文具的剪影。然后他伸手摸到火镰，点亮了案上的油灯。火光亮起来的那一瞬间，窗外的黑暗在玻璃上变成了一面完整的镜子。他把那封信从书箱中取出来，摆在灯下，让烛光照亮信纸上的每一个字。

"不拘年限。"

他把那四个字看了很久。然后他铺开一张新纸，拿起笔。蘸墨。笔尖在砚台上吸饱了墨汁，在灯光下闪着湿润的光。砚台里的墨汁反射着烛光，像一小片深色的水面。

他想了想。

然后他写了一个字——没有抬头，没有落款，只有一竖行工整的楷书：

"知道了。"

他写完之后，停了一下。没有把它装进信封。没有写地址。他只是在纸上写了"知道了"三个字，然后放下笔，看着那三个字在烛光中慢慢地变干。墨迹从湿润的黑色变成深色，最后固定成稳定的黑色，和纸面上的其它字迹一样了。他把那张纸折好，放进了案下的书箱里。和那封信放在一起。一封信，一个字的回信。他不会把它寄出去。

但思摩来信了。他会回。

有时就是这样——一个人还在做一件事，不是因为这件事能做成，而是因为另一个人在做同样的事。就像两棵遥远的树，在沉默中向同一个方向生长。
