# 第二百五十五章 撤离

天宝十五载六月，玄宗决定撤离长安。不是"迁都"，是"幸蜀"——去蜀中避难。这个决定是在深夜做出的，烛火在御案上跳动，把在座者的影子在墙壁上拉得很长。杨国忠提议，玄宗沉默了很久——久到殿内的空气几乎凝固，就连蜡烛的火焰都在那一刻停止了晃动——然后他点了头。消息封锁到最后一刻。第二天清晨，宫门在黎明前最暗的时刻提前开启。禁军护送着玄宗、贵妃、少数皇子皇孙和几位核心大臣从西门出城，向南进发。队伍不大，和这座帝国往日任何一次出巡的规模相比甚至有些寒酸——三辆牛车，十几匹马，几十名禁军，再加几位大臣及其家眷。随行的车辆有限，许多日常用品和档案都被留在了原处。

宫中负责档案的官员在最后一刻还在犹豫该带走哪些旧档。他站在库房里，面对密密麻麻的架子和卷轴——从武德年间到本朝的全部制度文书——他知道其中有一些是重要的，但他没有时间仔细挑选。太仓促了。他从架上抓了几卷摆在最前面的——高宗朝修订过的《永徽律疏》、玄宗朝编纂的《唐六典》——想了想，又放下一卷，换成了更小的一包奏章汇抄。他的手指在那些卷轴上快速掠过，指尖在一卷因受潮而微微鼓起的卷面上停顿了一瞬——他想打开看看，但门外有人在催了——他放弃了。他抱着那几卷档案快步走出库房，身后的门在风中被吹得来回摆动了几次，最终停在一个半开的姿态。他不知道有没有带走真正重要的东西。大部分人不知道。门没有锁——负责锁门的人已经在撤离的人群中走出了宫门。

长安城的百姓在清晨醒来时发现皇宫比平时安静。没有早朝的钟声，没有官员的车马通过朱雀大街。承天门紧闭着，门前的广场上空无一人。消息像水一样无声地漫开——"陛下走了。"一个卖饼的老汉听说后，放下手里的擀面杖，站在清晨的巷口朝皇宫的方向望了很久。他做了一辈子胡饼，知道哪些佐料可以少放、哪些必须足量，但他不知道一个国家没有了皇帝该怎么办。他站了一会儿，又弯腰重新拿起擀面杖，继续揉面。他手上的面粉在晨曦中泛着白色的光。街上有些人开始收拾细软，有些人把家里的米缸搬到板车上，也有人什么都没做，只是坐在门槛上，看着别人忙碌，想着一件事——走又能走到哪里去呢？

弘文馆的老书吏在坊间听到了这个消息。他站在巷口，手里攥着一块抹布——他离开库房时带出来的。他低头看了一眼那块布，叠好放进怀里。他现在可以离开了——弘文馆没有人值守了，城门的守卫也已经撤了——但他不知道该去哪里。他在长安住了大半辈子，在这座藏书楼里待了大半辈子，离开这座城，他无处可去。他走回弘文馆，穿过门厅，手指轻轻拂过那些排列整齐的书脊——不同质地的纸张在他的指腹下留下各异的触感，厚的薄的、光滑的粗糙的，每一本他都能凭触感认出大致是哪一类。但他的手指在经过某一本的时候停了下来——他摸到了那本书的封面在边缘处有一个细小的卷角，这是他四十多年前第一次放这本书时就已经有了的卷角。这么多年了，它还在那里。他走完了整排书架，在库房门口停下来，环顾了一眼这座他再熟悉不过的建筑——窗棂上的积灰、房梁上的蛛网、地面上被无数双脚踩出的光滑轨迹——然后他坐在门槛上没有再站起来。他的目光落在那本《文选》注疏所在的书架上——书脊上的字他看不太清了，但他知道就是那本。他坐在那里，没有锁门。长安城的门已经不需要锁了。整座城像一本被人读到一半随手合上的书，放在案上，等待一个不确定的归期。

他闭上眼睛。他身后那排书架上有一本《文选》注疏，书页之间夹着几片薄纸，记录着一个人用半生写下的文字。它们没有被人带走。它们还在那书页的夹层里，和那些关于贞观朝制度存废的条目一起，安静地躺在这个无人锁门的黄昏中。没有人来取走它们，也没有人注意到它们的存在。但它们的存在并不依赖被人注意到——它们只是在那里，在纸页之间，保持着沈知远写下它们时的姿态，和他离世时把它们留在这座城里的姿态。

他走出弘文馆，穿过已经空荡荡的长安城街道。街道两旁的店铺都关了门，门板封着，门窗紧闭，像一排排无声的眼睛。风从巷口吹过来，卷起地面上的落叶和碎纸，那些纸片在空中旋转了一瞬，然后落进路边的水洼里，被水浸透，慢慢地沉了下去。他走过西市附近的一条巷口时，闻到一股食物烧焦的气味——有人在前一夜离开了，锅里的粥已经煮干，锅底裂开了一条黑色的口子。他在巷口站了一下，看了一眼那条裂缝，然后继续走。他不是要去哪里——他只是不能坐着不动。他走过了尚书省的侧门，门敞开着，里面没有人。他走过吏部的官署，走廊上空无一人，值房里的案上还摊着半份没写完的公文——笔搁在砚边，笔尖的墨已经干了，在笔锋上凝成一小块硬壳。笔架上的另一支笔被风吹得轻轻摇晃，在空无一人的房间里发出细小的、有节奏的碰击声——哒，哒，哒——像在写一封永远不会被写完的信。

他走到宫城的墙根下，在墙角坐了下来。他看见城墙的砖缝里长出一株不知名的野草，在风中轻轻摇晃。砖缝里的土很薄——可能只有一小撮，被风吹进去的——但草还是长出来了，茎秆纤细，叶片在傍晚的微光中呈现出一种柔和的暗绿色。他不知道它的种子是从哪里来的。可能是被哪只鸟衔落的，可能在半空中从鸟喙里滑脱了。也可能是从很远的地方被风吹来的——从幽州，从范阳，从某座已经陷落的城池的城墙上——一粒种子顺着风飘了几千里，最后落进了长安城墙角的一道砖缝里。它不知道自己来自哪里，也不知道自己落在了哪里。它只是在砖缝里生了根，把仅有的一点水从砖缝深处的潮气中吸上来，然后长成了一株野草。

他也不知道长安城什么时候会再打开城门。但有一件事他是知道的——在这座城的某个地方，在一间没有锁门的库房里，在一排靠墙的书架底层，有一本书。书里夹着几片纸。纸上写着一个叫沈知远的人用一生写下的话。风从城墙上吹下来，带着砖缝里的灰尘和草籽的气味，落在他的肩上。他没有抖掉。那株野草还在风中摇晃。它的影子在他的膝盖上晃动，像一支笔在纸上写字——写的是什么，他不知道。
