# 第一百一十六章 旧档再查

贞观十年冬。长安落了三场雪。

文德皇后丧期已过，宫中的白幔撤了，百官服色也换回朱紫。但太极宫里的气氛没回暖——皇帝瘦了一圈，鬓边添了白发，早朝时话更少了。群臣奏事，他听着，点头，偶尔问一句，声音比从前哑。散朝后独自留在殿中，对着虚空出神。

沈知远选择在这时候调阅旧起居注。

理由很正当：修国史需核对前朝记注。门下省的主事看了文牒，没多问，开了弘文馆的库房门。

库房在殿西角，朝北，终年不见日头。门一开，一股陈年墨香混着防蠹草的味道扑面而来。架上的竹简和纸卷蒙着灰，蛛网挂在高处的梁角上。

“沈郎中要哪几年的？”

“贞观五年，六月到十二月。”

主事愣了愣。那几架在最深处，梯子都够不着。两个杂役搬了小半个时辰。卷册一摞一摞堆在长案上，纸已经泛黄，边角脆了，一碰就掉渣。

沈知远从袖中取出自己誊抄的一份名录，逐卷比对。

名录上的名字，是他用了三个月时间，从三省六部的旧档里一个一个拣出来的。吏部的铨选册、御史台的弹劾存目、兵部的职方录、户部的度支账——他翻了几百卷，比对任职时间和调迁记录，才凑齐这份名单。

十二个名字。

这些人有个共同点：贞观五年之前都在紧要位置上——吏部考功司掌官员考课，御史台察院掌监察纠弹，兵部职方司掌边防军务。都是能接触到核心事务的差事。贞观五年之后，一个一个，像被水洗过一样，再没出现在任何公文里。

有的外放了。有的告老。有的丁忧。有的病逝。

看起来都正常。太正常了。

沈知远翻到第六卷，手指停住。

*六月壬申，考功员外郎张怀瑾奏铨选事，帝纳之。*

墨迹到这一条之后，忽然断了。

不是被人撕掉或涂改的那种断——书卷完整，装订线完好，竹简没有断损。后面的日期还在，字还在，朝会议政的记录一条接一条，只是关于张怀瑾的记录再也没有了。一个人从六月的某一天起，从皇帝的起居注里消失。

沈知远把这一页举到窗口，对着光看。

纸的纹理均匀，没有接补痕迹。墨色一致，看不出任何重新誊抄的破绽。

做得干净。

他翻到卷末，看校注。

*已核。*

两个字，朱笔，笔迹工整，署名是黄门侍郎王珪。

王珪贞观七年罢相，出为同州刺史。当时说是因漏泄禁中语。沈知远记得，王珪被贬前一个月，曾与房玄龄在政事堂争执，过后便称病不朝。有人说是长孙无忌在背后推了一把——王珪掌门下省，封驳诏敕，挡了长孙无忌几道奏请。

沈知远把这一条记在纸上，继续往下翻。

黄昏的光从高窗斜射进来，灰尘在光柱里缓缓浮动。他的影子投在墙上，拉得很长。

他翻到了第二条。

*八月己亥，察院监察御史刘文素上疏，论铨选之弊。*

又是铨选。

沈知远的手指在纸面上停了一瞬。

刘文素的上疏，他在御史台存档中见过全文。疏中列举了贞观五年春铨选中的十三桩弊案，涉及七名官员的考课不实，其中两人与长孙无忌有旧。措辞激烈，直指吏部。

上疏之后第三天，刘文素被调离御史台，改任太常寺丞——一个管祭祀礼乐的闲职。

起居注里，关于刘文素的记录到此为止。

沈知远翻过两页，看见一行字：

*己酉，以中书侍郎长孙无忌为尚书右仆射。*

八月十四。

他把这两页并排摊开。

张怀瑾的最后一条——六月十七。长孙无忌升任吏部侍郎——六月二十。

刘文素的最后一条——八月十一。长孙无忌升任尚书右仆射——八月十四。

三天。

两次，都是三天。

沈知远靠在胡床的靠背上，闭上眼睛。库房里很静，只有屋顶偶尔落下积尘簌簌的声响。他能听见自己的心跳声，一下一下，沉而稳。

不是巧合。

吏部考功员外郎知道铨选底细——谁托了人情，谁走了门路，谁在考课上做了手脚。监察御史知道弹劾案的走向——谁参了谁，谁保了谁，哪桩案子被按了下去，哪桩被递到了御前。

这两个人消失的时间点，都紧挨着长孙无忌的升迁。

沈知远睁开眼，重新看那十二个名字。

还有十个人。

他从头开始，一个一个核对消失日期和长孙无忌的升迁记录。

贞观五年九月，户部度支郎中郑珪，因账目差错贬为沔州司马。同日，长孙无忌获赐金紫光禄大夫。

贞观六年二月，兵部职方郎中杜叔明，因漏泄军机调任闲职。五日后，长孙无忌兼领太常卿。

贞观六年七月，大理寺丞韦昭，审案有失，夺职。长孙无忌擢为司空。

贞观六年十一月，中书舍人裴延，因制敕违式，贬为巴州别驾。翌日，长孙无忌加散骑常侍。

贞观七年三月，吏部考功郎中崔元，贬台州刺史。

崔元被贬的消息，当时传遍了长安。明面上的理由是考课不公——他给几个山东士族的子弟打了上等，被御史弹劾。

但沈知远记得，崔元被贬之前，曾经找过戴胄。

那是贞观七年二月的一天。沈知远在尚书都堂碰见崔元从戴胄的值房里出来，面色铁青，袖口攥着一卷文书，捏得纸都皱了。事后沈知远问过戴胄，戴胄只说了一句：“崔郎中忧心国事。”便不再多言。

忧心什么？

沈知远翻了翻自己当年随手记的札记，找出了那几日的事：

*贞观七年二月，长孙无忌奏请厘革铨选之弊，请以考课为据，汰冗员。*

崔元掌考课。长孙无忌要动铨选，绕不开他。

然后崔元就被贬了。

从长安到台州，迢递数千里。那一年的台州瘴疠横行，崔元到任不到半年，染疫而亡。

沈知远合上札记。

十二个人。

十二个消失的日期，一一对应着长孙无忌的升迁——要么往前推三天，要么往后推五日。时间咬合得严丝合缝。

他从袖中取出另一份名录——贞观五年到七年，长孙无忌的全部迁转记录。

十七次。

十七次升迁、加衔、兼领。平均不到两个月一次。

从吏部侍郎到尚书右仆射，从司空到散骑常侍，从太常卿到太子少师。朝中要职，他几乎轮了一遍。

沈知远把两份名单摆在一起。一份是消失的人，一份是升迁的人。

这是一个棋盘的正面和背面。

他忽然想起一件旧事。

贞观六年腊月，长孙无忌做寿，在府中摆酒。沈知远那时刚入尚书省，品级低，原不在受邀之列。但戴胄带了他去。

酒过三巡，长孙无忌敬酒，说了一句话，沈知远至今记得。

“戴仆射辅政多年，某景仰得很。将来若是某在朝中主事，还望戴仆射指点。”

沈知远当时觉得不过是场面话。

但现在想来——

贞观六年腊月。长孙无忌已经兼领了太常卿、司徒。

他说“将来若是某在朝中主事”。

那时他已经在准备什么了。

沈知远把卷册归拢，放回架上。手碰到一本旧札记，里面夹着一页纸，字迹潦草，像是随手写的。

他展开来，是一首五言诗。笔势老辣，不是他的手笔。

*金乌衔月出，铁马踏霜归。*

*不是当时客，犹披旧日衣。*

没有署名。

不是他的东西。

沈知远把诗页夹回原处。是谁夹在这卷札记里的？什么时候？他不知道。也许是前一个借阅的人。

也许不是。

他站起来。腿已经麻了，膝盖僵直，走了两步才恢复知觉。

窗外有脚步声。

不是扫地。是靴子踩在石板上的声音，沉稳，有节奏——两个人，步调一致。

他没有抬头。

沈知远重新坐下来，把面前的卷册翻到另一页，做出还在查阅的样子。

脚步声停在门外。

“沈郎中还在？”声音是宫中当值的千牛卫。

“还在。”他应了一声，没回头。

“门要落锁了。”

“这就走。”

脚步声又响了，渐渐远去。

沈知远把卷册一一收起，放回架上。他走得比平时慢，走在廊下时，余光扫了一眼西边的回廊——空的。

走出弘文馆时，暮色已经漫过宫墙，廊下的灯笼次第亮起来。雪地映着灯光，泛着幽幽的蓝白。

他站在阶前，看着灯笼的光在雪地上投下一团团橘黄的影子。

三天。

这个数字像钉子一样扎在脑子里。

他沿着长廊往外走，经过甘露殿时，看见殿内灯还亮着。灯影里有人影伏在案上。皇帝今夜又要批奏章到几更？

沈知远没有驻足，低着头继续走。

出宫门时，掖门的守卒验了腰牌。他接过腰牌的手有些凉，不是冻的。

永兴里的宅邸在三坊外，沈知远没有坐车，沿着坊墙走。雪在脚下咯吱作响，长安的冬夜静谧得出奇。

回到宅中，掌灯，磨墨。他把名录又誊了一遍。墨磨得浓淡均匀，笔锋稳健，十二个名字写得端端正正。

十二个名字，十二个官职，十二个消失的日期。

他找出贞观五年的职官表，逐一标注这些人当年的隶属关系——七个人出自山东士族，三个人出自关陇集团，两个人出自江南士族。

不是一个派系。

那他们为什么被清掉？

沈知远搁下笔，盯着名录看了一炷香的工夫。

他把目光落在最末一个名字上。

*崔元，贞观七年三月，自吏部考功郎中贬为台州刺史。*

他想起崔元的面孔——清瘦，颧骨很高，说话时喜欢先低头再抬眼，目光很重。崔元最后一次来尚书都堂，袖中揣着一卷文书，脸上的表情已经不像愤怒，倒像恐惧。

沈知远闭上眼睛，在黑暗中重演那一日的场景。

崔元从戴胄值房里出来，面色铁青，有人叫了他一声，他像没听见，径直往门口走。走到廊下时停了一步，回头看了尚书都堂的匾额一眼。

那一眼。

现在想来，那一眼的意思也许是：我回不来了。

沈知远睁开眼。

窗纸发白了。案上烛台积了一汪烛泪，红蜡凝在铜盘里，像一摊凝固的血。

他吹了灯。没有睡。在黑暗中坐着，把这十二个人的履历从头到尾又默过一遍。

天快亮时，他听见里坊的鼓声。

晨鼓。

新的一天开始了。

沈知远站起来，腿已经麻了。他扶着案沿站了一会儿，走到院子里。雪停了，空气冷得像刀片。

院子很小，东墙根种了一棵槐树，落了雪，枝丫弯着。西墙边是他的书房，窗台不高，一抬腿就能翻进去。

他看见窗台上有几个脚印。

新鲜的。

他俯身细看——脚印不大，靴底纹路清晰，不是昨夜宫中侍卫留下的。他的宅邸很小，只有前门一个出口，后墙高丈余，侍卫只守在前院。没有人会走到书房窗外。

脚印朝西，通向两坊之间的巷道。

沈知远蹲下来，把雪上的印记看了很久。

印痕深——说明那个人站了有一阵子。

方向朝外——是离开的脚迹，不是来时的。

那人来过，看了，走了。

什么时候？

昨夜。在他回来的同时，或者之后。

沈知远站起身，拍掉膝上的雪，走进书房，把名录和札记收进暗格。暗格在书架背后，撬开一块活动的砖，里面是一个铁匣。他把铁匣放在砖上，合上，再把书归回原位。

他推开窗。冷风灌进来，吹得案上的纸哗哗作响。

远处，太极宫的飞檐在晨光里泛着金光。

消息，已经漏了。
